## 이 책을 쓴 이유

이 책은 5년간 진행한 통계 과외의 내용을 정리한 것입니다. 새로 집필한 원고가 아니라, 실제로 학생들을 가르칠 때 쓰던 자료를 다시 정리한 것입니다.

과외를 하면서 확인한 것은 학생들이 막히는 지점이 대체로 같다는 것입니다. 그리고 그 지점은 계산이 아니었습니다.

- 등분산성을 왜 검정해야 하는지 모른 채 절차만 반복하는 경우
- 유의확률이 작아야 하는 검정과 커야 하는 검정을 구분하지 못하는 경우
- 출력 결과는 얻었으나 어느 값을 논문에 옮겨야 하는지 판단하지 못하는 경우

세 경우 모두 공식을 몰라서가 아니라 **그 절차가 무엇을 확인하는 것인지 배우지 못해서** 발생합니다. 많은 통계 강의가 계산 절차는 가르치지만 그 절차의 목적은 설명하지 않습니다.

:::key 이 책이 설명하는 순서
이 책은 모든 개념에 대해 **왜 그 절차가 필요한가**를 먼저 설명한 뒤 계산 방법을 제시합니다.

예를 들어 등분산성 검정은 "분산이 같아야 한다"는 요건으로 제시하지 않습니다. 두 집단의 분산이 같다는 것은 처치가 개입하기 이전에 두 집단을 동질한 집단으로 간주할 수 있었다는 뜻이며, 이것이 흔들리면 평균 차이를 처치 때문이라고 말할 수 없다는 점을 먼저 설명합니다. 검정 절차는 그다음입니다.

계산은 R이 수행합니다. 독자가 해야 할 일은 **판단**입니다.
:::

## 대상 독자

다음 중 하나에 해당한다면 이 책이 적합합니다.

- 학위논문을 쓰면서 통계 분석을 직접 해야 하는 경우
- 통계 강의를 수강했으나 자신의 자료와 연결되지 않는 경우
- 비전공자로서 설문 자료를 처음 다루는 경우
- 실무에서 데이터를 다루다가 기초 개념을 정리하고 싶은 경우

통계학 전공자를 위한 책은 아닙니다. **수식을 유도하거나 증명하지 않습니다.** 대신 각 분석이 무엇을 확인하는 절차인지, 결과의 어느 값을 어떻게 읽는지, 그것을 보고서에 어떻게 기술하는지를 다룹니다.

## 분석 도구로 R을 사용하는 이유

SPSS는 클릭만으로 쓸 수 있어 시작하기 쉽습니다. 그러나 실제 분석 과정에서는 다음과 같은 문제가 발생합니다.

- 변수를 하나 제외하고 재분석해야 할 때 클릭 절차를 처음부터 반복해야 합니다
- 수 주 전에 수행한 분석의 설정을 재확인할 수 없습니다
- 학교나 회사의 라이선스가 끝나면 분석을 할 수 없습니다

R은 분석 과정이 코드로 기록됩니다. 기록이 남으면 수정은 한 줄로 끝나며 언제든 그대로 다시 돌릴 수 있습니다. 그리고 무료입니다.

:::warn 프로그래밍 학습이 아닙니다
이 책에서 사용하는 R 코드는 대부분 한 줄 분량입니다. `t.test(점수 ~ 집단, data = df)` 형태이며, 독자가 할 일은 변수명을 자기 자료에 맞게 바꾸는 것뿐입니다.

프로그래밍 언어를 습득하는 과정이 아니라 계산기 사용법을 익히는 과정에 가깝습니다.
:::

## 준비 사항

```r 최초 1회만 수행합니다
# 1) R 설치: https://cran.r-project.org
# 2) RStudio 설치: https://posit.co/download/rstudio-desktop
# 3) 패키지 설치 (콘솔에 입력)

install.packages(c("psych", "car", "effectsize"))
```

설치를 마쳤으면 분석을 시작할 때마다 다음 두 줄을 실행합니다.

```r 분석 시작 시
library(psych)                 # 기술통계
df <- read.csv("data.csv")     # 자료 불러오기
```

:::paper 자료 파일 만드는 법
설문 자료를 정리할 때는 **1행에 변수명, 1인당 1행**의 구조를 유지합니다. 변수명은 영문 소문자와 밑줄만 사용하는 것이 안전합니다(`self_esteem`, `age`, `gender`). 한글 변수명도 인식되지만 공백이 포함되면 오류가 발생합니다.

정리가 끝나면 엑셀에서 **다른 이름으로 저장 → CSV UTF-8**을 선택합니다.
:::

## 시리즈 구성

이 책은 네 권으로 구성된 시리즈의 첫 권입니다.

| 권 | 내용 | 적용 상황 |
| --- | --- | --- |
| **1권 기초통계** | 척도, 기술통계, 표집분포, 가설검정, t-검정, 분산분석 | 집단 간 차이와 기본 관계를 분석할 때 |
| 2권 회귀분석 | 단순·다중회귀, 더미변수, 매개·조절효과 | 영향력의 크기를 추정할 때 |
| 3권 요인분석 | 탐색적·확인적 요인분석, 신뢰도·타당도 | 측정도구를 검증할 때 |
| 4권 구조방정식 | 측정모형, 구조모형, 적합도 지수 | 변수 간 인과 구조를 검증할 때 |

:::recap
**요약** — 이 책을 마치면 자신의 자료에서 변수의 척도를 판별하고, 그에 적합한 분석을 선택하여 R로 수행하고, 출력에서 필요한 값을 식별하여 결과표와 서술문으로 옮길 수 있습니다.
