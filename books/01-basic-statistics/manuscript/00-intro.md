## 이 책이 전제하는 상태

이 책은 다음 중 하나에 해당하는 분을 위해 썼습니다.

- 학위논문 심사가 잡혔는데, 지도교수님이 말한 분석 이름조차 낯설다
- 학부 통계 수업을 들었지만 시험 끝나고 전부 사라졌다
- 설문 데이터는 모았는데, 엑셀을 열어놓고 뭘 눌러야 할지 모르겠다

통계학과 학생을 위한 책이 아닙니다. **수식을 유도하지 않고, 증명하지 않습니다.** 대신 "이 상황에서는 이 분석을 쓰고, 결과의 이 숫자를 이렇게 읽고, 논문에는 이렇게 적는다"를 반복합니다.

:::key 이 책의 목표
이 책을 다 읽고 나면, 자기 데이터를 보고 **"평균 비교구나" 또는 "관계 확인이구나"를 스스로 판단**할 수 있게 됩니다. 분석을 고를 수 있으면 나머지는 검색으로 해결됩니다. 못 고르면 검색조차 못 합니다.
:::

## 왜 R인가

SPSS는 클릭만 하면 되니 더 쉬워 보입니다. 그런데 실제로는 이런 일이 벌어집니다.

- 지도교수님이 "변수 하나 빼고 다시 돌려봐"라고 하면, 클릭을 처음부터 다시 해야 합니다
- 3주 전에 돌린 분석을 **어떤 옵션으로 돌렸는지 기억나지 않습니다**
- 학교 라이선스가 끊기면 그 순간부터 아무것도 못 합니다

R은 분석 과정이 코드로 남습니다. 코드가 남으면 수정이 한 줄이고, 기록이 그대로 재현됩니다. 그리고 무료입니다.

:::warn "코딩을 못 하는데요"
이 책에서 쓰는 R 코드는 대부분 **한 줄짜리**입니다. `t.test(점수 ~ 집단, data = df)` 같은 형태고, 여러분이 할 일은 `점수`와 `집단` 자리에 본인 변수 이름을 넣는 것뿐입니다. 프로그래밍을 배우는 게 아니라, 계산기 사용법을 배운다고 생각하시면 됩니다.
:::

## 준비물

```r 설치는 한 번만 하면 됩니다
# 1) R 설치: https://cran.r-project.org
# 2) RStudio 설치: https://posit.co/download/rstudio-desktop
# 3) 아래 패키지 설치 (콘솔에 붙여넣고 엔터)

install.packages(c("psych", "car", "effectsize"))
```

설치가 끝났다면, 앞으로 매번 분석을 시작할 때는 이 두 줄만 실행하면 됩니다.

```r 분석 시작 시 매번 실행
library(psych)          # 기술통계 요약
df <- read.csv("data.csv")   # 내 데이터 불러오기
```

:::paper 데이터 파일 준비 요령
설문 데이터를 엑셀로 정리할 때는 **1행 = 변수명, 1인 = 1행**을 지키세요. 변수명은 영문 소문자와 밑줄만 쓰는 것이 안전합니다(`self_esteem`, `age`, `gender`). 한글 변수명도 되지만, 띄어쓰기가 들어가는 순간 오류가 납니다. 다 만들었으면 엑셀에서 `다른 이름으로 저장 → CSV UTF-8`을 선택하세요.
:::

## 책의 구성

이 책은 네 권짜리 시리즈의 첫 권입니다.

| 권 | 다루는 것 | 언제 필요한가 |
| --- | --- | --- |
| **1권 기초통계** | 척도, 기술통계, t-검정, 분산분석, 상관, 카이제곱 | 집단 간 차이·기본 관계를 볼 때 |
| 2권 회귀분석 | 단순·다중회귀, 더미변수, 매개·조절효과 | 영향력의 크기를 볼 때 |
| 3권 요인분석 | 탐색적·확인적 요인분석, 신뢰도·타당도 | 측정도구를 검증할 때 |
| 4권 구조방정식 | 측정모형, 구조모형, 적합도 지수 | 변수 간 인과 구조를 볼 때 |

1권은 나머지 세 권의 토대입니다. 여기서 다루는 **척도 개념과 유의확률 읽는 법을 모르면 2권부터는 한 줄도 이해되지 않습니다.**

:::recap
**1권을 다 읽으면 할 수 있는 것** — 내 변수의 척도를 판별하고, 그에 맞는 분석을 골라, R로 돌리고, 출력에서 필요한 숫자를 찾아, 논문 결과표와 서술문으로 옮기는 것까지.
:::
