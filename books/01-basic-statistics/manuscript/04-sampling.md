## 우리가 실제로 하고 있는 일

연구자가 알고 싶은 것은 **모집단**입니다. 한국 대학생 전체의 자아존중감 평균이 얼마인가.

그런데 전체를 조사할 수는 없습니다. 그래서 **표본**을 뽑습니다. 240명을 조사해 평균 3.50을 얻었습니다.

여기서 질문이 생깁니다.

> 이 240명에서 나온 3.50이, 전체의 평균과 얼마나 가까울까?

다른 240명을 뽑았다면 3.42가 나왔을 수도 있고 3.58이 나왔을 수도 있습니다. **내가 뽑은 표본이 하필 이상한 표본일 가능성**을 어떻게 다룰 것인가. 이것이 추리통계가 푸는 문제입니다.

:::key 용어를 구분해 두세요
| 구분 | 모집단 | 표본 |
| --- | --- | --- |
| 대상 | 알고 싶은 전체 | 실제로 조사한 일부 |
| 평균 | *μ* (뮤) | *M* 또는 *X̄* |
| 표준편차 | *σ* (시그마) | *s* |
| 부르는 이름 | **모수**(parameter) | **통계치**(statistic) |

모수는 알 수 없는 진짜 값이고, 통계치는 우리가 계산한 값입니다. **통계치로 모수를 추정하는 것**이 우리가 하는 일의 전부입니다.
:::

## 표집분포 — 상상 속의 분포

핵심 아이디어는 이렇습니다.

**같은 크기의 표본을 무한히 반복해서 뽑는다고 상상합니다.** 표본마다 평균이 나올 것이고, 그 평균들을 모아 분포를 그립니다. 이것이 **표집분포(sampling distribution)**입니다.

!fig[**그림 4-1** 표집분포는 사람들의 점수가 모인 분포가 아니라, 표본평균이라는 통계치가 모인 분포다. (개념도)](ch04-sampling-concept.svg)

:::warn 가장 많이 헷갈리는 지점
표집분포는 **점수의 분포가 아닙니다.** 240명의 자아존중감 점수를 그린 히스토그램과는 전혀 다른 것입니다.

표집분포는 **통계치의 분포**입니다. 표본평균 *M*의 분포일 수도 있고, *t*값의 분포일 수도 있고, *F*값의 분포일 수도 있습니다. 무엇을 계산했느냐에 따라 표집분포도 달라집니다.

그리고 **실제로 그려본 적은 없습니다.** 우리는 표본을 하나만 뽑았으니까요. 그런데도 이 분포의 성질을 알기 때문에 추론이 가능해집니다. 이 점이 이상하게 느껴진다면 제대로 이해하신 겁니다.
:::

표집분포에 대해 알려진 세 가지가 있습니다.

1. **표본평균들의 평균은 모평균과 같다** — 편향 없이 맞춘다
2. **표본이 커질수록 표집분포는 좁아진다** — 정밀해진다
3. **표본이 충분히 크면 표집분포는 정규분포가 된다** — 원자료 모양과 상관없이

세 번째가 **중심극한정리**입니다.

## 중심극한정리 — 이 책에서 가장 중요한 정리

말로 하면 이렇습니다.

> 원자료가 어떤 모양이든, 표본크기 *n*이 커지면 표본평균의 분포는 정규분포에 가까워진다.

믿기 어려운 주장이라 직접 확인해 보겠습니다. **일부러 아주 심하게 치우친 모집단**을 만들어 씁니다.

```r 지수분포에서 표본을 반복해 뽑는다
set.seed(2025)
pop <- rexp(200000, rate = 1)     # 심하게 오른쪽으로 치우친 모집단

library(psych)
skew(pop)                          # 모집단의 왜도

# n명씩 뽑아 평균을 내는 일을 5,000번 반복
means5  <- replicate(5000, mean(sample(pop, 5)))
means30 <- replicate(5000, mean(sample(pop, 30)))

c(원자료 = skew(pop), n5 = skew(means5), n30 = skew(means30))
```

```out
원자료      n5     n30
  1.97    0.87    0.40
```

!fig[**그림 4-2** 모집단은 왜도 1.97로 심하게 치우쳐 있지만, 5명씩만 뽑아 평균을 내도 벌써 대칭에 가까워지고 30명이면 정규분포에 근사한다.](ch04-clt.svg)

**왜도가 1.97에서 0.40으로 줄었습니다.** 모집단은 전혀 정규분포가 아닌데, 표본평균의 분포는 정규분포를 닮아갑니다.

:::warn "표본을 많이 뽑는다"가 아닙니다
가장 흔한 오해입니다. 중심극한정리가 말하는 것은 **표본의 개수**가 아니라 **표본 하나의 크기 *n***입니다.

5명짜리 표본을 100만 번 뽑아도 표집분포는 정규분포가 되지 않습니다. **한 표본에 몇 명이 들어 있느냐**가 중요합니다.
:::

:::key 그래서 n ≥ 30이라는 관행이 있습니다
위 결과에서 n = 30이면 왜도가 0.40까지 떨어졌습니다. 이 정도면 정규분포로 취급해도 무리가 없다고 보아, 사회과학에서는 **각 집단 n이 30 이상이면 정규성 가정을 크게 걱정하지 않습니다.**

다만 원자료가 극단적으로 치우쳐 있다면 30으로는 부족할 수 있습니다. 절대적인 기준이 아니라 경험적인 관행입니다.
:::

**이 정리가 없으면 이 책의 나머지가 전부 무너집니다.** t-검정도 분산분석도 "표본평균이 정규분포를 따른다"를 전제로 하는데, 그 전제를 보장해 주는 것이 중심극한정리이기 때문입니다.

## 표준오차 — 내 평균을 얼마나 믿을 수 있나

표집분포의 **표준편차**를 특별히 **표준오차(standard error, SE)**라고 부릅니다.

$$
SE = \frac{s}{\sqrt{n}}
$$ (표본평균이 얼마나 흔들리는지)

이름이 헷갈리게 지어졌지만 의미는 분명합니다. **"내가 뽑은 표본평균이 모평균에서 평균적으로 이만큼 벗어나 있다"**는 값입니다. 표본을 뽑는 과정에서 생기는 오차를 수량화한 것입니다.

```r 표준오차 계산
s <- df$selfesteem
SE <- sd(s) / sqrt(length(s))

c(SD = sd(s), n = length(s), SE = SE)
```

```out
        SD          n         SE
 0.8338000 240.000000  0.0538000
```

표준편차는 0.83인데 표준오차는 0.054입니다. **훨씬 작습니다.** 개인들은 서로 많이 다르지만, 240명의 평균은 그렇게까지 흔들리지 않는다는 뜻입니다.

!fig[**그림 4-3** 자료의 표준편차는 그대로인데 표본크기만 커지면 표집분포가 좁아진다.](ch04-se-shrink.svg)

```r 표본크기별 표준오차
for (n in c(25, 100, 400)) cat(n, ":", round(sd(s)/sqrt(n), 4), "\n")
```

```out
25 : 0.1668
100 : 0.0834
400 : 0.0417
```

**표본이 4배가 되면 표준오차는 절반이 됩니다.** 분모에 제곱근이 붙어 있기 때문입니다. 이 사실이 실무에서 중요합니다. 정밀도를 두 배로 올리려면 표본을 네 배로 늘려야 하니까요.

## 표준편차와 표준오차는 다른 것을 잽니다

이름이 비슷해서 계속 헷갈리는 두 값입니다. **재는 대상이 완전히 다릅니다.**

!fig[**그림 4-4** 표준편차는 사람들이 서로 얼마나 다른지를, 표준오차는 내 추정이 얼마나 못 미더운지를 잰다. (개념도)](ch04-sd-vs-se.svg)

| | 표준편차 (SD) | 표준오차 (SE) |
| --- | --- | --- |
| 무엇을 재나 | **사람들이 서로 얼마나 다른가** | **내 평균이 얼마나 못 미더운가** |
| 표본이 커지면 | 변하지 않는다 | 작아진다 |
| 성격 | 자료 자체의 성질 | 추정의 정밀도 |
| 논문에서 | 기술통계 표 | 오차막대, 신뢰구간 |

:::paper 표에 SD를 쓸지 SE를 쓸지
**집단이 어떻게 생겼는지**를 보여주려면 SD입니다. 논문의 표 1(기술통계)에는 거의 항상 SD를 씁니다.

**평균을 얼마나 믿을 수 있는지**를 보여주려면 SE입니다. 그래프의 오차막대에 SE를 쓰는 경우가 많습니다.

오차막대를 그릴 때는 **캡션에 SD인지 SE인지 95% 신뢰구간인지 반드시 밝히세요.** 밝히지 않으면 독자가 해석할 수 없고, 심사에서 확실히 지적받습니다.
:::

:::key 표준오차는 앞으로 계속 나옵니다
6장의 신뢰구간, 7장의 t값, 9장의 F값이 모두 표준오차를 분모에 두고 계산됩니다.

**"차이 ÷ 그 차이가 흔들리는 정도"**라는 형태가 반복됩니다. 검정통계량이란 결국 "관찰된 차이가 우연한 흔들림의 몇 배인가"를 재는 값입니다.
:::

:::check 이 장을 마치기 전 확인
- 모수와 통계치를 구분할 수 있다
- 표집분포가 점수의 분포가 아니라 통계치의 분포임을 안다
- 중심극한정리가 표본의 **개수**가 아니라 **크기**에 대한 것임을 안다
- 표준편차와 표준오차가 재는 대상이 다르다는 것을 말할 수 있다
- 표본이 4배가 되면 표준오차가 절반이 되는 이유를 안다
:::

:::recap
**이 장의 한 줄** — 표본 하나로 모집단을 말할 수 있는 근거는 **중심극한정리**다. 원자료가 어떻게 생겼든 표본평균의 분포는 정규분포가 되고, 그 분포의 폭인 **표준오차**가 앞으로 모든 검정통계량의 분모가 된다.
:::
