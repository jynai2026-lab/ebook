## 왜 두 숫자인가

자료를 하나의 숫자로만 줄이면 중요한 것을 잃습니다.

두 반의 시험 평균이 똑같이 70점이라고 해봅시다. 한 반은 모두 68~72점 사이에 몰려 있고, 다른 반은 30점부터 100점까지 흩어져 있습니다. **평균만 보면 두 반은 같은 반입니다.** 그러나 교사가 해야 할 일은 완전히 다릅니다.

그래서 자료를 요약할 때는 항상 **두 가지**를 함께 봅니다.

- **가운데가 어디인가** — 대표값 (평균, 중앙값, 최빈값)
- **얼마나 흩어져 있는가** — 산포도 (분산, 표준편차)

논문의 표 1에 언제나 *M*과 *SD*가 나란히 붙어 있는 이유가 이것입니다. 둘 중 하나만으로는 자료를 설명하지 못합니다.

## 가운데를 가리키는 세 가지 방법

| 대표값 | 정의 | 어떤 의미의 '가운데'인가 |
| --- | --- | --- |
| **평균**(Mean) | 모든 값을 더해 개수로 나눔 | 무게중심 |
| **중앙값**(Median) | 크기순으로 세웠을 때 한가운데 값 | 순위상 한가운데 |
| **최빈값**(Mode) | 가장 많이 관측된 값 | 가장 흔한 값 |

자료가 좌우 대칭이면 셋은 거의 같은 곳을 가리킵니다. 문제는 **치우친 자료**입니다.

!fig[**그림 2-1** 오른쪽으로 치우친 분포에서 세 대표값이 서로 다른 곳을 가리킨다. (개념도)](ch02-three-centers.svg)

```r 원고의 예제 자료
y <- c(1, 1, 1, 2, 3, 4, 6, 8, 9, 9, 11)

c(합 = sum(y), 평균 = mean(y), 중앙값 = median(y))
```

```out
    합   평균 중앙값
    55      5      4
```

평균은 5, 중앙값은 4, 최빈값은 1입니다. 세 숫자가 다 다릅니다.

:::key 평균은 극단값에 끌려갑니다
평균은 **모든 값을 다 쓰기 때문에** 극단값 하나에도 움직입니다. 위 자료에서 11을 100으로 바꾸면 평균은 5에서 13.1로 뛰지만 중앙값은 4 그대로입니다.

그래서 **소득, 재산, 반응시간**처럼 한쪽으로 길게 늘어지는 변수는 평균보다 중앙값이 자료를 더 잘 대표합니다. 뉴스에서 "평균 연봉"과 "중위 연봉"을 따로 말하는 이유입니다.
:::

:::paper 논문에서는 거의 평균을 씁니다
중앙값이 더 정확할 때도 논문에서는 평균을 쓰는 경우가 많습니다. t-검정, 분산분석, 회귀분석이 모두 **평균을 비교하는 분석**이기 때문입니다.

다만 분포가 심하게 치우쳤다면 그대로 밀고 나가지 말고 ① 로그 변환을 하거나 ② 비모수 검정(Mann-Whitney U 등)으로 바꾸는 것을 고려하세요. 심사에서 지적받는 대표적인 지점입니다.
:::

## 흩어진 정도를 재는 길

여기서부터가 진짜입니다. 흩어짐을 재는 과정은 **막힐 때마다 한 단계씩 우회해 온 역사**입니다. 그 우회의 이유를 알면 공식이 외울 것이 아니라 당연한 것이 됩니다.

### 1단계 — 편차: 평균에서 얼마나 떨어졌나

가장 자연스러운 출발점은 **각 값이 평균에서 얼마나 떨어졌는지**입니다. 이것을 편차라고 합니다.

$$
\text{편차} = X - M
$$

자료가 100개면 편차도 100개입니다. 이걸 하나의 숫자로 줄이려면 더해야 합니다. 그런데 여기서 막힙니다.

!fig[**그림 2-2** 자료 7, 3, 5, 4, 2, 3의 편차. 평균 위로 올라간 만큼과 아래로 내려간 만큼이 정확히 상쇄되어 합이 0이 된다.](ch02-deviation.svg)

```r 편차를 더하면
x <- c(7, 3, 5, 4, 2, 3)

x - mean(x)          # 편차
sum(x - mean(x))     # 편차의 합
```

```out
[1]  3 -1  1  0 -2 -1
[1] 0
```

**편차의 합은 언제나 0입니다.** 우연이 아닙니다. 평균이 바로 "편차의 합이 0이 되는 지점"으로 정의되기 때문입니다. 무게중심이라는 표현이 여기서 나옵니다.

그러니 편차를 그냥 더해서는 흩어짐을 잴 수 없습니다. **부호를 없애야 합니다.**

### 2단계 — 제곱: 부호를 없애는 두 가지 방법 중 하나

부호를 없애는 방법은 두 가지입니다. 절댓값을 씌우거나, 제곱하거나.

!fig[**그림 2-3** 절댓값은 모든 편차를 같은 비중으로 세지만, 제곱은 멀리 떨어진 값에 더 큰 비중을 준다. (개념도)](ch02-why-square.svg)

통계학은 **제곱**을 택했습니다. 이유는 두 가지입니다.

첫째, **큰 편차에 더 큰 비중을 주기 위해서**입니다. 평균에서 4만큼 떨어진 값은 1만큼 떨어진 값보다 4배가 아니라 **16배** 더 흩어진 것으로 셉니다. 흩어짐을 볼 때는 극단값이 더 중요하다고 보는 관점입니다.

둘째, **수학적으로 다루기 좋기 때문**입니다. 절댓값은 미분이 안 되는 지점이 있지만 제곱은 매끄럽습니다. 이후의 모든 이론이 이 위에 세워집니다.

편차를 제곱해서 모두 더한 값을 **제곱합(Sum of Squares, SS)**이라고 합니다.

$$
SS = \sum (X - M)^2
$$ (앞으로 계속 나오는 이름입니다)

:::key SS는 이 책 전체에서 계속 나옵니다
제곱합은 여기서 끝나는 개념이 아닙니다. **분산분석은 전체 SS를 집단 간 SS와 집단 내 SS로 쪼개는 분석**이고(9장), 회귀분석의 결정계수도 SS의 비율입니다(2권). "흩어짐을 제곱합으로 잰다"는 약속 하나가 통계 전체를 관통합니다.
:::

### 3단계 — 나누기: 개수가 다른 자료를 비교하려면

SS에는 문제가 하나 남아 있습니다. **자료가 많을수록 무조건 커집니다.** 100명의 SS와 1000명의 SS를 비교하는 것은 의미가 없습니다.

그래서 개수로 나눠 **하나당 평균 얼마나 떨어져 있는지**로 바꿉니다. 이것이 **분산**입니다.

$$
s^2 = \frac{SS}{n-1} = \frac{\sum (X - M)^2}{n-1}
$$

### 4단계 — 제곱근: 단위를 되돌리기

분산에는 아직 불편한 점이 있습니다. **단위가 제곱**입니다. 점수의 분산은 "점수²"이라 무슨 뜻인지 감이 오지 않습니다.

그래서 제곱근을 씌워 원래 단위로 되돌립니다. 이것이 **표준편차**입니다.

$$
s = \sqrt{s^2}
$$ (자료와 같은 단위가 되어 해석할 수 있습니다)

!fig[**그림 2-4** 편차에서 표준편차까지, 각 단계마다 앞 단계의 문제를 하나씩 해결한다.](ch02-ss-flow.svg)

```r 한 번에 확인
x <- c(7, 3, 5, 4, 2, 3)

c(SS = sum((x - mean(x))^2),
  분산 = var(x),
  표준편차 = sd(x))
```

```out
      SS     분산 표준편차
16.00000  3.20000  1.78885
```

**표준편차 1.79는 "각 값이 평균 4에서 평균적으로 1.79만큼 떨어져 있다"**는 뜻입니다. 이제 해석할 수 있는 숫자가 됐습니다.

## n이 아니라 n−1로 나누는 이유

여기서 거의 모든 사람이 걸립니다. "평균 얼마나 떨어졌는지"를 구한다면 개수인 *n*으로 나눠야 할 것 같은데, 왜 *n*−1일까요.

**표본은 모집단보다 덜 퍼져 보이기 때문입니다.**

!fig[**그림 2-5** 표본을 뽑으면 흔한 값은 잘 뽑히고 극단값은 놓치기 쉽다. 그래서 표본의 퍼진 범위는 모집단보다 좁게 나온다. (개념도)](ch02-n-minus-1.svg)

모집단에서 표본을 뽑을 때, **가운데의 흔한 값은 잘 뽑히고 양쪽 끝의 드문 값은 놓치기 쉽습니다.** 그래서 표본만 보고 계산한 분산은 모집단의 진짜 분산보다 **작게** 나옵니다. 이것을 과소추정이라고 합니다.

*n*으로 나누는 대신 그보다 작은 *n*−1로 나누면 값이 조금 커집니다. **그 보정이 과소추정을 상쇄합니다.**

```r n으로 나눌 때와 n-1로 나눌 때
x  <- c(7, 3, 5, 4, 2, 3)
SS <- sum((x - mean(x))^2)

c(n으로_나눔 = SS / length(x),
  n에서1뺌 = SS / (length(x) - 1))
```

```out
n으로_나눔  n에서1뺌
  2.666667  3.200000
```

:::key 자유도라는 이름
이 *n*−1을 **자유도(degrees of freedom)**라고 부릅니다. 이름의 유래는 이렇습니다.

평균이 4로 정해진 6개 값이 있다고 합시다. 앞의 다섯 개는 아무 값이나 될 수 있지만, **마지막 하나는 평균을 4로 맞추기 위해 자동으로 결정됩니다.** 자유롭게 움직일 수 있는 값이 5개뿐이라는 뜻입니다.

자유도는 앞으로 계속 나옵니다. t-검정에서 `df = 238`, 분산분석에서 `df = 2, 27` 같은 숫자가 모두 이 개념입니다. **"몇 개가 자유롭게 움직일 수 있는가"**로 읽으면 됩니다.
:::

:::warn R의 `var()`와 `sd()`는 n−1을 씁니다
R의 `var()`, `sd()`는 **표본** 기준(*n*−1)으로 계산합니다. SPSS도 마찬가지입니다. 논문에서 다루는 자료는 거의 항상 표본이므로 이것이 맞습니다.

모집단 전체를 가지고 있는 드문 경우에만 *n*으로 나눠야 하는데, 그때는 직접 계산해야 합니다.
:::

## 표준편차를 알면 무엇이 보이는가

표준편차는 계산으로 끝나는 값이 아닙니다. **"이 값이 흔한가 드문가"를 판단하는 자**입니다.

!fig[**그림 2-6** 자료가 정규분포를 따른다면 평균 ±1 표준편차 안에 약 68%, ±2 안에 약 95%가 들어온다.](ch02-sd-meaning.svg)

이 68–95–99.7 규칙이 있으면 이런 판단이 바로 됩니다.

- 평균 70, 표준편차 5인 시험에서 **85점**은? 평균에서 3 표준편차 위 → 상위 0.1% 수준
- 평균 3.5, 표준편차 0.8인 자아존중감에서 **4.3점**은? 1 표준편차 위 → 상위 16% 정도

:::key 여기서 유의확률이 나옵니다
"평균에서 2 표준편차 이상 떨어진 값은 5%밖에 없다"는 사실을 기억해 두세요. **5장에서 다룰 유의수준 .05가 정확히 이 지점에서 나옵니다.** 우연으로 보기에는 너무 드문 경계를 어디에 그을 것인가의 문제입니다.
:::

## 표준점수 — 단위가 다른 것을 비교하는 법

수학 시험에서 72.8점, 영어 시험에서 94점을 받았습니다. **어느 과목을 더 잘 본 걸까요?**

원점수만으로는 답할 수 없습니다. 시험 난이도가 다르기 때문입니다. 필요한 것은 **각 과목 안에서 내가 어디쯤인가**입니다.

편차를 표준편차로 나누면 그 위치가 나옵니다. 이것이 **표준점수(z-score)**입니다.

$$
z = \frac{X - M}{s}
$$ (평균에서 표준편차 몇 개만큼 떨어졌는가)

!fig[**그림 2-7** 원점수로는 영어가 21점이나 높지만, 각 과목 안에서의 위치로 바꾸면 수학이 앞선다.](ch02-zscore.svg)

```r 두 과목 비교
z_math <- (72.8 - 70) / 5     # 수학: 평균 70, 표준편차 5
z_eng  <- (94   - 90) / 8     # 영어: 평균 90, 표준편차 8

c(수학 = z_math, 영어 = z_eng)
```

```out
수학 영어
0.56 0.50
```

**수학을 더 잘 봤습니다.** 원점수는 영어가 21점이나 높은데도 그렇습니다.

z점수로 바꾸면 어떤 자료든 **평균 0, 표준편차 1**인 분포에 놓입니다. 단위가 사라지므로 서로 다른 척도를 비교할 수 있게 됩니다.

:::warn z점수가 분포를 정규분포로 만들어 주지는 않습니다
자주 하는 오해입니다. z 변환은 **선형변환**이라 분포의 위치와 폭만 바꾸고 **모양은 그대로 둡니다.** 치우친 자료를 z점수로 바꿔도 여전히 치우쳐 있습니다.

정규분포로 만들려면 로그 변환처럼 모양 자체를 바꾸는 방법이 필요합니다.
:::

:::paper 논문에서 z점수를 쓰는 곳
① 단위가 다른 변수들을 한 모형에 넣을 때(회귀분석의 표준화 계수 β), ② 이상치를 판별할 때(보통 |z| > 3), ③ 여러 검사 점수를 합산할 때 씁니다.

R에서는 `scale()` 한 줄이면 됩니다. `df$z_selfesteem <- scale(df$selfesteem)`
:::

## 실제 데이터로 확인하기

```r 이 책의 예제 데이터
df <- read.csv("data/sample_data.csv")
s  <- df$selfesteem

c(n = length(s), M = mean(s), SD = sd(s),
  중앙값 = median(s), 최소 = min(s), 최대 = max(s))
```

```out
        n         M        SD    중앙값      최소      최대
240.00000   3.49700   0.83400   3.50000   1.19000   5.00000
```

평균 3.50과 중앙값 3.50이 거의 같습니다. **좌우로 크게 치우치지 않았다는 뜻**이고, 평균이 이 자료를 잘 대표한다는 신호입니다. 7장에서 이 변수로 t-검정을 할 때 정규성 가정을 크게 걱정하지 않아도 되는 근거가 여기 있습니다.

:::check 이 장을 마치기 전 확인
- 자료를 요약할 때 대표값과 산포를 **함께** 봐야 하는 이유를 말할 수 있다
- 편차를 그냥 더하면 0이 되는 이유를 안다
- 절댓값이 아니라 제곱을 쓰는 이유를 안다
- *n*−1로 나누는 이유를 "표본은 덜 퍼져 보인다"로 설명할 수 있다
- 표준편차를 "평균에서 평균적으로 이만큼"으로 읽을 수 있다
- z점수가 분포 모양을 바꾸지 않는다는 것을 안다
