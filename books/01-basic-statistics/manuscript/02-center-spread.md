## 대표값과 산포를 함께 보아야 하는 이유

자료를 하나의 숫자로 축약하면 중요한 정보가 소실됩니다.

두 학급의 시험 평균이 모두 70점이라고 가정합니다. 한 학급은 68~72점 구간에 밀집해 있고 다른 학급은 30점부터 100점까지 분포합니다. 평균만으로는 두 학급이 동일하지만, 교수자가 취해야 할 조치는 전혀 다릅니다.

따라서 자료를 요약할 때는 두 가지를 함께 제시합니다.

- **대표값** — 분포의 중심이 어디인가 (평균, 중앙값, 최빈값)
- **산포도** — 값들이 얼마나 흩어져 있는가 (분산, 표준편차)

논문의 기술통계표에 *M*과 *SD*가 항상 병기되는 것은 이 때문입니다. 어느 하나만으로는 분포를 설명할 수 없습니다.

## 세 가지 대표값

| 대표값 | 정의 | 중심의 의미 |
| --- | --- | --- |
| **평균**(mean) | 모든 값의 합을 사례 수로 나눈 값 | 무게중심 |
| **중앙값**(median) | 크기순 배열에서 50번째 백분위수 | 순위상 중앙 |
| **최빈값**(mode) | 가장 빈번하게 관측된 값 | 최다 빈도 |

분포가 좌우 대칭이면 세 값은 거의 일치합니다. 차이가 드러나는 것은 편포된 자료입니다.

!fig[**그림 2-1** 정적편포에서 세 대표값은 서로 다른 지점을 가리킨다. (개념도)](ch02-three-centers.svg)

```r 예시 자료
y <- c(1, 1, 1, 2, 3, 4, 6, 8, 9, 9, 11)

c(합 = sum(y), 평균 = mean(y), 중앙값 = median(y))
```

```out
    합   평균 중앙값
    55      5      4
```

평균은 5, 중앙값은 4, 최빈값은 1로 세 값이 모두 다릅니다.

:::key 평균의 민감성
평균은 모든 관측값을 계산에 사용하므로 극단값의 영향을 직접 받습니다. 위 자료에서 11을 100으로 치환하면 평균은 5에서 13.1로 이동하지만 중앙값은 4로 유지됩니다.

소득, 재산, 반응시간과 같이 한쪽으로 길게 늘어지는 변수에서는 중앙값이 분포를 더 적절히 대표합니다. 소득 통계에서 평균소득과 중위소득을 구분해 제시하는 이유가 여기에 있습니다.
:::

:::paper 논문에서 평균을 사용하는 이유
중앙값이 분포를 더 잘 대표하는 경우에도 논문에서는 평균을 보고하는 것이 일반적입니다. t-검정, 분산분석, 회귀분석이 모두 평균을 비교 대상으로 삼는 분석이기 때문입니다.

다만 분포의 편포가 심각한 경우에는 ① 로그 변환 등으로 분포를 조정하거나 ② 비모수 검정(Mann-Whitney U 검정 등)으로 전환하는 방안을 검토해야 합니다. 심사에서 지적되는 대표적 항목입니다.
:::

## 산포 측정의 네 단계

산포를 측정하는 공식은 네 단계를 거쳐 완성되었습니다. **각 단계는 직전 단계에서 발생한 문제를 해소하기 위해 도입된 것**이며, 그 맥락을 이해하면 공식을 암기할 필요가 없습니다.

### 1단계 — 편차

산포 측정의 출발점은 각 관측값이 평균에서 벗어난 정도입니다. 이를 **편차(deviation)**라 합니다.

$$
\text{편차} = X - M
$$

사례가 100개면 편차도 100개이므로, 이를 하나의 지표로 축약하려면 합산해야 합니다. 그러나 이 방식은 성립하지 않습니다.

!fig[**그림 2-2** 자료 7, 3, 5, 4, 2, 3의 편차. 평균 위쪽의 양의 편차와 아래쪽의 음의 편차가 상쇄되어 합이 0이 된다.](ch02-deviation.svg)

```r 편차의 합
x <- c(7, 3, 5, 4, 2, 3)

x - mean(x)          # 편차
sum(x - mean(x))     # 편차의 합
```

```out
[1]  3 -1  1  0 -2 -1
[1] 0
```

**편차의 합은 항상 0입니다.** 이는 우연이 아니라 평균의 정의에서 따라 나오는 결과입니다. 평균은 편차의 합이 0이 되는 지점으로 정의되며, 무게중심이라는 표현이 여기서 유래합니다.

따라서 편차를 단순 합산해서는 산포를 측정할 수 없으며, 부호를 제거하는 절차가 필요합니다.

### 2단계 — 제곱

부호를 제거하는 방법은 절댓값과 제곱 두 가지입니다.

!fig[**그림 2-3** 절댓값은 모든 편차를 동일한 비중으로 반영하지만, 제곱은 큰 편차에 더 큰 비중을 부여한다. (개념도)](ch02-why-square.svg)

통계학은 제곱을 채택했으며, 근거는 두 가지입니다.

첫째, **큰 편차에 더 큰 비중을 부여하기 위해서**입니다. 평균에서 4만큼 떨어진 값은 1만큼 떨어진 값의 4배가 아니라 16배로 계산됩니다. 산포를 평가할 때 극단값의 기여를 크게 반영하는 관점입니다.

둘째, **수리적으로 다루기 쉽기 때문**입니다. 절댓값 함수는 미분 불가능한 지점이 존재하지만 제곱 함수는 전 구간에서 미분 가능합니다. 이후의 추정 이론이 이 성질 위에 구축됩니다.

편차를 제곱하여 합산한 값을 **제곱합(Sum of Squares, SS)**이라 합니다.

$$
SS = \sum (X - M)^2
$$

:::key 제곱합은 이 책 전체를 관통합니다
제곱합은 산포 측정에 국한된 개념이 아닙니다. 분산분석은 전체 제곱합을 집단 간 제곱합과 집단 내 제곱합으로 분할하는 절차이며(9장), 회귀분석의 결정계수 역시 제곱합의 비율로 정의됩니다(2권).

"산포를 제곱합으로 측정한다"는 하나의 약속이 이후 대부분의 분석 논리를 규정합니다.
:::

### 3단계 — 사례 수로 나누기

제곱합에는 한 가지 문제가 남습니다. **사례가 많을수록 값이 커지므로** 사례 수가 다른 자료 간 비교가 불가능합니다.

이를 해소하기 위해 사례 수로 나누어 사례당 평균 산포로 환산합니다. 이 값이 **분산(variance)**입니다.

$$
s^2 = \frac{SS}{n-1} = \frac{\sum (X - M)^2}{n-1}
$$

### 4단계 — 제곱근

분산은 단위가 제곱이라는 한계가 있습니다. 점수의 분산은 점수를 제곱한 단위이므로 직접 해석하기 어렵습니다.

제곱근을 취해 원래 단위로 환원한 값이 **표준편차(standard deviation)**입니다.

$$
s = \sqrt{s^2}
$$

!fig[**그림 2-4** 편차에서 표준편차까지. 각 단계는 직전 단계의 한계를 해소한다.](ch02-ss-flow.svg)

```r 네 단계를 한 번에 확인
x <- c(7, 3, 5, 4, 2, 3)

c(SS = sum((x - mean(x))^2),
  분산 = var(x),
  표준편차 = sd(x))
```

```out
      SS     분산 표준편차
16.00000  3.20000  1.78885
```

표준편차 1.79는 **각 관측값이 평균 4에서 평균적으로 1.79만큼 떨어져 있다**는 의미이며, 자료와 동일한 단위를 가지므로 직접 해석할 수 있습니다.

## 자유도 — n−1로 나누는 근거

사례당 평균 산포를 구한다면 사례 수 *n*으로 나누어야 할 것처럼 보이지만, 실제로는 *n*−1로 나눕니다. 근거는 **표본이 모집단보다 산포가 작게 관측되기 때문**입니다.

!fig[**그림 2-5** 표본추출 과정에서 중심부의 빈번한 값은 잘 포착되지만 양극단의 희소한 값은 누락되기 쉽다. (개념도)](ch02-n-minus-1.svg)

모집단에서 표본을 추출할 때 중심부의 빈번한 값은 잘 포착되는 반면 양극단의 희소한 값은 누락될 가능성이 높습니다. 그 결과 표본으로 계산한 분산은 모분산보다 작게 산출되며, 이를 **과소추정(underestimation)**이라 합니다.

*n* 대신 그보다 작은 *n*−1로 나누면 값이 증가하며, 이 보정이 과소추정을 상쇄합니다.

```r 두 방식의 비교
x  <- c(7, 3, 5, 4, 2, 3)
SS <- sum((x - mean(x))^2)

c(n으로_나눔 = SS / length(x),
  n에서1뺌 = SS / (length(x) - 1))
```

```out
n으로_나눔  n에서1뺌
  2.666667  3.200000
```

:::key 자유도의 의미
*n*−1을 **자유도(degrees of freedom, df)**라 합니다.

평균이 4로 고정된 6개의 값을 생각해 보면, 앞의 다섯 값은 임의로 정할 수 있으나 마지막 값은 평균을 4로 맞추기 위해 자동으로 결정됩니다. 자유롭게 변할 수 있는 값이 5개라는 뜻입니다.

자유도는 이후 모든 검정에서 등장합니다. t-검정의 `df = 238`, 분산분석의 `df = 2, 27` 등이 모두 동일한 개념이며, **제약을 받지 않고 변할 수 있는 값의 개수**로 해석하면 됩니다.
:::

:::warn R의 `var()`와 `sd()`는 표본 기준입니다
R의 `var()`와 `sd()`는 *n*−1을 분모로 사용하는 표본 분산·표본 표준편차를 반환합니다. SPSS도 동일합니다. 논문에서 다루는 자료는 대부분 표본이므로 이것이 적절한 선택입니다.

모집단 전체를 확보한 경우에만 *n*을 분모로 사용해야 하며, 이때는 별도로 계산해야 합니다.
:::

## 표준편차의 해석

표준편차는 계산 결과에 그치지 않고 **특정 값이 흔한지 드문지를 판단하는 기준**으로 기능합니다.

!fig[**그림 2-6** 정규분포에서 평균 ±1 표준편차 구간에 약 68%, ±2 구간에 약 95%가 포함된다.](ch02-sd-meaning.svg)

이른바 68–95–99.7 규칙을 적용하면 다음과 같은 판단이 즉시 가능합니다.

- 평균 70, 표준편차 5인 시험에서 85점은 평균보다 3 표준편차 높으므로 상위 0.1% 수준
- 평균 3.5, 표준편차 0.8인 자아존중감에서 4.3점은 1 표준편차 높으므로 상위 16% 수준

:::key 유의수준 .05의 기원
평균에서 2 표준편차 이상 떨어진 값이 전체의 약 5%라는 사실에 주목할 필요가 있습니다. 5장에서 다루는 **유의수준 .05가 정확히 이 지점에서 설정**됩니다. 우연으로 보기 어려운 경계를 어디에 둘 것인가의 문제입니다.
:::

## 표준점수 — 척도가 다른 값의 비교

수학에서 72.8점, 영어에서 94점을 얻었을 때 어느 과목의 성취가 더 높은지는 원점수만으로 판단할 수 없습니다. 두 시험의 난이도와 점수 분포가 다르기 때문입니다.

필요한 것은 **각 분포 내에서의 상대적 위치**이며, 편차를 표준편차로 나누면 이를 얻을 수 있습니다. 이 값이 **표준점수(z-score)**입니다.

$$
z = \frac{X - M}{s}
$$

!fig[**그림 2-7** 원점수로는 영어가 21점 높으나, 각 분포 내 상대적 위치로 환산하면 수학이 앞선다.](ch02-zscore.svg)

```r 두 과목의 비교
z_math <- (72.8 - 70) / 5     # 수학: 평균 70, 표준편차 5
z_eng  <- (94   - 90) / 8     # 영어: 평균 90, 표준편차 8

c(수학 = z_math, 영어 = z_eng)
```

```out
수학 영어
0.56 0.50
```

원점수는 영어가 21점 높지만 상대적 위치는 수학이 앞섭니다.

표준점수로 변환하면 모든 자료가 **평균 0, 표준편차 1**인 분포에 놓이며 단위가 소거되므로, 척도가 상이한 변수 간 비교가 가능해집니다.

:::warn 표준화는 분포의 형태를 바꾸지 않습니다
빈번한 오해입니다. z 변환은 **선형변환**이므로 분포의 위치와 척도만 조정하며 형태는 그대로 유지됩니다. 편포된 자료를 표준화해도 편포는 해소되지 않습니다.

분포의 형태를 조정하려면 로그 변환과 같은 비선형 변환이 필요합니다.
:::

:::paper 표준점수의 활용
① 척도가 다른 변수를 동일 모형에 투입할 때(회귀분석의 표준화 계수 β), ② 이상치를 판별할 때(통상 |z| > 3), ③ 복수의 검사 점수를 합산할 때 사용합니다.

R에서는 `scale()` 함수로 처리합니다. `df$z_selfesteem <- scale(df$selfesteem)`
:::

## 예제 자료의 기술통계

```r 이 책의 예제 데이터
df <- read.csv("data/sample_data.csv")
s  <- df$selfesteem

c(n = length(s), M = mean(s), SD = sd(s),
  중앙값 = median(s), 최소 = min(s), 최대 = max(s))
```

```out
        n         M        SD    중앙값      최소      최대
240.00000   3.49700   0.83400   3.50000   1.19000   5.00000
```

평균 3.50과 중앙값 3.50이 거의 일치합니다. 이는 **분포가 크게 편포되지 않았음**을 시사하며, 평균이 자료를 적절히 대표한다는 근거가 됩니다. 7장에서 이 변수로 t-검정을 할 때 정규성 가정을 크게 우려하지 않아도 되는 이유가 여기에 있습니다.

:::check 점검 항목
- 대표값과 산포를 함께 제시해야 하는 이유를 설명할 수 있다
- 편차의 합이 0이 되는 이유를 평균의 정의로 설명할 수 있다
- 절댓값이 아니라 제곱을 채택한 두 가지 근거를 안다
- *n*−1로 나누는 근거를 과소추정으로 설명할 수 있다
- 표준편차를 "평균에서 평균적으로 이만큼"으로 해석할 수 있다
- 표준화가 분포의 형태를 바꾸지 않는다는 점을 안다
