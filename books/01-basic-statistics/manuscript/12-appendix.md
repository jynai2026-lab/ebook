## 분석 선택 흐름도

1장의 흐름도를 1권에서 다룬 내용 전체로 확장한 것입니다. 분석 방법을 정하지 못할 때는 **종속변수의 척도**부터 확인하십시오.

!fig[**그림 12-1** 1권 전체를 하나로 묶은 분석 선택 흐름도. 종속변수의 척도, 독립변수의 성격, 집단 수, 독립성 여부 순으로 내려가면 분석이 하나로 정해진다.](ch12-flowchart.svg)

판단 순서는 네 단계입니다.

**① 종속변수가 연속형인가 범주형인가** — 연속형이면 평균 비교, 범주형이면 빈도 비교입니다.
**② 독립변수가 범주형인가 연속형인가** — 범주형이면 집단 비교, 연속형이면 관계 분석(2권)입니다.
**③ 집단이 몇 개인가** — 둘이면 $t$-검정, 셋 이상이면 분산분석입니다.
**④ 집단이 서로 독립인가** — 같은 대상을 반복 측정했다면 종속표본 계열입니다.

## 전체 분석 비교표

| 분석 | 종속변수 | 독립변수 | 검정통계량 | 자유도 | 효과크기 | 장 |
| --- | --- | --- | --- | --- | --- | --- |
| 단일표본 $t$ | 연속형 | 없음 (기준값과 비교) | $t$ | $n-1$ | Cohen's $d$ | 6장 |
| 독립표본 $t$ | 연속형 | 범주형 2집단 (독립) | $t$ | $n_1+n_2-2$ | Cohen's $d$ | 7장 |
| 종속표본 $t$ | 연속형 | 범주형 2시점 (대응) | $t$ | 쌍 수 $-1$ | Cohen's $d$ | 8장 |
| 일원분산분석 | 연속형 | 범주형 3집단 이상 | $F$ | $a-1$, $N-a$ | $\eta^2$, $\omega^2$ | 9장 |
| 이원분산분석 | 연속형 | 범주형 2개 요인 | $F$ ×3 | 요인별 | 부분 $\eta^2$ | 11장 |
{.apa}

각 분석이 확인하는 가정입니다.

| 분석 | 독립성 | 정규성 | 등분산성 | 비고 |
| --- | --- | --- | --- | --- |
| 독립표본 $t$ | 설계로 확인 | 각 집단 | Levene | 깨지면 Welch |
| 종속표본 $t$ | **차이점수**의 독립성 | 차이점수 | 해당 없음 | 두 점수의 상관 보고 |
| 일원분산분석 | 설계로 확인 | 각 집단 | Levene | 깨지면 Welch's $F$ |
| 이원분산분석 | 설계로 확인 | 각 셀 | **셀 단위** Levene | 셀 크기 다르면 제3유형 |
{.apa}

## R 코드 모음

### 자료 준비

```r 분석을 시작할 때 반복되는 절차
df <- read.csv("data.csv")                  # CSV는 UTF-8로 저장
str(df)                                     # 척도가 의도대로 잡혔는지 먼저 확인
summary(df)                                 # 이상값·결측 훑어보기

df$gender <- factor(df$gender,              # 범주형은 반드시 factor로
                    levels = c(1, 2),
                    labels = c("남성", "여성"))

colSums(is.na(df))                          # 변수별 결측 개수
df <- na.omit(df)                           # 결측 제거 (필요할 때만)
```

### 기술통계

```r 기술통계
library(psych)

describe(df$selfesteem)                     # n, M, SD, 왜도, 첨도 한 번에
describeBy(df$selfesteem, df$gender)        # 집단별로

# 집단별 n / M / SD 만 간단히
round(sapply(split(df$selfesteem, df$gender),
             function(x) c(n = length(x), M = mean(x), SD = sd(x))), 2)
```

### 가정 검정

```r 정규성과 등분산성
library(car)

shapiro.test(df$selfesteem)                 # 정규성 (n이 크면 참고용)
hist(df$selfesteem)                         # 눈으로도 반드시 확인
qqnorm(df$selfesteem); qqline(df$selfesteem)

leveneTest(selfesteem ~ gender, data = df)  # 등분산성 (SPSS와 동일)
leveneTest(score ~ gender * school, data = tw)   # 이원분산분석은 셀 단위
```

### 평균 비교

```r 네 가지 t-검정과 분산분석
# 단일표본
t.test(df$selfesteem, mu = 3.0)

# 독립표본 (등분산 가정 충족)
t.test(selfesteem ~ gender, data = df, var.equal = TRUE)

# 독립표본 (등분산 가정 위배 → Welch)
t.test(selfesteem ~ gender, data = df, var.equal = FALSE)

# 종속표본
t.test(pp$post, pp$pre, paired = TRUE)

# 일원분산분석
fit <- aov(score ~ method, data = tc)
summary(fit)

# 이원분산분석
m <- aov(score ~ gender * school, data = tw)
summary(m)
```

### 사후검정

```r 다중비교
TukeyHSD(fit)                                          # 기본 선택지
pairwise.t.test(tc$score, tc$method, "bonferroni")     # Bonferroni
pairwise.t.test(tc$score, tc$method, "holm")           # Holm (권장)
pairwise.t.test(tc$score, tc$method, "none")           # LSD (집단 3개일 때만)
```

### 효과크기

```r 효과크기
library(effectsize)

cohens_d(selfesteem ~ gender, data = df)     # 독립표본
cohens_d(pp$post, pp$pre, paired = TRUE)     # 종속표본
eta_squared(fit)                             # 일원분산분석
omega_squared(fit)                           # 보정된 값
eta_squared(m, partial = TRUE)               # 이원분산분석
```

### 검정력과 표본크기

```r 자료를 모으기 전에 계산합니다
power.t.test(n = 30, delta = 0.5, sd = 1, sig.level = .05)      # 검정력
power.t.test(delta = 0.5, sd = 1, sig.level = .05, power = .80) # 필요 표본
```

## APA 보고 문장 템플릿

빈칸을 채우면 그대로 쓸 수 있는 형태입니다. 기울임체 표기와 소수점 자리수를 그대로 유지하십시오.

:::paper 독립표본 t-검정
> ○○에 따른 □□의 차이를 검증하기 위해 독립표본 *t*-검정을 실시하였다. 등분산성 검정 결과 Levene의 *F*(__, __) = __, *p* = .___으로 등분산 가정이 충족되어 Student *t*-검정을 적용하였다.
>
> 분석 결과, ○○집단의 □□(*M* = __, *SD* = __)이 △△집단(*M* = __, *SD* = __)보다 통계적으로 유의하게 높은 것으로 나타났다(*t*(__) = __, *p* = .___). 효과크기는 Cohen's *d* = __로 □□ 수준이었다.
:::

:::paper 종속표본 t-검정
> ○○의 효과를 검증하기 위해 사전-사후 점수에 대해 종속표본 *t*-검정을 실시하였다. 두 시점의 점수는 *r* = .__의 상관을 보였다.
>
> 분석 결과, 사후 점수(*M* = __, *SD* = __)가 사전 점수(*M* = __, *SD* = __)보다 통계적으로 유의하게 높았다(*t*(__) = __, *p* = .___). 평균 향상 폭은 __점이었으며 95% 신뢰구간은 [__, __]이었다. 효과크기는 Cohen's *d* = __로 □□ 수준이었다.
:::

:::paper 일원분산분석과 사후검정
> ○○에 따른 □□의 차이를 검증하기 위해 일원분산분석을 실시하였다. 등분산성 검정 결과 Levene의 *F*(__, __) = __, *p* = .___으로 가정이 충족되었다.
>
> 분석 결과 집단 간 차이는 통계적으로 유의하였다(*F*(__, __) = __, *p* = .___). 효과크기는 $\eta^2$ = .__였다.
>
> 어느 집단 간에 차이가 있는지 확인하기 위해 Tukey HSD를 이용한 사후검정을 실시한 결과, ○○집단(*M* = __)이 △△집단(*M* = __)보다 유의하게 높았으며(*p* = .___), □□집단과 △△집단 간에는 유의한 차이가 없었다(*p* = .___).
:::

:::paper 이원분산분석
> ○○과 △△가 □□에 미치는 영향을 검증하기 위해 이원분산분석을 실시하였다. 등분산성 검정 결과 Levene의 *F*(__, __) = __, *p* = .___으로 가정이 충족되었다.
>
> 분석 결과 ○○과 △△의 상호작용효과가 통계적으로 유의하였다(*F*(__, __) = __, *p* = .___, $\eta_p^2$ = .__). △△의 주효과도 유의하였으나(*F*(__, __) = __, *p* = .___), ○○의 주효과는 유의하지 않았다(*F*(__, __) = __, *p* = .___).
>
> 상호작용이 유의하여 단순주효과 분석을 실시한 결과, [수준별 결과를 서술한다].
:::

:::paper 유의하지 않은 결과
> 분석 결과 두 집단 간 차이는 통계적으로 유의하지 않았다(*t*(__) = __, *p* = .___). 효과크기는 Cohen's *d* = __로 작은 수준이었다.

유의하지 않은 결과에도 **효과크기를 함께 보고**합니다. "차이가 없었다"가 아니라 **"유의한 차이가 나타나지 않았다"**로 씁니다. 기각 실패는 영가설의 증명이 아니기 때문입니다.
:::

## 표기 규칙

| 항목 | 올바른 표기 | 잘못된 표기 |
| --- | --- | --- |
| 유의확률이 매우 작을 때 | *p* < .001 | *p* = .000 |
| 유의확률 일반 | *p* = .034 | *p* = 0.034 |
| 통계 기호 | *t*, *F*, *p*, *M*, *SD*, *n* (기울임) | t, F, p (정자) |
| 그리스 문자 | $\eta^2$, $\alpha$, $\beta$ (정자) | 기울임 |
| 신뢰구간 | 95% CI [0.30, 0.58] | 95% CI (0.30~0.58) |
| 자유도 | *t*(238) = −3.93 | *t* = −3.93 (*df* = 238) |
| 소수점 앞 0 | .05 (1을 넘을 수 없는 값) | 0.05 |
| 소수점 앞 0 | 3.93 (1을 넘을 수 있는 값) | .93 |
{.apa}

유의확률·상관계수·효과크기 비율처럼 **1을 넘을 수 없는 값은 소수점 앞의 0을 생략**합니다. $t$값이나 $F$값처럼 1을 넘을 수 있는 값은 그대로 적습니다.

## 자주 마주치는 오류 메시지

| 메시지 | 원인 | 해결 |
| --- | --- | --- |
| `object 'df' not found` | 객체를 만들지 않았거나 오타 | `ls()`로 확인 |
| `undefined columns selected` | 변수명 오타 | `names(df)`로 확인 |
| `grouping factor must have exactly 2 levels` | 집단이 2개가 아닌데 `t.test` 사용 | `aov()`로 변경 |
| `not enough 'x' observations` | 사례 수 부족 또는 결측 과다 | `table()`, `colSums(is.na(df))` |
| `there is no package called 'car'` | 패키지 미설치 | `install.packages("car")` |
| `could not find function "leveneTest"` | `library()` 누락 | `library(car)` 실행 |
| 한글이 깨져 보임 | 인코딩 불일치 | CSV를 **UTF-8**로 다시 저장 |
| 평균이 1.47처럼 나옴 | 범주형을 숫자로 처리 | `factor()`로 변환 |
{.apa}

:::warn 오류가 나지 않는데 결과가 이상한 경우
가장 찾기 어려운 상황입니다. **오류 메시지 없이 틀린 결과가 나오는** 경우는 대개 셋 중 하나입니다.

**① 척도 지정 누락** — 범주형 변수를 `factor()`로 변환하지 않았습니다. `str(df)`로 확인합니다.

**② 결측 처리 차이** — R의 기본 동작은 함수마다 다릅니다. `mean()`은 결측이 있으면 `NA`를 돌려주고, `t.test()`는 해당 사례를 제외하고 계산합니다. 분석 전에 결측을 어떻게 처리할지 정해두어야 합니다.

**③ 자료 형태 불일치** — 종속표본 $t$-검정은 넓은 형태(한 행에 두 시점), 분산분석은 긴 형태(집단 열 + 점수 열)를 요구합니다.
:::

## 자료 정리 점검표

분석에 들어가기 전에 확인할 항목입니다.

:::check 자료 구조
- 1행에 변수명, 1인당 1행 구조인가
- 변수명에 공백이나 특수문자가 없는가 (`self_esteem` 형태 권장)
- CSV를 **UTF-8**로 저장했는가
- 결측이 빈칸 또는 `NA`로 되어 있는가 (99, 999 같은 코드값이 남아 있지 않은가)
:::

:::check 변수 설정
- 범주형 변수를 모두 `factor()`로 변환했는가
- `str(df)`로 각 변수의 척도를 확인했는가
- 역채점 문항을 처리했는가
- 합산 또는 평균 변수를 만들었는가
:::

:::check 분석 전
- 종속변수의 왜도와 첨도를 확인했는가
- 히스토그램을 그려 보았는가
- 집단별 사례 수를 `table()`로 확인했는가
- 극단값이 입력 오류인지 실제 값인지 판단했는가
:::

:::check 보고
- 효과크기를 함께 산출했는가
- 가정 검정 결과를 기록했는가
- `p = .000`이 아니라 `p < .001`로 적었는가
- 유의하지 않은 결과도 빠짐없이 보고했는가
:::

## 다음 권 안내

1권에서는 **집단 간 차이**를 다뤘습니다. 남성과 여성, 처치집단과 통제집단, 세 가지 교수법. 모두 집단을 하나의 평균으로 축약해 그 거리를 재는 분석이었습니다.

7장에서 구분했던 두 번째 유형의 질문, **변수 간 관계**는 다루지 않았습니다. 그쪽이 2권의 주제입니다.

| 권 | 다루는 내용 | 1권과의 연결 |
| --- | --- | --- |
| **2권 회귀분석** | 상관, 단순·다중회귀, 더미변수, 매개·조절효과 | $\eta^2$이 $R^2$으로, 집단 비교가 더미변수로 |
| **3권 요인분석** | 탐색적·확인적 요인분석, 신뢰도와 타당도 | 여러 문항을 하나의 변수로 묶는 근거 |
| **4권 구조방정식** | 측정모형, 구조모형, 적합도 지수 | 2권과 3권을 하나의 모형으로 |

1권에서 익힌 것 가운데 이후 계속 쓰이는 것은 **① 유의확률을 읽는 법 ② 가정을 확인하는 습관 ③ 효과크기를 함께 보는 시각 ④ 출력을 결과표와 문장으로 옮기는 절차**입니다. 분석 기법은 바뀌어도 이 넷은 그대로입니다.

:::key 2권에서 이어지는 지점
**9장의 $\eta^2$** — 회귀분석의 $R^2$과 같은 개념입니다. 설명된 분산의 비율이라는 점에서 동일하며, 독립변수가 질적이냐 양적이냐만 다릅니다.

**7장의 집단 비교** — 집단변수를 0과 1의 더미변수로 바꾸면 회귀분석으로 같은 결과를 얻습니다. $t$-검정은 독립변수가 하나인 회귀분석의 특수한 경우입니다.

**11장의 상호작용** — 회귀분석에서는 조절효과(moderation)라는 이름으로 등장합니다. 두 변수를 곱해 모형에 넣는 것까지 발상이 같습니다.

**분산분석과 회귀분석은 사실 같은 모형입니다.** 2권에서 이 연결을 다룹니다.
