## 왜 하필 영가설을 세우는가

연구자가 확인하고 싶은 것은 대체로 "효과가 있다"입니다. 그런데 통계적 검정은 그 반대 명제, 즉 **"효과가 없다"에서 출발합니다.** 이 구조가 처음에는 납득되지 않습니다.

이유는 간단합니다. **효과가 있다는 명제로는 계산을 시작할 수 없기 때문입니다.**

"프로그램에 효과가 있다"는 진술을 생각해 보십시오. 효과가 3점일 수도, 5점일 수도, 0.7점일 수도 있습니다. 가능한 경우가 무수히 많으므로 어떤 분포를 그려야 할지 정할 수 없습니다.

반면 "효과가 없다"는 진술은 **하나의 값으로 확정됩니다.** 차이가 정확히 0이라는 뜻입니다. 값이 하나로 정해지면 그 값을 중심으로 분포를 그릴 수 있고, 분포를 그릴 수 있으면 확률을 계산할 수 있습니다.

:::key 영가설과 대립가설
**영가설(null hypothesis, $H_0$)** — 검정의 대상이 되는 명제입니다. 보통 "차이가 없다", "관계가 없다"의 형태이며, **연구자는 대체로 이것이 기각되기를 기대합니다.**

**대립가설(alternative hypothesis, $H_1$)** — 영가설이 기각되었을 때 채택되는 명제입니다. 보통 연구자가 주장하려는 내용입니다.

두 가설은 연구자의 선호로 정해지는 것이 아니라 **계산 가능성으로 정해집니다.** 값이 하나로 확정되는 쪽이 영가설이 됩니다.
:::

집단상담 프로그램의 효과를 검증하는 연구라면 가설은 이렇게 설정됩니다.

$$
H_0 : \mu_{\text{처치}} - \mu_{\text{통제}} = 0 \qquad H_1 : \mu_{\text{처치}} - \mu_{\text{통제}} \neq 0
$$ (영가설만 하나의 값으로 확정됩니다)

!fig[**그림 5-1** 영가설은 값이 0 하나로 정해지므로 분포를 그릴 수 있다. 대립가설은 가능한 값이 무수히 많아 분포를 특정할 수 없다. (개념도)](ch05-why-null.svg)

## 유의확률이 실제로 재는 것

유의확률은 오해가 가장 잦은 개념입니다. 먼저 정확한 정의부터 확인합니다.

> **유의확률(p-value)** — 영가설이 참이라고 가정했을 때, 지금 얻은 검정통계량만큼 극단적이거나 그보다 더 극단적인 값이 나올 확률.

정의에서 확인해야 할 지점이 세 군데입니다.

**"영가설이 참이라고 가정했을 때"** — 유의확률은 조건부 확률입니다. 영가설이 참이라는 전제 위에서만 계산됩니다.

**"지금 얻은 값만큼 극단적이거나 그보다 더 극단적인"** — 특정 지점의 확률이 아니라 **꼬리 쪽 면적 전체**입니다. 연속확률분포에서 어느 한 점의 확률은 0이므로 면적으로 계산할 수밖에 없습니다.

**"나올 확률"** — 확률이므로 0 이상 1 이하입니다.

!fig[**그림 5-2** 유의확률은 영가설 분포에서 내 결과보다 바깥쪽에 있는 면적이다. 점이 아니라 면적이다. (개념도)](ch05-pvalue.svg)

:::warn 유의확률은 영가설이 참일 확률이 아닙니다
가장 빈번한 오해입니다. $p = .03$은 **영가설이 참일 확률이 3%**라는 뜻이 아닙니다.

유의확률은 **영가설이 참이라고 가정한 상태에서** 계산된 값입니다. 전제로 깔아둔 것의 확률을 결과로 돌려줄 수는 없습니다.

정확한 해석은 이것입니다. "영가설이 참이라면, 이만한 결과가 나올 일은 100번 중 3번뿐이다. 그렇게 드문 일이 지금 일어났다고 보기보다는, 애초에 전제가 틀렸다고 보는 편이 자연스럽다."
:::

이 논리를 순서대로 정리하면 다음과 같습니다.

1. 영가설이 참이라고 가정한다
2. 그 가정 위에서 검정통계량의 분포를 그린다
3. 실제로 얻은 검정통계량이 그 분포의 어디에 있는지 확인한다
4. 너무 바깥쪽이면 — 이만한 값이 나올 확률이 너무 작으면 — **가정 자체를 의심한다**
5. 따라서 영가설을 기각한다

!fig[**그림 5-3** 가설검정의 다섯 단계. 대립가설을 증명하는 절차가 아니라 영가설을 소거하는 절차다. (개념도)](ch05-logic-steps.svg)

**증명이 아니라 소거법입니다.** 영가설로는 설명이 어려우니 다른 설명을 찾겠다는 것이지, 대립가설이 참임을 보인 것이 아닙니다.

:::key p = .000은 존재하지 않습니다
SPSS가 유의확률을 `.000`으로 표시하는 경우가 있습니다. 소수 넷째 자리에서 반올림한 표기일 뿐 확률이 0이라는 뜻이 아닙니다.

연속확률분포는 음의 무한대에서 양의 무한대까지 정의되므로 **어떤 값이든 나올 수 있습니다.** 확률이 정확히 0인 사건은 없습니다.

논문에는 반드시 **$p < .001$**로 기술합니다. R은 애초에 `p-value < 2.2e-16`처럼 표기하여 이 혼동을 방지합니다.
:::

## 유의수준 — 기준선은 연구자가 정합니다

유의확률을 계산했으면 기각 여부를 판단할 기준이 필요합니다. 이 기준을 **유의수준(significance level, $\alpha$)**이라 합니다.

사회과학에서는 관행적으로 .05를 사용하지만, **이 값은 수학적으로 도출된 것이 아니라 연구자가 설정하는 것입니다.** 판단이 틀렸을 때의 손실이 클수록 더 엄격한 기준을 적용해야 합니다.

| 유의수준 | 적용 상황 |
| --- | --- |
| .10 | 탐색적 연구, 선행연구가 거의 없는 영역 |
| **.05** | **사회과학의 일반적 기준** |
| .01 | 오판의 손실이 큰 경우, 대규모 표본 |
| .001 이하 | 의학·약학의 임상시험, 다중검정 보정 시 |

신약의 효과를 검정하는 상황을 생각해 보십시오. 효과가 없는 약을 효과가 있다고 판단하면 환자가 피해를 입습니다. 이런 경우 .05는 지나치게 느슨합니다.

## 두 종류의 오류

검정의 결론은 참 또는 거짓 둘 중 하나이고 실제 진리도 둘 중 하나이므로, 경우의 수는 네 가지입니다. 이 가운데 둘이 오류입니다.

!fig[**그림 5-4** 진리와 판단을 교차한 네 칸. 대각선 둘은 옳은 판단이고, 나머지 둘이 제1종·제2종 오류다. (개념도)](ch05-error-table.svg)

| | **실제로 $H_0$이 참** | **실제로 $H_1$이 참** |
| --- | --- | --- |
| **$H_0$ 기각 실패** | 옳은 판단 ($1-\alpha$) | **제2종 오류 ($\beta$)** |
| **$H_0$ 기각** | **제1종 오류 ($\alpha$)** | 옳은 판단 = 검정력 ($1-\beta$) |
{.apa}

**제1종 오류($\alpha$)** — 효과가 없는데 있다고 판단하는 오류입니다. 없는 것을 발견했다고 주장하는 셈이므로 **허위 발견**에 해당합니다.

**제2종 오류($\beta$)** — 효과가 있는데 없다고 판단하는 오류입니다. 있는 것을 놓친 것이므로 **탐지 실패**에 해당합니다.

:::key 제1종 오류를 더 심각하게 보는 이유
두 오류 중 어느 쪽이 더 위험한지는 상황에 따라 다르지만, 통계학의 관행은 **제1종 오류를 더 엄격하게 통제합니다.**

없는 효과를 있다고 발표하면 그 주장이 문헌에 남아 후속 연구가 그 위에 쌓입니다. 잘못된 전제 위에 축적된 연구를 되돌리는 데는 훨씬 큰 비용이 듭니다.

반면 있는 효과를 놓치면 발견이 늦어질 뿐 학문적 손실은 회복 가능합니다. 다른 연구자가 다시 확인하면 됩니다.

$\alpha$를 .05로 고정하고 $\beta$는 따로 통제하지 않는 관행은 이 비대칭에서 나왔습니다.
:::

:::warn 두 오류는 동시에 줄일 수 없습니다
$\alpha$를 .05에서 .01로 낮추면 제1종 오류는 줄지만, 기각이 어려워지므로 **제2종 오류는 늘어납니다.** 반대도 마찬가지입니다.

두 오류를 동시에 줄이는 방법은 하나뿐입니다. **표본크기를 늘리는 것**입니다. 이 부분은 이어지는 검정력 절에서 다룹니다.
:::

## 검정력 — 있는 것을 찾아낼 확률

**검정력(power, $1-\beta$)**은 대립가설이 참일 때 영가설을 올바르게 기각할 확률입니다. 즉 **실재하는 효과를 탐지해낼 확률**입니다.

연구자가 실질적으로 관리해야 할 값이 이것입니다. 검정력이 낮으면 아무리 자료를 잘 모아도 효과를 찾아내지 못합니다.

```r 검정력 계산 — 별도 패키지가 필요 없습니다
# 중간 크기 효과(d = 0.5)를 각 집단 30명으로 잡아낼 확률
power.t.test(n = 30, delta = 0.5, sd = 1, sig.level = 0.05)$power
```

```out
[1] 0.4778912
```

**검정력이 .478입니다.** 실제로 중간 크기의 효과가 존재하더라도 절반 이상의 확률로 놓친다는 뜻입니다. 각 집단 30명은 통계 교재에서 흔히 제시되는 최소 기준이지만, 검정력 관점에서는 충분하지 않습니다.

```r 표본크기를 바꿔 가며 확인
for (n in c(20, 30, 50, 64, 100))
  cat(sprintf("각 집단 n=%3d  검정력 = %.3f\n", n,
      power.t.test(n = n, delta = 0.5, sd = 1, sig.level = .05)$power))
```

```out
각 집단 n= 20  검정력 = 0.338
각 집단 n= 30  검정력 = 0.478
각 집단 n= 50  검정력 = 0.697
각 집단 n= 64  검정력 = 0.801
각 집단 n=100  검정력 = 0.940
```

!fig[**그림 5-5** 효과크기를 d = 0.5로 고정하고 표본크기만 바꾼 결과. 통상적인 목표선 .80을 넘으려면 각 집단 64명이 필요하다.](ch05-power-n.svg)

Cohen(1988)이 제시한 관행적 목표는 **검정력 .80**입니다. 필요한 표본크기를 거꾸로 구할 수도 있습니다.

```r 검정력 .80을 확보하려면 몇 명이 필요한가
power.t.test(delta = 0.5, sd = 1, sig.level = 0.05, power = 0.80)
```

```out
     Two-sample t test power calculation 

              n = 63.76576
          delta = 0.5
             sd = 1
      sig.level = 0.05
          power = 0.8
    alternative = two.sided

NOTE: n is number in *each* group
```

**각 집단 64명, 합계 128명**입니다. `NOTE`에 명시된 대로 `n`은 집단당 인원이므로, 이 값을 전체 표본크기로 오독하면 필요 인원의 절반만 모으게 됩니다.

:::key 검정력에 영향을 주는 네 가지
**① 효과크기** — 실제 효과가 클수록 찾기 쉽습니다. 다만 **연구자가 조정할 수 있는 값이 아닙니다.** 자연에 존재하는 크기입니다.

**② 유의수준** — $\alpha$를 키우면 검정력은 올라가지만 제1종 오류도 함께 커집니다. 아래 출력이 그 맞바꿈을 보여줍니다.

**③ 검정 방향** — 일방검정은 양방검정보다 검정력이 높습니다. 그러나 효과의 방향을 사전에 확신할 수 있는 경우가 드물어 실제로는 거의 쓰이지 않습니다.

**④ 표본크기** — **연구자가 학문적 비판 없이 조정할 수 있는 유일한 요인입니다.** $n$이 커지면 표준오차 $s/\sqrt{n}$이 작아지고, 표준오차가 작아지면 같은 크기의 차이도 더 큰 검정통계량으로 환산되어 기각이 쉬워집니다.
:::

```r 유의수준을 바꾸면 (각 집단 n = 30, d = 0.5)
for (a in c(.01, .05, .10))
  cat(sprintf("alpha=%.2f  검정력 = %.3f\n", a,
      power.t.test(n = 30, delta = .5, sd = 1, sig.level = a)$power))
```

```out
alpha=0.01  검정력 = 0.244
alpha=0.05  검정력 = 0.478
alpha=0.10  검정력 = 0.606
```

$\alpha$를 .01로 낮추면 검정력이 .244로 떨어집니다. 제1종 오류를 줄인 대가로 제2종 오류가 커진 것입니다. **두 오류는 이렇게 맞물려 있습니다.**

!fig[**그림 5-6** 영가설 분포와 대립가설 분포가 겹치는 구간에서 α와 β가 결정된다. 기각선을 오른쪽으로 옮기면 α는 줄지만 β는 늘어난다. (개념도)](ch05-alpha-beta.svg)

:::paper 표본크기는 연구계획서에 근거를 써야 합니다
"선행연구를 참고하여 200명을 표집하였다"는 기술로는 충분하지 않은 경우가 늘고 있습니다. 검정력 분석에 근거한 표집이 요구되는 추세입니다.

> 선행연구(○○○, 2021)에서 보고된 효과크기 Cohen's *d* = 0.50을 기준으로, 유의수준 .05, 검정력 .80을 확보하기 위한 표본크기를 산출한 결과 집단당 64명, 총 128명이 필요한 것으로 나타났다. 탈락률 15%를 고려하여 총 150명을 표집하였다.

효과크기의 출처(선행연구 또는 예비조사)를 함께 밝히는 것이 관건입니다.
:::

## 유의하다는 말이 중요하다는 뜻은 아닙니다

검정력 절에서 확인한 대로 표본크기가 커지면 기각이 쉬워집니다. 이 성질에는 대가가 따릅니다. **실질적으로 의미 없는 차이도 표본만 충분하면 유의해집니다.**

100점 만점 능력검사에서 모평균이 30점인 모집단을 가정합니다. 향상 프로그램을 적용한 뒤 평균이 31점, 표준편차가 15로 나왔습니다. **100점 만점에서 1점 차이**입니다.

```r 차이는 그대로 두고 표본크기만 바꿉니다
for (n in c(50, 100, 400, 1000)) {
  z <- (31 - 30) / (15 / sqrt(n))
  cat(sprintf("n=%4d  SE=%.3f  z=%.3f  p=%.4f  d=%.3f\n",
      n, 15/sqrt(n), z, 2*pnorm(-abs(z)), (31-30)/15))
}
```

```out
n=  50  SE=2.121  z=0.471  p=0.6374  d=0.067
n= 100  SE=1.500  z=0.667  p=0.5050  d=0.067
n= 400  SE=0.750  z=1.333  p=0.1824  d=0.067
n=1000  SE=0.474  z=2.108  p=0.0350  d=0.067
```

!fig[**그림 5-7** 평균 차이 1점과 효과크기 0.067은 그대로인데, 표본크기만 바뀌자 p값이 .637에서 .035로 떨어져 결론이 뒤집힌다.](ch05-effect-vs-p.svg)

$n$이 50일 때는 $p = .637$로 기각되지 않지만, $n$이 1,000이 되면 $p = .035$로 기각됩니다. **평균 차이 1점은 처음부터 끝까지 변하지 않았는데** 결론만 뒤집힌 것입니다.

반면 마지막 열의 효과크기 $d$는 네 경우 모두 **0.067로 동일합니다.** 효과크기 공식에는 표본크기가 들어가지 않기 때문입니다.

$$
d = \frac{\bar{X}_t - \mu_c}{\sigma}
$$ (검정통계량에서 $\sqrt{n}$만 제거한 형태입니다)

:::key 효과크기가 하는 일
검정통계량과 효과크기를 나란히 놓으면 차이가 분명해집니다.

$$
z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \qquad\text{vs}\qquad d = \frac{\bar{X} - \mu}{\sigma}
$$ (분모에서 $\sqrt{n}$이 빠진 것이 전부입니다)

검정통계량은 **표본크기의 영향을 받도록** 설계되어 있습니다. 표본이 커질수록 추정이 정밀해지므로, 같은 차이라도 더 확신을 갖고 판단할 수 있어야 하기 때문입니다.

효과크기는 그 $\sqrt{n}$을 제거합니다. 남는 것은 **표준편차 몇 개만큼 떨어져 있는가**라는 순수한 거리입니다. 그래서 표본크기가 달라도, 연구가 달라도 비교할 수 있습니다.
:::

Cohen(1988)의 해석 기준입니다.

| Cohen's $d$ | 해석 |
| --- | --- |
| 0.20 내외 | 작은 효과 |
| 0.50 내외 | 중간 효과 |
| 0.80 이상 | 큰 효과 |

위 예시의 $d = 0.067$은 작은 효과에도 미치지 못합니다. $n = 1{,}000$에서 유의하게 나왔더라도 **실질적 의미는 없다고 보고해야 합니다.**

:::warn 기준표를 절대적으로 적용하지 않습니다
Cohen 본인이 이 기준을 "참고할 것이 전혀 없을 때의 임시 기준"이라고 밝혔습니다. 분야마다 효과크기의 통상 범위가 다릅니다.

교육 개입 연구에서는 $d = 0.3$도 상당한 효과로 평가되는 반면, 실험실 조건의 지각 실험에서는 $d = 0.8$이 평범한 수준일 수 있습니다. **같은 주제를 다룬 선행연구의 효과크기와 비교하는 것**이 기준표보다 유용합니다.
:::

## 결과를 쓸 때

:::paper 유의성과 실질적 의미를 함께 기술합니다
> 분석 결과 두 집단의 평균 차이는 통계적으로 유의하였으나(*t*(998) = 2.11, *p* = .035), 효과크기는 Cohen's *d* = 0.07로 매우 작은 수준이었다. 이는 표본크기가 큰 데 따른 결과로 해석되며, 실질적인 차이로 보기는 어렵다.

유의한 결과가 나왔다고 해서 효과크기 보고를 생략해서는 안 됩니다. **APA 7판은 효과크기 보고를 요구합니다.** 유의하지 않은 결과에도 효과크기를 함께 제시합니다.
:::
