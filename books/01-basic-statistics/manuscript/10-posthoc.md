## 분산분석이 답하지 않은 것

9장에서 $F$(2, 27) = 18.12, $p$ < .001로 영가설을 기각했습니다. 그런데 기각된 영가설이 무엇이었는지 다시 봅시다.

$$
H_0 : \mu_A = \mu_B = \mu_C
$$

이 명제가 거짓이라는 것은 **"셋이 모두 같지는 않다"**는 뜻일 뿐입니다. 가능한 경우가 여럿입니다.

- A만 낮고 B와 C는 같을 수도 있고
- C만 높고 A와 B는 같을 수도 있고
- 셋이 모두 서로 다를 수도 있습니다

논문에 필요한 것은 "차이가 있었다"가 아니라 **"어느 교수법이 어느 교수법보다 효과적이었다"**입니다. 이를 확인하는 추가 절차를 **다중비교(multiple comparison)** 또는 **사후검정(post hoc test)**이라 합니다.

!fig[**그림 10-1** F가 유의하다는 것은 세 평균이 한 줄에 있지 않다는 뜻일 뿐이다. 어떤 배치인지는 별도로 확인해야 한다. (개념도)](ch10-what-f-says.svg)

## 되돌아온 딜레마

확인 방법은 명확합니다. 세 쌍을 각각 비교하면 됩니다. 그런데 **그렇게 하면 9장에서 피하려고 했던 제1종 오류 누적이 그대로 돌아옵니다.**

세 번 비교하면 최소 한 번 잘못 판단할 확률이 .1426이었습니다. 분산분석으로 한 번에 물어서 .05를 지켜놓고, 사후검정에서 다시 .1426으로 풀어버리면 앞의 노력이 무의미해집니다.

:::key 두 종류의 유의수준
문제를 정확히 보려면 유의수준을 두 층으로 나눠야 합니다.

**비교당 유의수준($\alpha^{PC}$, per-comparison)** — 개별 비교 하나에 적용되는 기준입니다.

**군집당 유의수준($\alpha^{FW}$, family-wise)** — **한 연구에서 수행한 비교 전체**를 묶었을 때, 그중 최소 한 번이라도 잘못 판단할 확률입니다.

$$
\alpha^{FW} = 1 - (1 - \alpha^{PC})^{c}
$$ ($c$는 비교 횟수)

연구자가 통제해야 하는 것은 **$\alpha^{FW}$**입니다. 논문의 결론은 개별 비교가 아니라 비교들의 묶음에서 나오기 때문입니다.

다중비교 방법들은 모두 **$\alpha^{FW}$를 .05로 유지하면서 개별 비교를 어떻게 할 것인가**에 대한 서로 다른 답입니다.
:::

!fig[**그림 10-2** 보정하지 않으면 비교를 거듭할수록 군집당 오류가 쌓인다. 보정은 개별 기준을 엄격하게 만들어 전체를 .05에 묶어두는 장치다.](ch10-familywise.svg)

## 네 가지 방법

### Bonferroni 방법

가장 직관적인 해법입니다. **비교 횟수만큼 유의수준을 나눕니다.**

$$
\alpha^{PC} = \frac{\alpha^{FW}}{c}
$$ (세 번 비교한다면 각각을 .05/3 = .0167로)

세 집단을 비교할 때 각 검정을 .0167 수준에서 판단하면, 군집당 오류는 다음과 같이 계산됩니다.

$$
\alpha^{FW} = 1 - \left(1 - \frac{0.05}{3}\right)^{3} = 1 - 0.951 = 0.049
$$ (목표한 .05 안에 들어옵니다)

실제로는 유의수준을 나누는 대신 **유의확률에 비교 횟수를 곱해서** 보고합니다. 결과는 같고 .05 기준을 그대로 쓸 수 있어 편리합니다.

:::warn 비교가 많아지면 지나치게 보수적입니다
Bonferroni는 비교 횟수에 정비례해 기준을 조입니다. 집단이 6개면 비교가 15회이므로 $\alpha^{PC}$가 **.0033**이 됩니다.

이 수준이면 실재하는 차이도 대부분 놓칩니다. 제1종 오류를 막으려다 **제2종 오류를 크게 키우는 것**입니다. 비교가 서너 개를 넘어가면 다른 방법을 고려해야 합니다.
:::

### Fisher의 LSD 방법

유의수준을 아예 보정하지 않고 $t$-검정을 그대로 반복합니다. 대신 **두 조건을 붙입니다.**

**① 분산분석의 $F$검정이 반드시 유의해야 한다.** 유의하지 않으면 사후검정으로 넘어가지 않습니다.
**② 집단이 정확히 셋일 때만 쓸 수 있다.**

두 조건이 지켜지면 보정 없이도 $\alpha^{FW}$가 .05를 넘지 않는다는 것이 알려져 있습니다. **$F$검정이 1차 관문 역할을 하기 때문**입니다.

:::warn 집단이 넷 이상이면 성립하지 않습니다
LSD가 안전한 것은 집단이 셋일 때뿐입니다. 넷 이상에서는 $F$가 유의하더라도 군집당 오류가 .05를 넘습니다.

집단 수를 확인하지 않고 LSD를 쓰는 것이 사후검정에서 가장 흔한 실수입니다. SPSS의 사후분석 창에서 LSD가 목록 맨 위에 있어 무심코 선택되는 경우가 많습니다.
:::

### Tukey HSD

사후검정에서 **가장 널리 쓰이는 방법**입니다. 모든 쌍을 비교하면서 군집당 유의수준을 .05로 유지합니다.

Bonferroni처럼 기계적으로 나누지 않고 **스튜던트화 범위 분포(studentized range distribution)**라는 별도의 분포를 씁니다. 가장 큰 평균과 가장 작은 평균의 차이가 우연히 얼마나 벌어질 수 있는지를 직접 모형화한 분포입니다.

그래서 Bonferroni보다 **덜 보수적이면서도** 군집당 오류를 정확히 통제합니다. 집단 크기가 같을 때 특히 잘 작동합니다.

### Scheffé 방법

**가장 보수적인 방법**입니다. 존재하는 사후검정 중 제1종 오류가 가장 작습니다.

비교의 개수가 **무한히 많다고 가정**하고 설계되었기 때문입니다. 아무리 많은 비교를 해도 $\alpha^{FW}$가 통제되지만, 그만큼 기각이 어렵습니다.

쌍별 비교만 할 것이라면 지나치게 엄격합니다. **"A와 B의 평균을 합친 것과 C를 비교"** 같은 복합 비교까지 자유롭게 하고 싶을 때 쓰는 방법입니다.

| 방법 | 보수성 | 적용 상황 |
| --- | --- | --- |
| Fisher LSD | 가장 느슨함 | 집단 **정확히 3개**, $F$ 유의할 때만 |
| **Tukey HSD** | **중간** | **모든 쌍 비교. 기본 선택지** |
| Bonferroni | 엄격함 | 비교 개수가 적고 미리 정해졌을 때 |
| Scheffé | 가장 엄격함 | 복합 비교를 포함할 때 |
{.apa}

!fig[**그림 10-3** 네 방법을 보수성 축에 놓은 것. 왼쪽으로 갈수록 차이를 잘 찾아내지만 헛발견도 늘고, 오른쪽으로 갈수록 그 반대다. (개념도)](ch10-methods.svg)

## R로 돌리기

9장의 교수법 자료를 그대로 씁니다. $F$(2, 27) = 18.12, $p$ < .001로 이미 유의했으므로 사후검정으로 넘어갈 수 있습니다.

### Tukey HSD

```r aov 결과를 그대로 넘기면 됩니다
fit <- aov(score ~ method, data = tc)
TukeyHSD(fit)
```

```out
  Tukey multiple comparisons of means
    95% family-wise confidence level

Fit: aov(formula = score ~ method, data = tc)

$method
    diff         lwr       upr     p adj
B-A  5.4  1.63010117  9.169899 0.0039568
C-A  9.1  5.33010117 12.869899 0.0000064
C-B  3.7 -0.06989883  7.469899 0.0551655
```

출력을 읽는 법입니다.

| 열 | 의미 |
| --- | --- |
| `diff` | 두 집단의 평균 차이 (뒤 − 앞) |
| `lwr`, `upr` | 그 차이의 **군집당 보정된** 95% 신뢰구간 |
| `p adj` | 보정된 유의확률. 이 값을 .05와 비교 |

결론입니다.

- **B − A = 5.4, $p$ = .004** — B가 A보다 유의하게 높습니다
- **C − A = 9.1, $p$ < .001** — C가 A보다 유의하게 높습니다
- **C − B = 3.7, $p$ = .055** — 차이는 있지만 유의수준에 미치지 못합니다

신뢰구간으로도 같은 판단이 가능합니다. **C−B의 구간 [−0.07, 7.47]만 0을 포함합니다.**

!fig[**그림 10-4** Tukey HSD의 세 신뢰구간. 0을 걸치는 구간이 하나 있고, 그것이 C−B다.](ch10-tukey-ci.svg)

### Bonferroni와 비교

```r p.adjust.method로 방법을 바꿉니다
pairwise.t.test(tc$score, tc$method, p.adjust.method = "bonferroni")
```

```out
	Pairwise comparisons using t tests with pooled SD 

data:  tc$score and tc$method 

  A       B     
B 0.0043  -     
C 6.6e-06 0.0656

P value adjustment method: bonferroni 
```

### 보정하지 않으면

```r 비교를 위해 보정 없이도 돌려봅니다
pairwise.t.test(tc$score, tc$method, p.adjust.method = "none")
```

```out
	Pairwise comparisons using t tests with pooled SD 

data:  tc$score and tc$method 

  A       B     
B 0.0014  -     
C 2.2e-06 0.0219

P value adjustment method: none 
```

## 방법에 따라 결론이 갈리는 지점

세 결과를 나란히 놓으면 이 장에서 가장 중요한 사실이 드러납니다.

| 비교 | 보정 없음 | Tukey HSD | Bonferroni | Holm |
| --- | --- | --- | --- | --- |
| B − A | .0014 | .0040 | .0043 | .0029 |
| C − A | < .001 | < .001 | < .001 | < .001 |
| **C − B** | **.0219** | **.0552** | **.0656** | **.0219** |
{.apa}

*주.* Holm은 `p.adjust.method = "holm"`으로 산출하였다.

!fig[**그림 10-5** 같은 자료에 보정 방법만 바꾼 결과. C−B 한 쌍에서 결론이 갈린다.](ch10-method-compare.svg)

**C−B 한 쌍에서 결론이 갈립니다.** 보정하지 않으면 유의하고($p$ = .022), Tukey와 Bonferroni에서는 유의하지 않습니다($p$ = .055, .066).

:::warn 분석을 마친 뒤에 방법을 고르면 안 됩니다
위 표를 보고 "유의하게 나오는 방법을 쓰면 되겠다"고 판단하는 것은 **자료를 보고 기준을 맞추는 것**입니다. 유의성 낚시(p-hacking)에 해당하며 연구윤리 문제로 이어집니다.

**분석 계획 단계에서 방법을 정하고, 결과가 어떻게 나오든 그대로 보고합니다.** 특별한 사정이 없으면 Tukey HSD를 씁니다.

$p$ = .055처럼 경계에 걸린 결과는 숨기지 말고 있는 그대로 적는 편이 낫습니다. "유의수준에 근접하였으나 통계적으로 유의하지는 않았다"는 서술이 정확하며, 심사에서도 문제 되지 않습니다.
:::

:::key Holm 방법 — 실무에서 쓸 만한 절충안
표의 마지막 열에 있는 Holm(1979) 방법은 Bonferroni를 개선한 것입니다.

Bonferroni가 모든 비교에 같은 기준을 적용하는 반면, Holm은 **유의확률을 작은 순서로 정렬한 뒤 단계적으로 기준을 완화**합니다. 가장 작은 값에는 $\alpha/c$, 다음에는 $\alpha/(c-1)$, 그 다음은 $\alpha/(c-2)$ 순입니다.

그 결과 **군집당 오류는 Bonferroni와 똑같이 통제하면서 검정력은 더 높습니다.** 통계적으로 Bonferroni보다 언제나 우월합니다.

논문 관행이 아직 Bonferroni와 Tukey에 머물러 있어 채택률은 낮지만, 방법을 자유롭게 고를 수 있는 상황이라면 Holm이 합리적인 선택입니다. R에서 `p.adjust()`의 기본값이 Holm인 것도 같은 이유입니다.
:::

## 동질적 부분집합

Tukey 결과를 정리하면 다음 구조가 보입니다.

- A < B (유의)
- A < C (유의)
- B와 C는 구분되지 않음

**A는 나머지 둘과 다르고, B와 C는 서로 구분되지 않는다**는 것입니다. SPSS는 이를 **동질적 부분집합(homogeneous subsets)** 표로 보여줍니다.

!fig[**그림 10-6** 세 집단을 하나의 축에 놓은 것. A는 따로 떨어지고, B와 C는 같은 묶음으로 남는다.](ch10-subsets.svg)

| 교수법 | *n* | 부분집합 1 | 부분집합 2 |
| --- | --- | --- | --- |
| A | 10 | 68.20 | |
| B | 10 | | 73.60 |
| C | 10 | | 77.30 |
{.apa}

*주.* 같은 열에 표시된 집단 간에는 유의한 차이가 없다.

:::warn B와 C가 같다는 뜻이 아닙니다
"구분되지 않는다"와 "같다"는 다릅니다. $p$ = .055는 **차이가 없음을 증명한 것이 아니라 다르다고 판단할 근거가 부족하다**는 뜻입니다.

7장의 등분산 검정에서 확인한 원칙이 그대로 적용됩니다. **기각 실패는 영가설의 증명이 아닙니다.**

집단당 10명은 사후검정을 하기에 넉넉한 수가 아닙니다. 표본이 더 컸다면 3.7점 차이도 유의했을 수 있습니다. 논문에는 이 가능성을 제한점으로 언급해 두는 것이 정확합니다.
:::

## 사후검정을 하면 안 되는 경우

:::warn F가 유의하지 않으면 거기서 끝냅니다
$F$가 유의하지 않은데 사후검정으로 넘어가는 경우가 있습니다. **분산분석 전체가 "차이가 없다"고 판정한 자료에서 굳이 짝을 찾는 것**이며, 9장에서 막아둔 오류 누적을 되살리는 행위입니다.

$F$가 유의하지 않으면 사후검정 없이 "집단 간 차이가 유의하지 않았다"로 보고를 마칩니다.

예외가 있다면 **사전에 계획된 비교(planned comparison)**입니다. 연구 가설에서 특정 두 집단의 비교를 미리 명시했다면 $F$와 무관하게 그 비교를 할 수 있습니다. 다만 이는 사후검정이 아니라 **대비(contrast) 분석**이며, 연구계획서에 미리 적혀 있어야 합니다.
:::

## SPSS 출력과의 대응

| SPSS | R |
| --- | --- |
| 사후분석 → Tukey | `TukeyHSD(fit)` |
| 사후분석 → Bonferroni | `pairwise.t.test(..., "bonferroni")` |
| 사후분석 → LSD | `pairwise.t.test(..., "none")` |
| 사후분석 → Scheffe | `DescTools::ScheffeTest(fit)` |
| 다중 비교 표의 평균차 | `diff` |
| 다중 비교 표의 유의확률 | `p adj` |
| 동질적 부분집합 | 직접 정리 |

SPSS 경로는 `분석 → 평균 비교 → 일원배치 분산분석 → 사후분석`입니다.

> 어느 집단 간에 차이가 있는지 확인하기 위해 Tukey HSD를 이용한 사후검정을 실시하였다.
>
> 그 결과 교수법 B(*M* = 73.60)와 C(*M* = 77.30)는 모두 교수법 A(*M* = 68.20)보다 성취도가 통계적으로 유의하게 높았다(각각 *p* = .004, *p* < .001). 반면 B와 C 사이의 차이는 3.70점으로 유의수준에 근접하였으나 통계적으로 유의하지는 않았다(*p* = .055, 95% CI [−0.07, 7.47]).
>
> 이는 기존 교수법(A)에 비해 새로운 두 교수법이 모두 효과적이며, 두 새 교수법 사이에는 뚜렷한 우열을 확인하기 어려움을 시사한다. 다만 집단당 사례 수가 10명으로 제한적이어서 검정력이 충분하지 않았을 가능성을 고려할 필요가 있다.

세 요소가 들어 있습니다. **① 사용한 방법 ② 각 쌍의 결과 ③ 경계값에 대한 해석과 한계.** 유의하지 않은 쌍을 생략하지 않는 것이 중요합니다.
:::

:::check 점검 항목
- $F$가 유의한 것을 확인한 뒤 사후검정에 들어갔다
- 비교당 유의수준과 군집당 유의수준을 구분할 수 있다
- 분석 전에 방법을 정했다
- LSD는 집단이 정확히 3개일 때만 쓸 수 있다는 것을 안다
- 유의하지 않은 쌍도 결과표에 포함했다
- 경계값($p$ ≈ .05)을 있는 그대로 보고했다
:::

:::recap
**요약** — 사후검정은 **군집당 유의수준을 .05로 묶어둔 채** 어느 쌍이 다른지 확인하는 절차입니다. 기본 선택지는 **Tukey HSD**이며, 방법에 따라 결론이 갈릴 수 있으므로 **분석 전에 방법을 정해두어야 합니다.** $F$가 유의하지 않으면 사후검정으로 넘어가지 않습니다.
:::
