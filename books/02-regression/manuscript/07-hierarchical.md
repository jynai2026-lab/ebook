## 한꺼번에 넣으면 알 수 없는 것

3장에서는 스트레스, 지지, 효능감을 한꺼번에 넣었습니다. 그런데 소진에 영향을 줄 만한 것은 그것만이 아닙니다. 성별, 연령, 근속연수 같은 **인구학적 변수**도 소진과 관련이 있을 수 있습니다.

연구자가 정말 묻고 싶은 것은 대개 이렇습니다.

**"인구학적 특성의 영향을 감안하고도, 직무 관련 변수들이 소진을 추가로 설명하는가. 얼마나 더 설명하는가."**

여섯 변수를 한꺼번에 넣으면 각 계수는 알 수 있지만, **직무 관련 변수 묶음이 더해 준 설명력**은 따로 보이지 않습니다. 이 질문에 답하려면 변수를 묶음으로 나눠 **순서대로** 넣고, 묶음이 들어갈 때마다 $R^2$이 얼마나 늘어나는지 봐야 합니다. 이것이 **위계적 회귀분석(hierarchical regression)**입니다.

## 순서는 연구자가 정합니다

변수를 넣는 순서는 연구 질문이 정합니다. 일반적인 원칙은 다음과 같습니다.

| 단계 | 넣는 변수 | 이유 |
| --- | --- | --- |
| 1단계 | 통제변수 (성별, 연령, 근속연수) | 관심 변수와 무관하게 결과에 영향을 줄 수 있는 것을 먼저 걷어 냄 |
| 2단계 | 주요 독립변수 (스트레스, 지지, 효능감) | 연구의 핵심 질문 |
| 3단계 | 상호작용항 등 | 2단계 위에서만 의미가 있는 것 (8장) |
{.apa}

시간이나 인과의 순서를 따르기도 합니다. 성별과 연령은 직장 경험보다 먼저 정해져 있으므로 앞에 둡니다.

:::warn 위계적 회귀 ≠ 단계선택 ≠ 위계적 선형모형
이름이 비슷해서 자주 혼동합니다.

- **위계적 회귀분석**: 연구자가 **이론에 따라** 묶음과 순서를 정합니다. 이 장의 내용입니다.
- **단계선택(stepwise)**: 컴퓨터가 **유의확률에 따라** 변수를 넣고 뺍니다. 3장에서 피해야 한다고 했던 방법입니다.
- **위계적 선형모형(HLM)**: 학생이 학급에, 직원이 팀에 속하는 것처럼 **자료 자체가 위계적인** 경우의 다층모형입니다. 4장의 독립성 위반에 대한 해결책이며, 전혀 다른 분석입니다.

논문의 연구방법에 "위계적 회귀분석"이라고 쓸 때 어느 것인지 혼동이 없도록 투입 단계를 함께 밝힙니다.
:::

## R로 돌리기

"유의하지 않으니 빼자"는 판단은 하지 않습니다. 통제변수를 넣은 것은 그 효과를 **검증하기 위해서가 아니라 감안하기 위해서**입니다. 연구 설계 단계에서 넣기로 했다면, 결과와 상관없이 그대로 두고 보고합니다.
:::

### 2단계 — 주요 독립변수를 더함

`update()`는 기존 모형에 변수를 더할 때 편리합니다. `. ~ .`은 "기존 모형 그대로"라는 뜻입니다.

```r 2단계: 스트레스, 지지, 효능감을 더함
m2 <- update(m1, . ~ . + stress + support + efficacy)
summary(m2)
```

$R^2$이 .013에서 **.406**으로 늘었습니다. 늘어난 만큼이 **결정계수 변화량 $\Delta R^2$**입니다.

$$
\Delta R^2 = R^2_2 - R^2_1 = .4056 - .0130 = .393
$$ (2단계 변수들이 추가로 설명한 몫)

### 늘어난 몫이 유의한가

$\Delta R^2$의 유의성은 두 모형을 비교하는 $F$검정으로 확인합니다. 3장과 5장에서 변수 묶음을 함께 뺄 때 썼던 바로 그 `anova()`입니다.

```r 두 모형 비교 (F 변화량 검정)
anova(m1, m2)
```

```out
Analysis of Variance Table

Model 1: burnout ~ female + age + tenure
Model 2: burnout ~ female + age + tenure + stress + support + efficacy
  Res.Df     RSS Df Sum of Sq      F    Pr(>F)    
1    296 134.633                                  
2    293  81.075  3    53.557 64.517 < 2.2e-16 ***
---
Signif. codes:  0 ‘***’ 0.001 ‘**’ 0.01 ‘*’ 0.05 ‘.’ 0.1 ‘ ’ 1
```

$$
F_{\text{change}} = \frac{(SS_{E1} - SS_{E2}) / \Delta df}{SS_{E2} / df_2} = \frac{(134.633 - 81.075) / 3}{81.075 / 293} = 64.52
$$ (줄어든 잔차제곱합 ÷ 남은 잔차제곱합)

**$\Delta R^2$ = .393, $F$(3, 293) = 64.52, $p$ < .001.** 인구학적 변수를 통제한 뒤에도 직무 관련 세 변수가 소진 변동의 39.3%를 추가로 설명합니다.

!fig[**그림 7-1** 단계별 설명력. 통제변수가 1.3%를 설명하고, 직무 관련 변수가 39.3%를 더한다. 위계적 회귀가 보고하는 핵심은 이 '더해진 몫'이다.](ch07-blocks.svg)

:::key $F$ 변화량 검정은 늘 같은 질문입니다
"작은 모형에 변수 몇 개를 더했더니 잔차가 줄었다. 그 줄어든 만큼이 우연으로 볼 수 있는 수준보다 큰가."

5장에서 스트레스와 업무과부하를 함께 뺄 때, 6장에서 직급 더미 두 개를 함께 검정할 때, 지금 세 변수 묶음을 더할 때 모두 같은 검정입니다. 분자의 자유도($\Delta df$)는 더한 변수의 수, 분모의 자유도는 큰 모형의 잔차 자유도입니다.
:::

### 효과크기

$\Delta R^2$ 자체가 효과크기이지만, Cohen의 $f^2$으로 바꿔 보고하기도 합니다.

$$
f^2 = \frac{\Delta R^2}{1 - R^2_2} = \frac{.393}{1 - .406} = 0.66
$$ (더해진 몫 ÷ 아직 설명되지 않은 몫)

| $f^2$ | 해석 (Cohen, 1988) |
| --- | --- |
| .02 | 작은 효과 |
| .15 | 중간 효과 |
| .35 이상 | 큰 효과 |
{.apa}

0.66은 큰 효과입니다. 8장의 조절효과처럼 $\Delta R^2$이 .02~.04 수준일 때 이 기준이 특히 쓸모가 있습니다.

## 계수는 마지막 모형에서 읽습니다

2단계의 스트레스 계수(0.521)는 3장의 0.526과 조금 다릅니다. 성별, 연령, 근속연수까지 통제한 값이기 때문입니다. 각 변수의 효과를 해석할 때는 **모든 변수가 들어간 마지막 모형**의 계수를 씁니다. 1단계 계수는 "통제변수만 있을 때" 어떠했는지를 보여줄 뿐입니다.

```r 2단계 모형의 표준화 계수
library(effectsize)
standardize_parameters(m2)
```

### 순서가 바꾸는 것과 바꾸지 않는 것

같은 여섯 변수를 거꾸로, 직무 변수를 먼저 넣고 통제변수를 나중에 넣으면 어떻게 될까요.

```r 순서를 뒤집으면: 통제변수를 나중에
m_job <- lm(burnout ~ stress + support + efficacy, data = d)
anova(m_job, m2)
summary(m2)$r.squared - summary(m_job)$r.squared
```

```out
Analysis of Variance Table

Model 1: burnout ~ stress + support + efficacy
Model 2: burnout ~ female + age + tenure + stress + support + efficacy
  Res.Df    RSS Df Sum of Sq      F Pr(>F)
1    296 82.579                           
2    293 81.075  3    1.5041 1.8119 0.1451
[1] 0.01102614
```

| 순서 | 통제변수의 $\Delta R^2$ | 직무 변수의 $\Delta R^2$ |
| --- | --- | --- |
| 통제변수 먼저 | .013 | .393 |
| 직무 변수 먼저 | .011 | .395 |
{.apa}

**마지막 모형은 같습니다.** 계수, $R^2$, 표준오차 모두 그대로입니다. 바뀌는 것은 각 묶음에 돌아가는 $\Delta R^2$입니다. 두 묶음이 함께 설명하는 몫(여기서는 아주 작음)이 **먼저 들어간 쪽에 돌아갑니다.** 그래서 순서가 곧 연구자의 주장입니다. "통제변수를 먼저 넣었다"는 것은 겹치는 몫이 있다면 통제변수 쪽에 양보하고, 그래도 남는 직무 변수의 몫만 주장하겠다는 보수적인 선택입니다.

:::warn 결측치가 있으면 두 모형의 사례 수가 달라집니다
`lm()`은 모형에 들어간 변수 중 하나라도 비어 있는 사람을 빼고 계산합니다. 2단계에서 넣은 변수에 결측이 있으면 2단계 모형의 사례 수가 1단계보다 적어지고, `anova()`는 다음 오류를 냅니다.

`models were not all fitted to the same size of dataset`

사례 수가 다른 두 모형의 $R^2$을 빼는 것은 의미가 없습니다. **분석에 쓸 모든 변수가 있는 사람만 먼저 골라 두고** 그 자료로 모든 단계를 돌립니다.

`d_c <- na.omit(d[, c("burnout", "female", "age", "tenure", "stress", "support", "efficacy")])`
:::

## 논문 결과표

위계적 회귀분석의 결과표는 단계마다 열을 나란히 둡니다.

**표 7. 소진에 대한 위계적 회귀분석 결과**

| 변수 | 모형 1 *B* | 모형 1 β | 모형 2 *B* | 모형 2 β |
| --- | --- | --- | --- | --- |
| 성별 (0 = 남, 1 = 여) | 0.082 | — | 0.074 | — |
| 연령 | −0.010 | −.11 | −0.008 | −.08 |
| 근속연수 | 0.001 | .01 | −0.002 | −.02 |
| 직무스트레스 | | | 0.521\*\*\* | .48 |
| 사회적지지 | | | −0.211\*\*\* | −.19 |
| 자기효능감 | | | −0.247\*\*\* | −.20 |
| $R^2$ | .013 | | .406 | |
| 수정 $R^2$ | .003 | | .393 | |
| $\Delta R^2$ | | | .393\*\*\* | |
| *F* | 1.30 | | 33.33\*\*\* | |
{.apa}

*주.* *N* = 300. 성별은 더미변수이므로 β를 보고하지 않았다. \*\*\**p* < .001.

:::paper 결과 서술 예시
> 인구학적 변수를 통제한 상태에서 직무 관련 변수가 소진에 미치는 영향을 검증하기 위해 위계적 회귀분석을 실시하였다(표 7). 1단계에서 투입한 성별, 연령, 근속연수는 소진을 유의하게 설명하지 못하였다(*R*² = .013, *F*(3, 296) = 1.30, *p* = .274).
>
> 2단계에서 직무스트레스, 사회적지지, 자기효능감을 추가로 투입한 결과 설명력이 39.3% 증가하였으며 이는 통계적으로 유의하였다(Δ*R*² = .393, *F*(3, 293) = 64.52, *p* < .001, *f*² = 0.66). 직무스트레스는 소진에 정적인 영향을(β = .48, *p* < .001), 사회적지지(β = −.19, *p* < .001)와 자기효능감(β = −.20, *p* < .001)은 부적인 영향을 미쳤다.

$\Delta R^2$과 그 $F$검정이 위계적 회귀분석의 결론입니다. 이 두 값을 반드시 함께 씁니다.
:::

:::check 점검 항목
- 투입 순서를 연구 질문과 이론에 따라 정했다
- 위계적 회귀와 단계선택, 위계적 선형모형을 구분했다
- 단계마다 $R^2$, $\Delta R^2$, $F$ 변화량 검정을 보고했다
- 모든 단계를 같은 사례로 돌렸다(결측 처리)
- 계수는 마지막 모형에서 해석했다
- 통제변수가 유의하지 않아도 빼지 않았다
:::

:::recap
**요약** — 위계적 회귀분석은 변수를 연구자가 정한 순서대로 묶음으로 넣고, 묶음이 더해질 때마다 늘어나는 설명력 **$\Delta R^2$**과 그 유의성($F$ 변화량 검정)을 봅니다. 마지막 모형은 순서와 상관없이 같지만, 겹치는 몫이 먼저 들어간 묶음에 돌아가므로 **순서가 곧 연구자의 주장**입니다. 통제변수를 먼저 넣는 것은 그 주장을 보수적으로 하겠다는 뜻입니다.
:::
