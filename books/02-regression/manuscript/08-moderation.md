## 질문이 바뀝니다

지금까지의 질문은 "스트레스가 소진과 관련이 있는가, 얼마나 관련이 있는가"였습니다. 답은 기울기 하나였습니다. 모든 사람에게 같은 기울기를 적용했습니다.

그런데 직관적으로 이런 생각이 듭니다. 같은 스트레스를 받아도 **기댈 곳이 있는 사람은 덜 무너지지 않을까.** 동료와 상사의 지지가 스트레스의 충격을 흡수해 주는 것입니다. 이를 **완충 가설(buffering hypothesis)**이라 합니다(Cohen & Wills, 1985).

이 가설을 통계의 언어로 바꾸면 이렇습니다.

**"스트레스가 소진에 미치는 영향(기울기)의 크기가 사회적지지의 수준에 따라 달라지는가."**

이처럼 한 변수의 효과 크기를 바꾸는 제3의 변수를 **조절변수(moderator)**라 하고, 그 현상을 **조절효과(moderation)**라 합니다.

!fig[**그림 8-1** 조절효과의 개념 모형과 통계 모형. 왼쪽처럼 조절변수는 화살표 자체를 겨냥한다. 실제 분석은 오른쪽처럼 두 변수의 곱을 하나의 독립변수로 넣어서 한다. (개념도)](ch08-concept.svg)

:::key 1권 11장의 상호작용과 같은 것입니다
1권 11장에서 성별과 학교 유형의 **상호작용**을 보았습니다. 학교 유형에 따라 남녀 차이가 달랐고, 그래프의 선이 평행하지 않았습니다.

조절효과는 그것과 **같은 개념**입니다. 차이는 조절변수가 집단(학교 유형)이 아니라 연속변수(지지 점수)라는 것뿐입니다. 그래서 "선이 평행하지 않다"가 "기울기가 조절변수 값에 따라 연속적으로 변한다"로 바뀝니다.
:::

## 곱하기 항 하나

조절효과는 두 변수를 **곱한 항**을 회귀식에 넣어 표현합니다.

$$
\hat{Y} = b_0 + b_1 X + b_2 W + b_3 XW
$$ ($X$ 스트레스, $W$ 지지, $XW$ 둘의 곱)

곱하기 항이 왜 "기울기가 달라진다"를 뜻하는지는 식을 $X$에 대해 묶어 보면 보입니다.

$$
\hat{Y} = (b_0 + b_2 W) + (b_1 + b_3 W)\,X
$$ ($X$의 기울기 자리에 $W$가 들어 있습니다)

스트레스의 기울기가 하나의 숫자 $b_1$이 아니라 **$b_1 + b_3 W$**입니다. 지지($W$)가 1점 높아질 때마다 스트레스의 기울기가 $b_3$만큼 바뀝니다. **$b_3$이 0이 아니면 조절효과가 있다**는 뜻이고, 검정할 것은 $b_3$ 하나입니다.

| 계수 | 의미 |
| --- | --- |
| $b_3$ | 지지가 1점 높아질 때 스트레스 기울기의 변화량. **조절효과의 크기** |
| $b_1$ | 지지가 **0일 때**의 스트레스 기울기 |
| $b_2$ | 스트레스가 **0일 때**의 지지 기울기 |
{.apa}

$b_1$과 $b_2$의 해석에 주의하십시오. 곱하기 항이 들어가면 이들은 더 이상 "평균적인 효과"가 아니라 **상대 변수가 0일 때의 효과**입니다. 이것이 다음 절의 중심화가 필요한 이유입니다.

## 먼저 중심화합니다

지지와 스트레스는 1~5점 척도라 0점이 없습니다. 원점수 그대로 곱하기 항을 넣으면 어떻게 되는지 봅니다.

```r 원점수로 곱하기 항을 넣으면
library(car)
d <- read.csv("data/survey.csv")
m_raw <- lm(burnout ~ efficacy + stress * support, data = d)
round(coef(m_raw), 3)
round(vif(m_raw), 2)
```

```out
   (Intercept)       efficacy         stress        support stress:support 
        -1.295         -0.237          1.871          0.948         -0.380 
      efficacy         stress        support stress:support 
          1.12          37.32          26.75          49.59
```

R 모형식의 `stress * support`는 `stress + support + stress:support`를 줄인 것입니다. 결과에 두 가지 문제가 보입니다.

**① 계수가 엉뚱합니다.** 스트레스 계수 1.871은 "지지가 0점인 사람"의 기울기이고, 지지 계수 **+0.948**은 "스트레스가 0점인 사람"의 기울기입니다. 둘 다 존재하지 않는 사람입니다. 지지가 소진을 높이는 것처럼 보이는 양수 부호도 이 때문입니다.

**② VIF가 37~50입니다.** $XW$는 $X$와 $W$를 곱해 만들었으니 원래 변수들과 상관이 높을 수밖에 없습니다. 이를 **비본질적 다중공선성**이라 합니다. 5장의 다중공선성과 달리 변수의 측정 원점을 옮기기만 하면 사라집니다.

해결책은 2장에서 본 **평균 중심화**입니다. 곱하기 전에 각 변수에서 평균을 뺍니다.

```r 중심화한 뒤 곱하기 항
d$stress_c  <- d$stress  - mean(d$stress)
d$support_c <- d$support - mean(d$support)
m_int <- lm(burnout ~ efficacy + stress_c * support_c, data = d)
round(coef(m_int), 3)
round(vif(m_int), 2)
```

```out
       (Intercept)           efficacy           stress_c          support_c 
             3.684             -0.237              0.533             -0.223 
stress_c:support_c 
            -0.380 
          efficacy           stress_c          support_c stress_c:support_c 
              1.12               1.06               1.15               1.00
```

VIF가 모두 1 근처로 떨어졌습니다. 그리고 이제 `stress_c`의 계수는 **지지가 평균인 사람의 스트레스 기울기**, `support_c`의 계수는 **스트레스가 평균인 사람의 지지 기울기**가 됩니다. 해석할 수 있는 값입니다.

:::ok 중심화는 모형을 바꾸지 않습니다
중심화 전후로 바뀌는 것은 $b_1$, $b_2$와 그 표준오차뿐입니다. **곱하기 항의 계수 $b_3$과 그 검정, $R^2$, 예측값은 완전히 같습니다.** 위 두 출력에서 `stress:support`와 `stress_c:support_c`의 계수가 모두 −0.380인 것을 확인하십시오. 중심화는 결과를 바꾸는 조작이 아니라 **해석하기 좋은 자리로 원점을 옮기는 것**입니다.

종속변수는 중심화하지 않습니다. 곱하기 항에 들어가는 독립변수와 조절변수만 중심화합니다.
:::

```r 1단계: 주효과, 2단계: 곱하기 항
summary(m_int)
anova(m_main, m_int)
```

:::paper 조절효과의 $\Delta R^2$은 원래 작습니다
4%라고 하면 작아 보입니다. 그러나 조절효과는 "효과의 차이"를 재는 것이라 주효과보다 훨씬 작게 나오는 것이 정상입니다. Aguinis 등(2005)이 30년간의 연구를 검토한 결과 조절효과의 $f^2$ 중앙값은 **.002**였습니다. 이 기준으로 보면 0.074는 상당히 큰 조절효과입니다.

같은 이유로 조절효과를 검정하려면 주효과보다 **훨씬 큰 표본**이 필요합니다. 사례가 적은 연구에서 조절효과가 유의하지 않았다고 "조절효과가 없다"고 결론 내리지 않습니다.
:::

## 단순기울기 — 지지 수준별로 나눠 보기

$b_3$ = −0.380은 "기울기가 달라진다"는 것을 알려주지만, 구체적으로 지지가 낮은 사람과 높은 사람에게 스트레스의 기울기가 각각 얼마인지는 따로 구해야 합니다. 이것을 **단순기울기(simple slope)**라 합니다.

관례적으로 조절변수의 **평균 −1 *SD*, 평균, 평균 +1 *SD*** 세 지점에서 구합니다. 지지의 표준편차는 0.597이므로 2.92점, 3.52점, 4.12점입니다.

### 원점을 옮기는 방법

`stress_c`의 계수가 "`support_c`가 0인 사람의 기울기"라는 성질을 이용합니다. 지지에서 평균 대신 **"평균 − 1 *SD*"를 빼서** 중심화하면, 그 변수가 0인 사람은 지지가 낮은 사람이 되고, `stress_c`의 계수는 그 사람들의 기울기가 됩니다.

```r 지지 수준을 바꿔 가며 스트레스 기울기 구하기
s <- sd(d$support)
for (k in c(-1, 0, 1)) {
  d$w <- d$support - (mean(d$support) + k * s)
  mk <- lm(burnout ~ efficacy + stress_c * w, data = d)
  cat(sprintf("지지 %+d SD (%.2f점): 기울기 %.3f, SE %.3f, p = %.2g\n",
              k, mean(d$support) + k * s,
              coef(mk)["stress_c"], sqrt(vcov(mk)["stress_c", "stress_c"]),
              summary(mk)$coefficients["stress_c", 4]))
}
```

```out
지지 -1 SD (2.92점): 기울기 0.760, SE 0.070, p = 2.6e-23
지지 +0 SD (3.52점): 기울기 0.533, SE 0.049, p = 2.6e-23
지지 +1 SD (4.12점): 기울기 0.306, SE 0.068, p = 1e-05
```

## 어디서부터 유의하지 않은가 — 존슨-네이만 구간

±1 *SD*라는 세 지점은 관례일 뿐 특별한 의미가 없습니다. 지지가 계속 높아지면 스트레스의 기울기는 점점 작아지다가 언젠가 0과 구분되지 않게 됩니다. **그 경계가 어디인지**를 찾는 것이 **존슨-네이만(Johnson-Neyman) 방법**입니다.

단순기울기 $b_1 + b_3 W$의 표준오차는 계수들의 분산과 공분산으로 계산됩니다. 이것을 지지의 모든 값에서 구해 $t$가 임계값 밑으로 내려가는 지점을 찾습니다.

```r 존슨-네이만: 기울기가 유의하지 않게 되는 지지 점수
b <- coef(m_int); V <- vcov(m_int)
w  <- seq(-2, 2, by = .001)                              # 중심화된 지지
sl <- b["stress_c"] + b["stress_c:support_c"] * w
se <- sqrt(V["stress_c", "stress_c"] + w^2 * V["stress_c:support_c", "stress_c:support_c"] +
           2 * w * V["stress_c", "stress_c:support_c"])
crit <- qt(.975, df.residual(m_int))
jn <- min(w[abs(sl / se) < crit]) + mean(d$support)       # 원래 척도로
jn
sum(d$support >= jn)
```

```out
[1] 4.4592
[1] 23
```

**지지가 4.46점 이상이면 스트레스의 기울기가 유의하지 않습니다.** 300명 가운데 23명이 이 범위에 있습니다. 지지가 아주 높은 사람에게는 스트레스와 소진의 관련이 통계적으로 확인되지 않는다는 뜻입니다.

!fig[**그림 8-3** 사회적지지 점수에 따른 스트레스 기울기와 95% 신뢰구간. 신뢰구간이 0을 포함하기 시작하는 4.46점이 존슨-네이만 경계다. 아래 막대는 지지 점수의 분포다.](ch08-jn.svg)

:::warn 경계 밖에서는 "효과가 없다"가 아닙니다
존슨-네이만 경계 위쪽은 기울기가 0과 **구분되지 않는** 구간이지, 0인 구간이 아닙니다. 그 범위의 사람이 23명뿐이라 추정이 불안정한 것도 이유입니다. "지지가 매우 높은 집단에서는 스트레스와 소진의 관련이 유의하지 않았다"로 씁니다.
:::

```out
Signif. codes:  0 ‘***’ 0.001 ‘**’ 0.01 ‘*’ 0.05 ‘.’ 0.1 ‘ ’ 1
```

모형 전체의 휨을 보는 **Tukey 검정이 $p$ = .259로 사라졌습니다.** 4장에서 보인 휨의 상당 부분은 스트레스의 기울기가 지지에 따라 다른 것을 직선 하나로 요약한 데서 왔던 것입니다. 스트레스 축의 약한 휨($p$ = .016)은 남지만, 이차항을 더해도 설명력은 1.1%p 늘 뿐이어서 이 정도는 직선 모형으로 충분하다고 판단합니다.

진단이 모형에 빠진 것을 가리키고, 이론이 그것이 무엇인지 알려준 예입니다.

## 조절효과를 볼 때 하지 말아야 할 것

:::warn 조절변수를 두 집단으로 쪼개지 않습니다
지지를 중앙값 기준으로 "높은 집단"과 "낮은 집단"으로 나눠 따로 회귀분석하는 방법이 흔히 쓰입니다. 피해야 합니다.

- 연속변수를 둘로 자르면 정보를 버립니다. 중앙값 바로 위와 바로 아래의 사람이 완전히 다른 집단이 되고, 검정력이 크게 떨어집니다(MacCallum et al., 2002).
- 두 집단의 기울기가 **서로 다른지**는 검정하지 않습니다.
:::

:::warn "한쪽은 유의, 다른 쪽은 비유의"는 조절효과의 증거가 아닙니다
남녀를 나눠 분석했더니 남자는 $p$ = .03, 여자는 $p$ = .08이었다고 합시다. 이것으로 "성별이 조절한다"고 할 수 없습니다. 두 기울기가 0.30과 0.27로 거의 같은데 한쪽 표본이 작아서 유의성만 갈렸을 수 있습니다.

**"유의함과 유의하지 않음의 차이는 그 자체로 유의하지 않을 수 있습니다"**(Gelman & Stern, 2006). 조절효과는 반드시 **곱하기 항의 검정**으로 확인합니다. 성별처럼 범주형 조절변수라면 더미변수와 독립변수의 곱을 넣으면 됩니다.
:::

## 논문 결과표

**표 8. 사회적지지의 조절효과**

| 변수 | 1단계 *B* (*SE*) | 2단계 *B* (*SE*) |
| --- | --- | --- |
| 자기효능감 | −0.227 (0.058)\*\*\* | −0.237 (0.056)\*\*\* |
| 직무스트레스 (X) | 0.526 (0.051)\*\*\* | 0.533 (0.049)\*\*\* |
| 사회적지지 (W) | −0.222 (0.055)\*\*\* | −0.223 (0.053)\*\*\* |
| X × W | | −0.380 (0.081)\*\*\* |
| $R^2$ | .395 | .436 |
| $\Delta R^2$ | | .042\*\*\* |
{.apa}

*주.* *N* = 300. 직무스트레스와 사회적지지는 평균 중심화하였다. \*\*\**p* < .001.

1단계 계수는 3장 모형과 같습니다. 변수를 중심화해도 곱하기 항이 없는 모형의 기울기는 바뀌지 않기 때문입니다.

:::paper 결과 서술 예시
> 직무스트레스와 소진의 관계에서 사회적지지의 조절효과를 검증하기 위해, 자기효능감을 통제한 상태에서 위계적 회귀분석을 실시하였다. 다중공선성을 줄이고 해석을 쉽게 하기 위해 직무스트레스와 사회적지지는 평균 중심화하였다(VIF ≤ 1.15).
>
> 2단계에서 상호작용항을 투입한 결과 설명력이 유의하게 증가하였으며(Δ*R*² = .042, *F*(1, 295) = 21.85, *p* < .001), 상호작용항의 계수는 부적으로 유의하였다(*B* = −0.380, *p* < .001). 단순기울기 분석 결과, 직무스트레스가 소진에 미치는 영향은 사회적지지가 낮을 때(−1 *SD*; *B* = 0.760, *p* < .001) 가장 컸고, 평균일 때(*B* = 0.533, *p* < .001), 높을 때(+1 *SD*; *B* = 0.306, *p* < .001) 순으로 작아졌다(그림 8-2). 존슨-네이만 분석에 따르면 사회적지지가 4.46점 이상인 경우(*n* = 23) 직무스트레스의 영향은 유의하지 않았다. 이는 사회적지지가 직무스트레스의 부정적 영향을 완충한다는 가설을 지지한다.

조절효과는 **표, 단순기울기, 그림** 세 가지를 함께 보고하는 것이 원칙입니다. 그림 없이 계수만 있으면 독자가 방향을 해석하기 어렵습니다.
:::

:::check 점검 항목
- 조절변수가 "효과의 크기"를 바꾸는지 묻는 질문임을 확인했다
- 곱하기 전에 독립변수와 조절변수를 평균 중심화했다
- 곱하기 항이 있을 때 주효과 계수는 "상대 변수가 0(평균)일 때"의 효과로 읽었다
- 곱하기 항의 $\Delta R^2$과 계수의 검정을 보고했다
- 단순기울기(−1 *SD*, 평균, +1 *SD*)를 구하고 그림으로 제시했다
- 필요하면 존슨-네이만 경계를 보고했다
- 조절변수를 집단으로 쪼개 따로 분석하지 않았다
:::

:::recap
**요약** — 조절효과는 **한 변수의 기울기가 다른 변수의 값에 따라 달라지는 것**이며, 두 변수의 곱을 회귀식에 넣어 그 계수 $b_3$으로 검정합니다. 곱하기 항이 있으면 주효과 계수는 상대 변수가 0일 때의 기울기이므로, **평균 중심화**로 원점을 해석 가능한 자리로 옮깁니다. 조절효과가 확인되면 단순기울기와 그림으로 "누구에게 더 강한지"를 구체적으로 보여줍니다.
:::
