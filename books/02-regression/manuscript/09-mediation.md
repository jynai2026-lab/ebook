## '얼마나'에서 '어떻게'로

직무스트레스와 이직의도의 상관은 .44였습니다(1장). 스트레스가 높은 사람이 이직을 더 생각합니다. 그런데 **왜** 그럴까요.

하나의 설명은 이렇습니다. 스트레스가 쌓이면 정서적으로 지치고(소진), 지친 사람이 조직을 떠나고 싶어 한다. 이 설명이 맞다면 스트레스의 영향은 **소진을 거쳐서** 이직의도에 도달합니다.

이처럼 독립변수의 영향을 종속변수로 전달하는 중간 변수를 **매개변수(mediator)**라 하고, 그 경로를 통해 전달되는 효과를 **매개효과(mediation)** 또는 **간접효과(indirect effect)**라 합니다.

!fig[**그림 9-1** 매개모형. 스트레스의 영향은 소진을 거쳐 가는 간접경로(a, b)와 소진을 거치지 않는 직접경로(c′)로 나뉜다. (개념도)](ch09-concept.svg)

:::key 조절과 매개는 다른 질문입니다
이름이 비슷하고 둘 다 제3의 변수를 다루지만 묻는 것이 다릅니다.

| | 조절효과 (8장) | 매개효과 (9장) |
| --- | --- | --- |
| 질문 | **언제, 누구에게** 효과가 강한가 | **어떻게, 무엇을 거쳐** 효과가 생기는가 |
| 제3변수의 위치 | 화살표를 겨냥함 | 화살표 사이에 끼어듦 |
| 제3변수와 X의 관계 | 상관이 없어도 됨 | X가 제3변수에 영향을 줌 (경로 a) |
| 분석 | 곱하기 항 | 경로 계수의 곱 |
{.apa}

사회적지지는 스트레스의 효과를 **바꾸는** 변수(조절), 소진은 스트레스의 효과를 **나르는** 변수(매개)입니다.
:::

## 효과를 쪼갠다

매개분석은 회귀분석 세 개로 이루어집니다.

```r 세 개의 회귀식
d <- read.csv("data/survey.csv")
m_c <- lm(turnover ~ stress, data = d)            # 총효과 c
m_a <- lm(burnout ~ stress, data = d)             # 경로 a
m_b <- lm(turnover ~ stress + burnout, data = d)  # 경로 b와 직접효과 c'

round(rbind(c       = summary(m_c)$coefficients["stress", ],
            a       = summary(m_a)$coefficients["stress", ],
            b       = summary(m_b)$coefficients["burnout", ],
            c_prime = summary(m_b)$coefficients["stress", ]), 4)
```

```out
        Estimate Std. Error t value Pr(>|t|)
c         0.5837     0.0692  8.4381   0.0000
a         0.6017     0.0529 11.3833   0.0000
b         0.5621     0.0686  8.1972   0.0000
c_prime   0.2455     0.0749  3.2750   0.0012
```

| 경로 | 회귀식 | 값 | 의미 |
| --- | --- | --- | --- |
| $c$ | 이직의도 ~ 스트레스 | 0.584 | **총효과**. 스트레스가 1점 높을 때 이직의도가 높은 정도 |
| $a$ | 소진 ~ 스트레스 | 0.602 | 스트레스가 1점 높을 때 소진이 높은 정도 (2장과 같은 값) |
| $b$ | 이직의도 ~ 스트레스 + **소진** | 0.562 | 스트레스가 같을 때, 소진이 1점 높으면 이직의도가 높은 정도 |
| $c'$ | 이직의도 ~ **스트레스** + 소진 | 0.245 | **직접효과**. 소진이 같을 때 스트레스의 효과 |
{.apa}

$b$와 $c'$은 같은 회귀식에서 나옵니다. 3장의 다중회귀 계수이므로 각각 "다른 쪽이 같을 때"로 읽습니다.

### 간접효과 $= a \times b$

스트레스가 1점 높으면 소진이 $a$ = 0.602점 높고, 소진이 1점 높으면 이직의도가 $b$ = 0.562점 높습니다. 그러면 스트레스 1점이 **소진을 거쳐서** 이직의도에 전달하는 몫은 두 기울기의 곱입니다.

$$
\text{간접효과} = a \times b = 0.602 \times 0.562 = 0.338
$$ (소진을 거쳐 전달되는 스트레스의 효과)

그리고 다음 관계가 정확히 성립합니다.

$$
\underbrace{c}_{\text{총효과}} = \underbrace{c'}_{\text{직접효과}} + \underbrace{a \times b}_{\text{간접효과}} \qquad 0.584 = 0.245 + 0.338
$$ (총효과는 직접효과와 간접효과로 남김없이 나뉩니다)

```r 간접효과를 두 방법으로
a <- coef(m_a)["stress"]
b <- coef(m_b)["burnout"]
unname(a * b)                                          # a × b
unname(coef(m_c)["stress"] - coef(m_b)["stress"])      # c - c'
```

```out
[1] 0.3382168
[1] 0.3382168
```

두 값이 소수점 끝까지 같습니다. 소진을 모형에 넣었을 때 스트레스의 계수가 0.584에서 0.245로 **줄어든 만큼이 바로 소진을 거쳐 가던 몫**입니다. 3장에서 다른 변수를 넣으면 계수가 줄어든다고 했던 현상을, 매개분석은 "경로"로 해석합니다.

!fig[**그림 9-2** 총효과 0.584(위)가 소진을 거치는 간접효과 0.338과 직접효과 0.245(아래)로 나뉜다. 스트레스가 이직의도에 미치는 영향의 58%가 소진을 거쳐 간다.](ch09-decompose.svg)

## 고전적 방법 — Baron과 Kenny의 4단계

오랫동안 매개효과는 Baron과 Kenny(1986)의 절차로 확인했습니다. 지금도 많은 학위논문에서 볼 수 있습니다.

| 단계 | 확인할 것 | 이 자료 |
| --- | --- | --- |
| 1 | $X$ → $Y$ (경로 $c$)가 유의하다 | 0.584, $p$ < .001 충족 |
| 2 | $X$ → $M$ (경로 $a$)이 유의하다 | 0.602, $p$ < .001 충족 |
| 3 | $X$를 통제한 $M$ → $Y$ (경로 $b$)가 유의하다 | 0.562, $p$ < .001 충족 |
| 4 | $M$을 통제하면 $c'$이 $c$보다 작아진다 | 0.584 → 0.245 충족 |
{.apa}

네 조건을 모두 만족하므로 이 절차로는 "매개효과가 있다"고 결론 내립니다. 4단계에서 $c'$이 유의하지 않게 되면 **완전매개**, 여전히 유의하면 **부분매개**라 불렀습니다. 여기서는 $c'$ = 0.245가 유의하므로 부분매개입니다.

:::warn 4단계 절차의 한계
이 절차는 지금은 권장되지 않습니다(Hayes, 2009; Zhao et al., 2010).

- **간접효과 $a \times b$ 자체를 검정하지 않습니다.** $a$와 $b$가 각각 유의한지만 봅니다. 매개효과의 크기와 불확실성을 알 수 없습니다.
- **1단계가 불필요하게 엄격합니다.** 간접효과와 직접효과가 서로 반대 방향이면 둘이 상쇄되어 총효과 $c$가 유의하지 않을 수 있습니다. 그래도 매개는 존재합니다.
- 유의성 검정을 여러 번 거치므로 **검정력이 낮습니다.** 실제 매개효과가 있어도 놓치기 쉽습니다.

지금은 **간접효과 $a \times b$를 직접 검정**하는 것이 표준입니다.
:::

## 간접효과를 직접 검정하기

### Sobel 검정

간접효과 $ab$의 표준오차를 근사해 $z$검정을 하는 방법입니다(Sobel, 1982).

$$
SE_{ab} = \sqrt{b^2 s_a^2 + a^2 s_b^2}, \qquad z = \frac{ab}{SE_{ab}}
$$ ($s_a$, $s_b$는 두 경로 계수의 표준오차)

```r Sobel 검정
sa <- summary(m_a)$coefficients["stress", "Std. Error"]
sb <- summary(m_b)$coefficients["burnout", "Std. Error"]
se_ab <- sqrt(b^2 * sa^2 + a^2 * sb^2)
z <- a * b / se_ab
round(c(ab = unname(a * b), se = unname(se_ab), z = unname(z), p = 2 * pnorm(-abs(unname(z)))), 4)
```

```out
    ab     se      z      p 
0.3382 0.0508 6.6520 0.0000
```

$z$ = 6.65, $p$ < .001로 간접효과가 유의합니다. 그러나 Sobel 검정에는 근본적인 문제가 있습니다. **두 정규분포 변수의 곱은 정규분포가 아닙니다.** $a$와 $b$가 각각 정규분포를 따라도 $ab$의 표집분포는 한쪽으로 치우칩니다. 정규분포를 가정한 $z$검정은 이 치우침을 무시하므로, 특히 표본이 작을 때 부정확하고 검정력이 낮습니다.

### 부트스트랩 — 지금의 표준

$ab$의 표집분포를 공식으로 구하기 어렵다면, **직접 만들어 보면** 됩니다. 1권 4장에서 표본을 무한히 다시 뽑는 상상으로 표집분포를 이해했습니다. 부트스트랩은 그 상상을 컴퓨터로 실제로 합니다.

1. 300명의 자료에서 **300명을 복원추출**로 다시 뽑습니다. 같은 사람이 두세 번 뽑히기도 하고 한 번도 안 뽑히기도 합니다.
2. 그 표본으로 $a$와 $b$를 추정하고 $ab$를 계산합니다.
3. 이것을 2,000번 반복합니다.
4. 2,000개의 $ab$를 크기순으로 늘어놓고 **아래 2.5%와 위 2.5% 지점**을 95% 신뢰구간으로 삼습니다.

신뢰구간이 0을 포함하지 않으면 간접효과가 유의하다고 판단합니다. 분포의 모양을 가정하지 않으므로 치우친 분포에서도 정확합니다(Preacher & Hayes, 2008).

R에서는 `lavaan` 패키지로 합니다. 4권 구조방정식에서 쓸 패키지이기도 합니다. 모형을 문자열로 적고, 경로마다 이름표(`a`, `b`, `cp`)를 붙인 뒤, `:=`로 간접효과를 정의합니다.

```r lavaan으로 매개모형과 부트스트랩 (2,000회)
library(lavaan)
model <- '
  burnout  ~ a * stress
  turnover ~ b * burnout + cp * stress
  indirect := a * b
  total    := cp + a * b
'
set.seed(2026)
fit <- sem(model, data = d, se = "bootstrap", bootstrap = 2000)
pe <- parameterEstimates(fit, boot.ci.type = "perc")
pe[pe$label != "", c("label", "est", "se", "pvalue", "ci.lower", "ci.upper")]
```

```out
     label   est    se pvalue ci.lower ci.upper
1        a 0.602 0.056      0    0.493    0.712
2        b 0.562 0.069      0    0.424    0.694
3       cp 0.245 0.069      0    0.110    0.386
7 indirect 0.338 0.051      0    0.242    0.442
8    total 0.584 0.069      0    0.453    0.720
```

| 출력의 이 자리 | 값 | 의미 |
| --- | --- | --- |
| `a`, `b`, `cp`의 `est` | 0.602, 0.562, 0.245 | `lm()`으로 구한 값과 같음 |
| `se` | 부트스트랩 표준오차 | 2,000번 추정값의 표준편차 |
| `indirect`의 `ci.lower`, `ci.upper` | **[0.242, 0.442]** | 간접효과의 95% 부트스트랩 신뢰구간 |
| `total` | 0.584 | 총효과 = cp + a × b |
{.apa}

**간접효과는 0.338, 95% 부트스트랩 신뢰구간 [0.242, 0.442]**로 0을 포함하지 않습니다. 소진을 통한 매개효과가 유의합니다.

!fig[**그림 9-3** 부트스트랩으로 얻은 간접효과 2,000개의 분포. 가운데 95%가 [0.242, 0.442]이고 0과 멀리 떨어져 있다. 분포가 오른쪽으로 약간 치우쳐 있다.](ch09-boot.svg)

:::paper `set.seed()`를 꼭 씁니다
부트스트랩은 무작위로 다시 뽑기 때문에 돌릴 때마다 신뢰구간이 조금씩 달라집니다. `set.seed(2026)`처럼 난수의 출발점을 고정하면 같은 결과가 재현됩니다. 논문에는 반복 횟수(2,000회 또는 5,000회)와 신뢰구간 방식(백분위수)을 적습니다. SPSS의 PROCESS 매크로는 기본값이 5,000회입니다.
:::

```

```

표준화 간접효과는 .254입니다. 스트레스가 1 표준편차 높을 때 소진을 거쳐 이직의도가 0.25 표준편차 높다는 뜻입니다.

## 완전매개와 부분매개

직접효과 $c'$ = 0.245는 95% 신뢰구간 [0.110, 0.386]이 0을 포함하지 않아 유의합니다. 소진을 통제해도 스트레스가 이직의도와 직접 관련된 몫이 남는다는 뜻이고, 전통적인 용어로는 **부분매개**입니다.

총효과 가운데 간접효과의 비율을 계산하기도 합니다.

$$
\frac{ab}{c} = \frac{0.338}{0.584} = .58
$$ (총효과의 58%가 소진을 거쳐 감)

:::warn 완전매개라는 말을 아껴 씁니다
"완전매개"는 $c'$이 유의하지 않다는 뜻인데, 이는 **표본크기에 크게 좌우됩니다.** 표본이 작으면 직접효과가 있어도 유의하지 않아 완전매개로 보이고, 같은 모형이라도 표본이 크면 부분매개가 됩니다. 그래서 최근에는 완전/부분의 구분보다 **간접효과와 직접효과를 각각의 크기와 신뢰구간으로 보고**하는 것을 권합니다(Hayes, 2018).

매개 비율($ab/c$)도 총효과가 작을 때 매우 불안정합니다. 참고 수치로만 씁니다.
:::

## 인과에 대한 주의

매개분석은 본질적으로 **인과에 대한 주장**입니다. "스트레스가 소진을 **일으키고**, 소진이 이직의도를 **일으킨다**." 그런데 이 자료는 한 시점에 세 변수를 모두 설문으로 쟀습니다.

같은 자료에 방향을 바꾼 모형, 예컨대 "이직을 생각하는 사람이 일에서 마음이 떠나 소진을 더 느낀다"를 적합해도 통계적으로는 똑같이 잘 맞습니다. **자료는 화살표의 방향을 말해 주지 않습니다.**

:::warn 횡단 자료의 매개분석
Maxwell과 Cole(2007)은 한 시점 자료로 추정한 매개효과가 실제 시간에 따라 일어나는 매개효과를 크게 왜곡할 수 있음을 보였습니다. 횡단 자료로 매개분석을 할 때는 다음을 지킵니다.

- 화살표의 방향을 **이론과 선행연구**로 정당화합니다.
- 결과를 "소진이 매개하였다"보다 **"매개모형과 일치하는 결과를 보였다"**로 조심스럽게 씁니다.
- 연구의 한계에 횡단 설계의 제약을 밝히고, 종단 연구가 필요함을 적습니다.

0장에서 "영향을 미친다"는 표현에 대해 했던 이야기가 매개분석에서 가장 중요해집니다.
:::

:::paper SPSS PROCESS 매크로와의 관계
학위논문에서는 Hayes의 **PROCESS 매크로**로 매개분석을 하는 경우가 많습니다. 이 장의 모형은 PROCESS의 **Model 4**이고, 위 `lavaan` 결과와 같은 계수와 (부트스트랩 난수에 따른 작은 차이를 빼면) 같은 신뢰구간을 줍니다. 8장의 조절효과는 **Model 1**, 10장의 조절된 매개는 **Model 7**입니다.

Hayes는 R용 PROCESS(`process.R`)도 공식 홈페이지에서 배포합니다. 이 책은 4권 구조방정식으로 이어지도록 `lavaan`을 씁니다.
:::

## 논문 결과표

**표 9. 소진의 매개효과**

| 경로 | *B* | *SE* | 95% CI | β |
| --- | --- | --- | --- | --- |
| 직무스트레스 → 소진 (*a*) | 0.602\*\*\* | 0.056 | [0.493, 0.712] | .551 |
| 소진 → 이직의도 (*b*) | 0.562\*\*\* | 0.069 | [0.424, 0.694] | .462 |
| 직무스트레스 → 이직의도 (*c*′, 직접효과) | 0.245\*\*\* | 0.069 | [0.110, 0.386] | .185 |
| 간접효과 (*a* × *b*) | 0.338 | 0.051 | [0.242, 0.442] | .254 |
| 총효과 (*c*) | 0.584\*\*\* | 0.069 | [0.453, 0.720] | .439 |
{.apa}

*주.* *N* = 300. 표준오차와 신뢰구간은 2,000회 부트스트랩의 백분위수 방식이며, 유의확률은 부트스트랩 표준오차로 계산하였다. 간접효과의 유의성은 신뢰구간으로 판단. \*\*\**p* < .001.

:::paper 결과 서술 예시
> 직무스트레스와 이직의도의 관계에서 소진의 매개효과를 검증하기 위해 `lavaan` 패키지로 매개모형을 추정하고, 간접효과의 유의성을 2,000회 부트스트랩의 백분위수 신뢰구간으로 검정하였다(표 9, 그림 9-2).
>
> 직무스트레스는 소진에 정적인 영향을 미쳤고(*B* = 0.602, *p* < .001), 직무스트레스를 통제한 상태에서 소진은 이직의도에 정적인 영향을 미쳤다(*B* = 0.562, *p* < .001). 소진을 통한 간접효과는 0.338로, 95% 신뢰구간 [0.242, 0.442]이 0을 포함하지 않아 유의하였다. 소진을 통제한 후에도 직무스트레스의 직접효과는 유의하였다(*B* = 0.245, *p* < .001). 즉, 직무스트레스는 이직의도에 직접 영향을 미칠 뿐 아니라 소진을 거쳐 간접적으로도 영향을 미쳤으며, 총효과의 약 58%가 소진을 통해 전달되었다.

경로도(그림 9-2 아래쪽)에 계수를 적어 함께 제시하면 독자가 한눈에 구조를 파악합니다.
:::

:::check 점검 항목
- 매개(어떻게)와 조절(언제)의 질문을 구분했다
- 화살표의 방향을 이론으로 정당화했다
- 간접효과 $a \times b$를 직접 검정했다(4단계 절차만으로 결론 내리지 않음)
- 부트스트랩 반복 횟수, 신뢰구간 방식, `set.seed()`를 밝혔다
- 간접효과·직접효과·총효과를 모두 신뢰구간과 함께 보고했다
- 완전/부분매개는 참고로만 쓰고, 횡단 설계의 한계를 밝혔다
:::

:::recap
**요약** — 매개분석은 총효과 $c$를 매개변수를 거치는 **간접효과 $a \times b$**와 거치지 않는 **직접효과 $c'$**로 나눕니다($c = c' + ab$). 간접효과는 곱이라서 표집분포가 치우치므로, **부트스트랩 신뢰구간**이 0을 포함하는지로 검정합니다. 계산은 회귀분석 세 개면 되지만, 화살표의 방향은 자료가 아니라 이론과 설계가 정당화해야 합니다.
:::
