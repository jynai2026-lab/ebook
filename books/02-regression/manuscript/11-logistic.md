## 종속변수가 0과 1이면

이 자료의 `quit`은 조사 1년 뒤 실제로 퇴사했으면 1, 재직 중이면 0입니다. 300명 가운데 63명(21%)이 퇴사했습니다. 이직의도가 높았던 사람이 실제로 더 많이 떠났을까요.

```r 퇴사 여부별 이직의도 평균
d <- read.csv("data/survey.csv")
table(d$quit)
tapply(d$turnover, d$quit, mean)
```

```out
  0   1 
237  63 
       0        1 
2.564346 3.317460
```

퇴사자의 이직의도 평균이 3.32점으로 재직자(2.56점)보다 높습니다. 그렇다면 지금까지처럼 `lm()`으로 회귀분석을 하면 될까요.

### 직선으로는 안 되는 이유

```r 0/1 종속변수에 직선을 적합하면
m_lin <- lm(quit ~ turnover, data = d)
coef(m_lin)
predict(m_lin, newdata = data.frame(turnover = c(1, 5)))
```

```out
(Intercept)    turnover 
 -0.2959035   0.1858231 
         1          2 
-0.1100803  0.6332122
```

이직의도가 1점인 사람의 예측값이 **−0.11**입니다. 퇴사 "확률"이 음수일 수는 없습니다. 이직의도가 아주 높은 사람이 있었다면 1을 넘는 확률도 나왔을 것입니다. 직선은 양쪽으로 끝없이 뻗지만 확률은 0과 1 사이에 갇혀 있기 때문입니다.

!fig[**그림 11-1** 0과 1뿐인 퇴사 여부에 직선(점선)과 S자 곡선(실선)을 적합한 결과. 직선은 0 아래로 내려가지만 S자 곡선은 0과 1 사이에 머문다. 점은 겹치지 않도록 위아래로 조금씩 흩었다.](ch11-linear-vs-logit.svg)

4장의 가정도 맞지 않습니다. 종속변수가 0과 1뿐이니 잔차는 정규분포가 될 수 없고, 예측값이 0.5 근처일 때 잔차가 가장 크게 흩어지므로 등분산도 깨집니다.

필요한 것은 **0과 1 사이에 머무는 S자 곡선**입니다.

## 확률을 로짓으로

S자 곡선을 회귀분석의 틀로 다루기 위해, 확률을 두 단계로 변환합니다.

**① 확률 → 오즈(odds).** 일어날 확률을 일어나지 않을 확률로 나눈 값입니다.

$$
\text{odds} = \frac{p}{1 - p}
$$ (퇴사할 확률이 퇴사하지 않을 확률의 몇 배인가)

퇴사율 21%라면 오즈는 $.21 / .79 = 0.27$입니다. "퇴사자 1명당 재직자 약 4명"이라는 뜻입니다. 오즈는 0에서 무한대까지 갑니다.

**② 오즈 → 로짓(logit).** 오즈에 자연로그를 씌웁니다.

$$
\text{logit}(p) = \ln\frac{p}{1 - p}
$$ (로그오즈. −∞에서 +∞까지 움직인다)

```r 확률, 오즈, 로짓의 관계
p <- c(.10, .21, .50, .79, .90)
data.frame(p, odds = round(p / (1 - p), 3), logit = round(log(p / (1 - p)), 3))
```

```out
     p  odds  logit
1 0.10 0.111 -2.197
2 0.21 0.266 -1.325
3 0.50 1.000  0.000
4 0.79 3.762  1.325
5 0.90 9.000  2.197
```

확률 .5가 로짓 0이고, .5보다 작으면 음수, 크면 양수입니다. 확률 .21과 .79의 로짓이 부호만 다르게 대칭입니다. 로짓은 **음의 무한대에서 양의 무한대까지** 움직이므로, 직선 회귀식을 그대로 받아 줄 수 있습니다.

!fig[**그림 11-2** 로짓과 확률의 관계. 로짓은 어떤 값이든 될 수 있지만, 확률로 되돌리면 언제나 0과 1 사이의 S자 곡선이 된다.](ch11-logit-map.svg)

## 로지스틱 회귀식

확률 대신 로짓을 직선으로 예측하는 것이 **로지스틱 회귀(logistic regression)**입니다.

$$
\ln\frac{p}{1 - p} = b_0 + b_1 X_1 + b_2 X_2
$$ (좌변이 로짓이라는 것만 다르고 우변은 지금까지의 회귀식과 같다)

R에서는 `lm()` 대신 `glm()`을 쓰고 `family = binomial`을 지정합니다. 이직의도와 직무만족으로 퇴사를 예측합니다.

```r 로지스틱 회귀
m_log <- glm(quit ~ turnover + satisfaction, family = binomial, data = d)
summary(m_log)
```

```out

    data = d)

satisfaction  -0.6835     0.2585  -2.645  0.00818 **
```

계수 옆의 검정이 $t$가 아니라 **$z$**(Wald 검정)입니다. 이직의도($z$ = 5.62, $p$ < .001)와 직무만족($z$ = −2.65, $p$ = .008) 모두 퇴사를 유의하게 예측합니다.

## 계수 읽기 — 오즈비

계수 1.232는 "이직의도가 1점 높으면 **로짓**이 1.232 높다"입니다. 로짓은 직관적으로 와닿지 않으므로 계수에 지수를 씌워 **오즈비(odds ratio, OR)**로 바꿉니다.

$$
OR = e^{b}
$$ (설명변수가 1 높을 때 오즈가 몇 배가 되는가)

```r 오즈비와 95% 신뢰구간
round(exp(cbind(OR = coef(m_log), confint(m_log))), 3)
```

```out
                OR 2.5 % 97.5 %
(Intercept)  0.061 0.007  0.473
turnover     3.428 2.268  5.377
satisfaction 0.505 0.299  0.828
```

| 변수 | *OR* | 읽는 법 |
| --- | --- | --- |
| 이직의도 | 3.428 | 만족이 같을 때, 이직의도가 1점 높으면 퇴사할 오즈가 **3.43배** |
| 직무만족 | 0.505 | 이직의도가 같을 때, 만족이 1점 높으면 퇴사할 오즈가 **0.51배**(약 절반) |
{.apa}

오즈비가 1이면 관계가 없다는 뜻입니다. 1보다 크면 오즈를 높이고, 작으면 낮춥니다. 그래서 **오즈비의 신뢰구간이 1을 포함하는지**가 유의성 판단 기준입니다. 이직의도 [2.27, 5.38], 직무만족 [0.30, 0.83] 모두 1을 포함하지 않습니다.

0.505처럼 1보다 작은 오즈비는 $(1 - 0.505) \times 100$ = **49.5% 감소**로 표현하기도 합니다.

:::warn 오즈비는 확률의 배수가 아닙니다
"이직의도가 1점 높으면 퇴사 확률이 3.43배"라고 쓰면 틀립니다. 3.43배가 되는 것은 **오즈**입니다. 확률로는 몇 배가 되는지 직접 계산해 봅니다.

```r 직무만족이 평균일 때 이직의도별 퇴사 확률
predict(m_log, newdata = data.frame(turnover = c(2, 3, 4),
                                    satisfaction = mean(d$satisfaction)),
        type = "response")
```

```out
         1          2          3 
0.07149714 0.20882797 0.47499757
```

이직의도 2점 → 3점에서 확률은 0.071 → 0.209로 2.9배, 3점 → 4점에서는 0.209 → 0.475로 2.3배입니다. **오즈비는 어디서나 3.43으로 같지만 확률의 배수는 위치마다 다릅니다.** S자 곡선의 기울기가 위치마다 다르기 때문입니다. 확률이 작을 때(10% 미만)만 오즈비와 확률의 배수가 비슷해집니다.

독자에게 효과의 크기를 전달하려면 이처럼 **대표적인 값에서의 예측 확률**을 함께 제시하는 것이 좋습니다.
:::

!fig[**그림 11-3** 직무만족이 평균일 때 이직의도에 따른 퇴사 예측 확률. 이직의도 2점에서 7%, 3점에서 21%, 4점에서 48%로 오른다.](ch11-prob.svg)

## 모형 전체 평가

### 우도비 검정

로지스틱 회귀에는 제곱합이 없습니다. 대신 **이탈도(deviance)**로 모형이 자료에서 얼마나 벗어나는지를 잽니다. `summary()` 아래쪽의 두 값입니다.

| 이탈도 | 값 | 의미 |
| --- | --- | --- |
| `Null deviance` | 308.37 | 설명변수 없이 퇴사율 21%만으로 예측했을 때 |
| `Residual deviance` | 256.75 | 이직의도와 만족으로 예측했을 때 |
{.apa}

두 값의 차이가 설명변수 덕분에 줄어든 이탈도이며, 카이제곱 분포를 따릅니다. 이것이 1~7장의 $F$검정에 해당하는 **우도비 검정(likelihood ratio test)**입니다.

```r 설명변수가 없는 모형과 비교 (우도비 검정)
m_null <- glm(quit ~ 1, family = binomial, data = d)
anova(m_null, m_log, test = "Chisq")
```

```out
Analysis of Deviance Table

Model 1: quit ~ 1
Model 2: quit ~ turnover + satisfaction
  Resid. Df Resid. Dev Df Deviance  Pr(>Chi)    
1       299     308.37                          
2       297     256.75  2   51.624 6.165e-12 ***
---
Signif. codes:  0 ‘***’ 0.001 ‘**’ 0.01 ‘*’ 0.05 ‘.’ 0.1 ‘ ’ 1
```

$\chi^2$(2) = 51.62, $p$ < .001. 두 설명변수가 퇴사 예측을 유의하게 개선합니다.

### 유사 결정계수

로지스틱 회귀에는 $R^2$이 없습니다. 비슷한 역할을 하는 지표가 여러 개 있으며 **유사 결정계수(pseudo $R^2$)**라 부릅니다.

```r 유사 결정계수와 적합도 검정
library(performance)
r2_nagelkerke(m_log)
r2_coxsnell(m_log)
performance_hosmer(m_log)
```

```out
Nagelkerke's R2 
      0.2461491 
Cox & Snell's R2 
       0.1580886 
# Hosmer-Lemeshow Goodness-of-Fit Test

  Chi-squared: 7.734
           df: 8    
      p-value: 0.460
```

Nagelkerke $R^2$ = .246, Cox & Snell $R^2$ = .158입니다. 학위논문에서는 Nagelkerke 값을 가장 많이 보고합니다.

:::warn 유사 $R^2$은 '설명된 분산'이 아닙니다
이름은 비슷하지만 1~3장의 $R^2$처럼 "변동의 몇 %를 설명한다"는 뜻이 아닙니다. 지표마다 값도 다르고, 일반적으로 OLS의 $R^2$보다 작게 나옵니다. 같은 지표끼리 모형을 비교하는 용도로 쓰고, ".25이므로 25%를 설명한다"라고 쓰지 않습니다.
:::

Hosmer-Lemeshow 검정은 예측 확률과 실제 비율이 맞는지를 봅니다. 1권 3장의 정규성 검정처럼 **$p$가 커야 좋은 검정**입니다. $p$ = .460이므로 모형이 자료와 잘 맞습니다.

## 분류표 — 몇 명을 맞혔나

예측 확률이 .5 이상이면 퇴사, 미만이면 재직으로 분류하고 실제와 비교합니다.

```r 분류표 (기준 0.5)
p_hat <- predict(m_log, type = "response")
table(실제 = d$quit, 예측 = ifelse(p_hat >= .5, 1, 0))
```

```out
    예측
실제   0   1
   0 228   9
   1  50  13
```

!fig[**그림 11-4** 분류표. 전체 정확도는 80.3%이지만, 실제 퇴사자 63명 가운데 맞힌 것은 13명(20.6%)뿐이다.](ch11-classification.svg)

| 지표 | 계산 | 값 |
| --- | --- | --- |
| 정확도 | (228 + 13) / 300 | 80.3% |
| 민감도 (퇴사자를 퇴사로) | 13 / 63 | 20.6% |
| 특이도 (재직자를 재직으로) | 228 / 237 | 96.2% |
{.apa}

정확도 80.3%는 좋아 보입니다. 그러나 **모두 "재직"으로 찍어도 79%**(237 / 300)를 맞힙니다. 모형이 더한 것은 1.3%p입니다. 그리고 정작 알고 싶은 퇴사자는 다섯 명 중 한 명만 맞혔습니다.

:::key 결과가 드물면 정확도는 믿을 만한 지표가 아닙니다
퇴사율이 21%이므로 예측 확률이 .5를 넘는 사람이 원래 적습니다. 그래서 대부분을 재직으로 분류하고, 정확도는 높지만 퇴사자는 놓칩니다.

로지스틱 회귀의 목적이 **분류**가 아니라 **관계의 크기를 추정**하는 것이라면 분류표는 보조 자료입니다. 이직의도의 오즈비 3.43과 예측 확률의 변화가 이 연구의 핵심 결과이고, 그것은 분류 정확도와 상관없이 유효합니다. 분류가 목적이라면 기준값을 퇴사율(.21) 근처로 낮추거나, 민감도와 특이도를 함께 보는 ROC 분석을 씁니다.
:::

## 가정과 주의할 점

로지스틱 회귀에는 정규성과 등분산 가정이 없습니다. 대신 다음을 확인합니다.

- **독립성** — 4장과 같습니다. 자료 수집 방식이 결정합니다.
- **로짓과의 선형성** — 연속 설명변수가 확률이 아니라 **로짓**과 직선 관계여야 합니다. 의심되면 4장처럼 이차항을 넣어 확인합니다.
- **다중공선성** — 5장과 같습니다. `car::vif()`가 `glm` 모형에도 작동합니다.
- **사례 수** — 사건(여기서는 퇴사)의 수가 중요합니다. 설명변수 하나당 사건이 **최소 10건**은 있어야 한다는 경험 규칙(Peduzzi et al., 1996)이 흔히 인용됩니다. 퇴사 63건, 설명변수 2개이므로 31.5건으로 충분합니다. 300명이어도 퇴사자가 15명뿐이라면 설명변수를 하나만 넣을 수 있습니다.

:::paper 결과 서술 예시
> 이직의도와 직무만족이 1년 후 실제 퇴사에 미치는 영향을 검증하기 위해 로지스틱 회귀분석을 실시하였다(표 11). 모형은 통계적으로 유의하였으며(χ²(2) = 51.62, *p* < .001, Nagelkerke *R*² = .246), Hosmer-Lemeshow 검정 결과 모형의 적합도가 양호하였다(χ²(8) = 7.73, *p* = .460).
>
> 직무만족을 통제한 상태에서 이직의도가 1점 높을수록 퇴사할 오즈가 3.43배 증가하였고(*OR* = 3.43, 95% CI [2.27, 5.38]), 이직의도를 통제한 상태에서 직무만족이 1점 높을수록 퇴사할 오즈가 49.5% 감소하였다(*OR* = 0.51, 95% CI [0.30, 0.83]). 직무만족이 평균일 때 퇴사 예측 확률은 이직의도 2점에서 7.1%, 3점에서 20.9%, 4점에서 47.5%였다.
:::

- 대표적인 값에서 예측 확률을 함께 제시했다
- 우도비 검정, 유사 $R^2$(어느 지표인지 명시), 적합도 검정을 보고했다
- 분류표를 볼 때 기저율과 민감도를 함께 봤다
- 설명변수당 사건 수가 10건 이상인지 확인했다
:::

**요약** — 종속변수가 두 범주이면 확률을 **로짓**(로그오즈)으로 바꿔 직선으로 예측하는 로지스틱 회귀를 씁니다. 계수에 지수를 씌운 **오즈비**는 설명변수가 1 높을 때 오즈가 몇 배가 되는지를 나타내며, 확률의 배수와는 다릅니다. 모형 평가는 이탈도와 우도비 검정, 유사 $R^2$으로 하고, 결과가 드물면 분류 정확도에 속지 않도록 기저율과 민감도를 함께 봅니다.
