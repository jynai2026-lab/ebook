## 이상한 결과 하나

이 자료에는 **업무과부하**(`workload`)라는 변수가 있습니다. "처리해야 할 일이 너무 많다"는 정도를 잰 것입니다. 업무과부하가 높은 사람이 소진도 높으리라는 것은 상식입니다. 실제로 상관이 .46입니다.

직무스트레스, 업무과부하, 사회적지지를 함께 넣어 소진을 회귀분석합니다.

```r 업무과부하를 함께 넣은 모형
library(car)
d <- read.csv("data/survey.csv")
m_both <- lm(burnout ~ stress + workload + support, data = d)
round(summary(m_both)$coefficients, 3)
```

```out
            Estimate Std. Error t value Pr(>|t|)
(Intercept)    2.250      0.276   8.140    0.000
stress         0.694      0.110   6.280    0.000
workload      -0.155      0.100  -1.554    0.121
support       -0.288      0.054  -5.367    0.000
```

업무과부하의 계수가 **−0.155**입니다. "다른 변수가 같다면 업무가 많을수록 덜 소진된다"는 결과입니다. 유의하지는 않지만($p$ = .121) 부호부터 상식과 반대입니다.

비교를 위해 업무과부하를 빼고, 또 스트레스를 빼고 돌려 봅니다.

```r 둘 중 하나씩만 넣은 모형
m_stress <- lm(burnout ~ stress + support, data = d)
m_load   <- lm(burnout ~ workload + support, data = d)
round(summary(m_stress)$coefficients, 3)
round(summary(m_load)$coefficients, 3)
```

```out
            Estimate Std. Error t value Pr(>|t|)
(Intercept)    2.190      0.274   7.982        0
stress         0.542      0.052  10.456        0
support       -0.284      0.054  -5.294        0
            Estimate Std. Error t value Pr(>|t|)
(Intercept)    2.626      0.287   9.156        0
workload       0.400      0.050   8.030        0
support       -0.309      0.057  -5.443        0
```

| | 스트레스만 | 업무과부하만 | 둘 다 |
| --- | --- | --- | --- |
| 스트레스 $b$ (*SE*) | 0.542 (0.052) | | **0.694 (0.110)** |
| 업무과부하 $b$ (*SE*) | | 0.400 (0.050) | **−0.155 (0.100)** |
| $R^2$ | .363 | .284 | .368 |
{.apa}

따로 넣으면 둘 다 소진과 뚜렷한 정적 관계입니다. 함께 넣으면 다음 네 가지가 동시에 일어납니다.

1. 업무과부하의 **부호가 뒤집힙니다.**
2. 두 변수의 **표준오차가 두 배로 커집니다**(0.052 → 0.110, 0.050 → 0.100).
3. 스트레스 계수는 오히려 **부풀었습니다**(0.542 → 0.694).
4. 그런데 $R^2$은 .363에서 .368로 **거의 늘지 않습니다.**

이것이 **다중공선성(multicollinearity)**의 전형적인 증상입니다. 원인은 하나입니다. 두 변수의 상관이 **.89**입니다.

!fig[**그림 5-1** 업무과부하를 따로 넣었을 때와 스트레스와 함께 넣었을 때의 계수와 95% 신뢰구간. 함께 넣으면 구간이 두 배로 넓어지고 업무과부하의 부호가 뒤집힌다.](ch05-coef-ci.svg)

## 왜 이런 일이 생기는가

3장의 핵심을 떠올립니다. 다중회귀 계수는 **그 변수에서 다른 독립변수들과 겹치는 부분을 걷어 내고 남은 고유한 부분**으로 구한 기울기였습니다.

스트레스와 업무과부하는 상관이 .89입니다. 스트레스에서 업무과부하(와 지지)로 예측되는 부분을 걷어 내면 얼마나 남을까요.

```r 스트레스가 다른 두 변수로 얼마나 설명되는가
summary(lm(stress ~ workload + support, data = d))$r.squared
```

```out
[1] 0.7910769
```

스트레스 변동의 **79%가 다른 두 변수와 겹칩니다.** 걷어 내고 남는 고유한 부분은 21%뿐입니다. 300명의 정보로 기울기를 구하는 것이 아니라, 그 21%의 좁은 정보로 기울기를 구하는 셈입니다.

!fig[**그림 5-2** 스트레스와 업무과부하의 변동이 대부분 겹친다. 다중회귀 계수는 겹치지 않는 가장자리(빗금)만으로 계산되므로, 정보가 적어 표본마다 크게 흔들린다. (개념도)](ch05-overlap.svg)

정보가 적으면 추정이 불안정해집니다. **표준오차가 커지는 것**이 그 불안정성의 표현입니다. 부호가 뒤집힌 것도 같은 이유입니다. 고유한 부분이 좁으면 그 안의 우연한 흔들림이 계수를 반대쪽으로 끌고 갈 수 있습니다. 두 변수가 거의 같은 정보를 가지고 있으니, 한쪽이 크게 양수가 되면 다른 쪽이 음수가 되어 합을 맞추는 일도 생깁니다. 스트레스 계수가 부푼 것이 그 짝입니다.

:::key 다중공선성은 "틀린 계산"이 아니라 "정보 부족"입니다
계수는 여전히 치우치지 않은 추정치입니다. 다만 **두 변수의 효과를 서로 떼어 낼 정보가 자료에 별로 없습니다.** 그래서 각자의 몫을 정확히 나누지 못하고, 그 불확실성이 큰 표준오차로 나타납니다.

반대로 **둘을 합친 설명력은 정확히 추정됩니다.** $R^2$이 거의 그대로였던 이유입니다. 예측이 목적이라면 다중공선성은 큰 문제가 아닙니다. 각 변수의 고유한 효과를 해석하는 것이 목적일 때 문제가 됩니다.
:::

## 분산팽창지수 (VIF)

위에서 구한 79%를 이용하면 표준오차가 얼마나 부풀었는지 계산할 수 있습니다.

$$
\text{VIF}_j = \frac{1}{1 - R^2_j}
$$ ($R^2_j$는 $j$번째 독립변수를 나머지 독립변수들로 회귀했을 때의 결정계수)

스트레스의 VIF는 $1 / (1 - .791) = 4.79$입니다. 이 값을 **분산팽창지수(variance inflation factor, VIF)**라 합니다. 다른 독립변수와 전혀 겹치지 않을 때보다 **계수의 분산이 4.79배** 크다는 뜻입니다. 표준오차로는 그 제곱근인 $\sqrt{4.79}$ = 2.19배입니다.

```r 분산팽창지수
vif(m_both)
vif(m_stress)
```

```out
  stress workload  support 
4.786450 4.774919 1.051269 
  stress  support 
1.049424 1.049424
```

업무과부하를 넣은 모형에서는 스트레스와 업무과부하의 VIF가 4.8 안팎이고, 빼면 1.05로 떨어집니다. 표준오차가 0.052에서 0.110으로 2.1배가 된 것과 맞아떨어집니다.

!fig[**그림 5-3** 두 독립변수의 상관에 따른 VIF와 표준오차 배율($\sqrt{\text{VIF}}$). 상관이 .8을 넘으면 급격히 커진다. 이 자료의 .89는 표준오차를 2.2배로 부풀린다.](ch05-vif-curve.svg)

| 기준 | 해석 |
| --- | --- |
| VIF < 2.5 | 문제없음 |
| 2.5 ~ 5 | 주의. 해석에 영향이 있는지 확인 |
| 5 ~ 10 | 다중공선성이 상당함 |
| VIF ≥ 10 | 심각 |
{.apa}

공차(tolerance)는 VIF의 역수($1 - R^2_j$)입니다. SPSS가 함께 출력하며 .10 미만을 심각한 수준으로 봅니다(VIF 10 초과와 같은 기준).

:::warn "VIF가 10 미만이므로 다중공선성은 없었다"
학위논문에서 가장 자주 보는 문장입니다. 이 장의 예에서 VIF는 4.79로 그 기준에 한참 못 미칩니다. 그런데도 **부호가 뒤집히고 표준오차가 두 배가 되었습니다.**

VIF 10은 "이 정도면 누구나 문제라고 할 수준"이지 "이 아래면 괜찮다"는 보증이 아닙니다. VIF와 함께 **증상**을 봅니다. 상관표에서 독립변수끼리 .80을 넘는 쌍이 있는지, 단순회귀와 부호가 반대인 계수가 있는지, 개념적으로 같은 것을 두 번 잰 변수가 있는지입니다.
:::

## 표본이 바뀌면

다중공선성이 만드는 불안정성을 직접 확인해 봅니다. 300명을 무작위로 150명씩 둘로 나눠 같은 모형을 따로 돌립니다.

```r 무작위로 나눈 두 절반에서 같은 모형
set.seed(1)
i <- sample(nrow(d), 150)
A <- d[i, ]; B <- d[-i, ]

f_both <- burnout ~ stress + workload + support
round(rbind(A = coef(lm(f_both, data = A)), B = coef(lm(f_both, data = B))), 3)

f_one <- burnout ~ stress + support
round(rbind(A = coef(lm(f_one, data = A)), B = coef(lm(f_one, data = B))), 3)
```

```out
  (Intercept) stress workload support
A       2.177  0.875   -0.305  -0.265
B       2.304  0.462    0.040  -0.307
  (Intercept) stress support
A       2.089  0.575  -0.262
B       2.322  0.501  -0.308
```

업무과부하를 넣은 모형에서는 절반 A와 B의 계수가 크게 다릅니다. 스트레스는 0.875와 0.462, 업무과부하는 −0.305와 +0.040으로 **부호까지 바뀝니다.** 업무과부하를 뺀 모형에서는 스트레스 계수가 두 절반에서 비슷합니다.

!fig[**그림 5-4** 같은 자료를 무작위로 둘로 나눠 얻은 계수. 업무과부하를 함께 넣으면 두 절반의 계수가 크게 벌어지고, 빼면 가까이 붙는다.](ch05-split.svg)

같은 모집단에서 뽑은 두 표본이 이렇게 다른 답을 내놓는다면, **어느 쪽 계수도 그 자체로 해석하기 어렵습니다.** 다중공선성이 문제인 진짜 이유는 표준오차라는 숫자가 아니라 이 불안정성입니다.

## 따로는 유의하지 않아도 함께는

업무과부하는 다중회귀에서 유의하지 않았습니다. 그러면 업무과부하는 소진과 무관한 것일까요. 스트레스와 업무과부하를 **함께 빼면** 모형이 얼마나 나빠지는지 봅니다.

```r 두 변수를 함께 뺐을 때의 F검정
anova(lm(burnout ~ support, data = d), m_both)
```

```out
Analysis of Variance Table

  Res.Df     RSS Df Sum of Sq      F    Pr(>F)    
1    298 118.850                                  
2    296  86.169  2    32.681 56.132 < 2.2e-16 ***
---

```

$F$(2, 296) = 56.13, $p$ < .001입니다. **둘이 함께는 소진을 강하게 설명합니다.** 개별 $t$검정이 유의하지 않은 것은 "둘 중 누구의 몫인지 가를 수 없다"는 뜻이지 "둘 다 상관없다"는 뜻이 아닙니다.

## 어떻게 할 것인가

정답은 하나가 아니라, **두 변수가 무엇이고 연구 질문이 무엇인지**에 따라 정해집니다.

**① 같은 개념을 두 번 잰 것이라면 — 하나만 넣거나 합칩니다.**

업무과부하는 직무스트레스의 주요 원천이어서 문항 내용도 겹칩니다. 이론적으로 둘을 구분할 이유가 약하다면 연구 질문에 더 맞는 하나를 고릅니다. 둘 다 버리기 아깝다면 표준화한 뒤 평균을 내 **합성 변수**로 만듭니다.

```r 두 변수를 표준화해 평균 낸 합성 변수
d$load <- (scale(d$stress) + scale(d$workload)) / 2
m_comp <- lm(burnout ~ load + support, data = d)
round(summary(m_comp)$coefficients, 3)
vif(m_comp)
```

```out
            Estimate Std. Error t value Pr(>|t|)
(Intercept)    3.881      0.196  19.793        0
load           0.322      0.034   9.553        0
support       -0.290      0.055  -5.280        0
    load  support 
1.051126 1.051126
```

합성 변수의 계수는 0.322로 안정적이고 VIF는 1.05입니다. 다만 이제 계수는 스트레스도 업무과부하도 아닌 **"업무 부담"**이라는 새 개념의 효과이므로, 그 개념을 정의하고 이름 붙여 보고해야 합니다. 두 척도를 하나로 묶어도 되는지는 3권의 요인분석이 답하는 질문입니다.

**② 통제변수끼리 겹친다면 — 그대로 둡니다.**

7장에서 연령과 근속연수를 통제변수로 함께 넣습니다. 두 변수는 상관이 .86이고 VIF가 3.8 정도 됩니다. 그러나 연령과 근속연수 각각의 계수를 해석할 것이 아니라 **둘을 함께 통제하는 것**이 목적이므로 문제가 되지 않습니다. 다중공선성은 겹치는 변수들 사이에서만 일어나며, 다른 변수의 계수에는 영향을 주지 않습니다.

**③ 서로 다른 개념이고 둘 다 연구 질문이라면 — 넣고, 한계를 밝힙니다.**

두 변수의 고유한 효과를 구분하는 것 자체가 연구 질문이라면 하나를 빼는 것은 질문을 바꾸는 것입니다. 이 경우에는 그대로 넣고, 넓은 신뢰구간을 그대로 보고하고, 개별 계수보다 **두 변수의 공동 기여**(위의 $F$검정)를 함께 제시합니다. 표본을 늘리는 것도 근본적인 해결책입니다.

:::warn 하지 말아야 할 것
- **유의하지 않은 쪽을 지우기.** 표본의 우연이 결정하게 됩니다. 위의 두 절반처럼 다른 표본이었다면 지워진 변수가 달랐을 것입니다.
- **부호가 이상한 계수를 그대로 해석하기.** "업무과부하는 소진을 줄인다"고 쓰면 안 됩니다.
- **중심화로 해결하려 하기.** 평균 중심화는 VIF를 바꾸지 않습니다. 단, 8장의 **상호작용항**처럼 변수를 곱해 만든 항의 공선성은 중심화로 줄어듭니다. 이 둘은 다른 문제입니다.
:::

## 논문에 쓰는 법

:::paper 결과 서술 예시
> 독립변수 간 다중공선성을 확인하기 위해 분산팽창지수(VIF)를 산출하였다. 직무스트레스와 업무과부하의 상관이 .89로 높았고, 두 변수를 함께 투입한 모형에서 VIF가 각각 4.79, 4.77로 나타났으며 업무과부하의 회귀계수가 단순상관과 반대 부호를 보였다. 두 변수는 개념적으로 중첩되므로 이후 분석에서는 직무스트레스만을 투입하였다.

다중공선성이 없을 때는 한 문장으로 충분합니다.

> 모든 독립변수의 VIF가 1.06~1.15로 다중공선성의 문제는 없었다.

3장 모형(스트레스, 지지, 효능감)의 실제 값입니다.
:::

**요약** — 다중공선성은 독립변수끼리 너무 닮아서 **각자의 고유한 몫을 가를 정보가 부족한 상태**입니다. 계수의 표준오차가 $\sqrt{\text{VIF}}$배로 커지고, 표본마다 계수가 크게 흔들리며 부호가 뒤집히기도 합니다. 함께 가진 설명력은 정확하므로 예측에는 문제가 적고, 개별 효과를 해석할 때 문제가 됩니다. 해결은 통계가 아니라 **두 변수가 무엇인지**에서 출발합니다.
