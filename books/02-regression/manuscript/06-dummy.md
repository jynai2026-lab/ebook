## 범주를 숫자로 넣으면 안 되는 이유

직급에 따라 직무만족이 다를까요. 직급은 사원, 대리, 과장이상의 세 범주입니다.

가장 먼저 떠오르는 방법은 사원 = 1, 대리 = 2, 과장이상 = 3으로 숫자를 매겨 회귀분석에 넣는 것입니다. 그러나 이렇게 하면 회귀분석은 이 숫자를 **등간척도**로 받아들입니다. 1권 1장에서 다룬 척도 구분이 여기서 문제가 됩니다.

- 사원 → 대리의 차이와 대리 → 과장이상의 차이가 **같다고** 가정하게 됩니다.
- 범주에 순서가 없는 경우(부서: 영업, 생산, 연구)라면 숫자 자체가 의미가 없습니다. 영업 = 1, 생산 = 2로 매길지 반대로 매길지에 따라 결과가 달라집니다.

필요한 것은 **"어느 범주에 속하는가"만을 담는 숫자**입니다.

## 더미변수

범주마다 "여기에 속하면 1, 아니면 0"인 변수를 만듭니다. 이것을 **더미변수(dummy variable)**라 합니다. 범주가 $k$개면 더미변수는 $k-1$개를 만듭니다.

| 직급 | $D_{\text{대리}}$ | $D_{\text{과장이상}}$ |
| --- | --- | --- |
| 사원 | 0 | 0 |
| 대리 | 1 | 0 |
| 과장이상 | 0 | 1 |
{.apa}

사원에게는 더미변수가 없습니다. 두 더미가 모두 0이면 사원입니다. 이렇게 **모든 더미가 0인 범주를 기준 집단(reference group)**이라 합니다. 더미를 $k$개 만들지 않는 이유는, 세 번째 더미가 앞의 두 더미로 완전히 결정되기 때문입니다($D_{\text{사원}} = 1 - D_{\text{대리}} - D_{\text{과장이상}}$). 5장의 다중공선성이 극단으로 간 상태여서 계산이 불가능합니다.

R에서는 범주형 변수를 `factor`로 만들어 두면 더미변수를 자동으로 만듭니다. **첫 번째 수준이 기준 집단**이 됩니다.

```r 직급을 factor로, 사원이 첫 번째(기준)가 되도록
d <- read.csv("data/survey.csv")
d$position <- factor(d$position, levels = c("사원", "대리", "과장이상"))
tapply(d$satisfaction, d$position, mean)
```

```out
    사원     대리 과장이상 
3.057692 3.250000 3.550000
```

`levels`를 지정하지 않으면 R은 가나다순으로 정렬해 과장이상이 기준 집단이 됩니다. 기준을 의도대로 정하는 습관을 들이십시오.

첫 번째 사람은 대리라서 `position대리` 열이 1, 두 번째 사람은 과장이상이라서 `position과장이상` 열이 1입니다. 회귀식은 이렇습니다.

$$
\widehat{\text{만족}} = 3.058 + 0.192 \times D_{\text{대리}} + 0.492 \times D_{\text{과장이상}}
$$

직급마다 더미 값을 넣어 보면 계수의 의미가 드러납니다.

| 직급 | 대입 | 예측값 | 실제 평균 |
| --- | --- | --- | --- |
| 사원 | $3.058 + 0 + 0$ | 3.058 | 3.058 |
| 대리 | $3.058 + 0.192$ | 3.250 | 3.250 |
| 과장이상 | $3.058 + 0.492$ | 3.550 | 3.550 |
{.apa}

:::key 더미변수의 계수는 평균의 차이입니다
**절편**은 기준 집단(사원)의 평균입니다. **각 더미의 계수**는 그 집단의 평균이 기준 집단보다 얼마나 높은지입니다.

- `position대리` 0.192 = 대리 평균 − 사원 평균
- `position과장이상` 0.492 = 과장이상 평균 − 사원 평균

계수 옆의 $t$검정은 "그 집단과 기준 집단의 평균이 같은가"를 검정합니다. 대리와 사원의 차이는 $p$ = .030, 과장이상과 사원의 차이는 $p$ < .001입니다.
:::

`summary()` 마지막 줄을 보십시오. $F$(2, 297) = 14.82, $p$ < .001. 1권 9장의 일원분산분석을 그대로 돌려 봅니다.


**$F$값, 자유도, 유의확률이 모두 같습니다.** 우연이 아닙니다. 분산분석은 독립변수가 더미변수뿐인 회귀분석입니다.

| | 분산분석 | 회귀분석 |
| --- | --- | --- |
| 집단 간 제곱합 | $SS_B$ = 11.93 | $SS_R$ = 11.93 |
| 집단 내 제곱합 | $SS_W$ = 119.60 | $SS_E$ = 119.60 |
| 설명된 비율 | $\eta^2$ = .091 | $R^2$ = .091 |
{.apa}

1권 9장에서 "$\eta^2$은 회귀분석의 $R^2$과 같은 개념"이라고 했던 것이 여기서 확인됩니다. 같은 개념이 아니라 **같은 숫자**입니다.

### $t$-검정은 더미 하나짜리 회귀입니다

집단이 둘이면 더미변수가 하나입니다. 1권 7장의 자아존중감 자료로 확인합니다.

```r 1권 7장 자료: t-검정과 회귀분석
df <- read.csv("data/sample_data.csv")
df$gender <- factor(df$gender, levels = c(1, 2), labels = c("남성", "여성"))

t.test(selfesteem ~ gender, data = df, var.equal = TRUE)$statistic
summary(lm(selfesteem ~ gender, data = df))$coefficients
```


$t$의 크기 3.934와 유의확률 .0001095가 같습니다. 부호만 다른데, $t$-검정은 남성 − 여성을, 회귀분석은 여성 − 남성(기준 집단이 남성)을 계산했기 때문입니다. 회귀계수 0.411은 1권에서 구한 두 평균의 차이(3.6995 − 3.2882)입니다.

:::key 하나의 모형, 여러 이름
1권과 2권에서 배운 분석은 대부분 **같은 모형의 다른 모습**입니다.

| 독립변수 | 분석 이름 |
| --- | --- |
| 집단 2개 | 독립표본 $t$-검정 = 더미 1개 회귀 |
| 집단 3개 이상 | 일원분산분석 = 더미 여러 개 회귀 |
| 연속변수 1개 | 단순회귀 |
| 연속변수 여러 개 | 다중회귀 |
| 집단 + 연속변수 | 공분산분석 = 더미와 연속변수를 함께 넣은 회귀 |
{.apa}

통계학에서는 이 모두를 **일반선형모형(general linear model)**이라는 하나의 이름으로 부릅니다. R이 `t.test()`, `aov()`, `lm()`에 모두 같은 `y ~ x` 문법을 쓰는 이유입니다.
:::

## 기준 집단 바꾸기

기준 집단을 과장이상으로 바꾸면 계수가 달라집니다.

```r 과장이상을 기준으로
d$position_m <- relevel(d$position, ref = "과장이상")
coef(lm(satisfaction ~ position_m, data = d))
```

```out
   (Intercept) position_m사원 position_m대리 
     3.5500000     -0.4923077     -0.3000000
```

절편이 과장이상의 평균 3.55가 되고, 두 계수는 사원과 대리가 과장이상보다 **낮은** 만큼(−0.492, −0.300)이 됩니다. 모형 자체는 바뀌지 않습니다. $R^2$, $F$, 각 집단의 예측값이 모두 같습니다. **기준 집단은 어떤 비교를 계수로 보고 싶은지에 따라 고릅니다.** 보통은 가장 큰 집단, 통제 집단, 또는 이론적 출발점(가장 낮은 직급)을 기준으로 삼습니다.

## 모든 쌍을 비교하려면

기준 집단이 사원이면 계수는 "사원 대 대리", "사원 대 과장이상"만 보여줍니다. 대리와 과장이상의 비교는 없습니다. 세 쌍을 모두 비교하려면 1권 10장의 다중비교가 필요합니다. `emmeans` 패키지가 회귀모형에서 바로 Tukey 비교를 해 줍니다.

```r 회귀모형에서 Tukey 다중비교
library(emmeans)
emmeans(m_pos, pairwise ~ position)
```

`$contrasts`의 세 줄이 Tukey 방법으로 보정한 비교입니다. 사원과 대리의 차이는 더미의 $t$검정에서 $p$ = .030이었지만 **보정 후에는 $p$ = .075**로 유의하지 않습니다. 비교를 세 번 하므로 오류 누적을 막는 대가입니다. 1권 10장에서 본 그대로입니다.

:::warn 더미의 $t$검정만으로 "직급 차이가 있다"고 하지 않습니다
"직급이 직무만족과 관련이 있는가"는 **두 더미를 함께** 검정하는 질문입니다. 위의 $F$(2, 297) = 14.82가 그 답입니다. 개별 더미의 $t$검정은 기준 집단과의 비교일 뿐이라서, 기준 집단을 바꾸면 결과가 달라집니다.

순서는 1권 9~10장과 같습니다. **먼저 $F$검정으로 범주 전체의 효과를 확인하고, 유의하면 다중비교로 어느 쌍이 다른지 봅니다.**
:::

## 연속변수와 함께 넣기

더미변수는 연속변수와 함께 넣을 수 있습니다. 직급이 높으면 만족이 높은 이유가 **소진이 덜해서**일 수도 있습니다. 소진을 함께 넣어 봅니다.

```r 직급과 소진을 함께
m_both <- lm(satisfaction ~ position + burnout, data = d)
round(summary(m_both)$coefficients, 3)
anova(lm(satisfaction ~ burnout, data = d), m_both)
```

```out

  Res.Df     RSS Df Sum of Sq      F    Pr(>F)

```

3장의 해석이 그대로 적용됩니다. `position과장이상` 0.424는 **"소진 수준이 같다면, 과장이상이 사원보다 만족이 0.42점 높다"**입니다. 소진을 넣기 전의 0.492보다 조금 줄었습니다. 직급 차이의 일부가 소진 차이로 설명된 것입니다.

직급 전체의 효과는 `anova()`로 두 더미를 함께 검정합니다. 소진을 통제해도 **$F$(2, 296) = 13.32, $p$ < .001**로 직급의 효과가 유의합니다. 1권에서 다루지 않은 **공분산분석(ANCOVA)**이 바로 이것입니다. 집단 비교에 연속변수를 통제변수로 더한 회귀분석입니다.

## 이분 변수는 0과 1로

성별처럼 범주가 둘인 변수는 직접 0과 1로 만들어 넣어도 됩니다. 어느 쪽을 1로 했는지를 반드시 밝힙니다.

```r 성별을 0과 1로
d$female <- ifelse(d$gender == "여", 1, 0)
coef(lm(burnout ~ female, data = d))
```

```out
(Intercept)      female 
 2.82743750  0.06863393
```

`female`의 계수 0.069는 여성의 소진이 남성보다 0.07점 높다는 뜻입니다(유의하지 않음). 결과표에는 "성별(0 = 남, 1 = 여)"처럼 코딩을 함께 적습니다. 그래야 독자가 계수의 부호를 해석할 수 있습니다.

더미변수에는 표준화 계수 β를 보고하지 않는 편이 좋습니다. 0과 1뿐인 변수에서 "1 표준편차 높다"는 말은 의미가 없기 때문입니다.

**요약** — 범주형 변수는 **더미변수**로 바꿔 회귀분석에 넣습니다. 절편은 기준 집단의 평균, 더미의 계수는 기준 집단과의 평균 차이입니다. 이렇게 하면 $t$-검정은 더미 하나, 분산분석은 더미 여러 개, 공분산분석은 더미와 연속변수를 함께 넣은 회귀분석이 됩니다. 1권과 2권의 분석은 모두 **일반선형모형** 하나의 다른 모습입니다.
