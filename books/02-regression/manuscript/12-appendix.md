## 분석 선택 흐름도

분석 방법을 정하지 못할 때는 **종속변수의 척도**에서 시작해 **무엇을 묻고 싶은지**로 내려갑니다.

!fig[**그림 12-1** 2권의 분석 선택 흐름도. 종속변수가 연속형이면 묻는 질문에 따라 분석이 정해지고, 0과 1뿐이면 로지스틱 회귀로 간다. 어느 회귀분석이든 4장의 진단과 5장의 다중공선성 점검을 거친다.](ch12-flowchart.svg)

**① 종속변수가 연속형인가 이분형인가** — 연속형이면 `lm()`, 0과 1이면 `glm(family = binomial)`입니다.
**② 독립변수에 범주형이 있는가** — 있으면 더미변수로 바꿉니다(6장). 어느 분석에서든 같습니다.
**③ 무엇을 묻는가** — 관계의 크기(2~3장), 추가 설명력(7장), 조건에 따른 차이(8장), 경로(9장), 둘의 결합(10장).

## 분석 비교표

| 분석 | 핵심 질문 | 핵심 값 | 검정 | 효과크기 | 장 |
| --- | --- | --- | --- | --- | --- |
| 상관 | 함께 움직이는가 | $r$ | $t$ (df = $n-2$) | $r$, $r^2$ | 1장 |
| 단순회귀 | 1 높으면 얼마나 | $b_1$ | $t$, $F$ | $R^2$, $\beta$ | 2장 |
| 다중회귀 | 다른 변수가 같을 때 | $b_j$ | $t$, 모형 $F$ | $R^2$, 수정 $R^2$, $\beta$, $sr^2$ | 3장 |
| 더미 회귀 | 기준 집단과의 차이 | 더미 계수 | $t$, 범주 전체 $F$ | $R^2$ (= $\eta^2$) | 6장 |
| 위계적 회귀 | 묶음이 더 설명하는가 | $\Delta R^2$ | $F$ 변화량 | $\Delta R^2$, $f^2$ | 7장 |
| 조절 | 언제, 누구에게 | $b_3$ (곱하기 항) | $t$, $\Delta R^2$ | $\Delta R^2$, $f^2$ | 8장 |

| 조절된 매개 | 경로가 조건에 따라 | $a_3 \times b$ | 부트스트랩 CI | 조건부 간접효과 | 10장 |
| 로지스틱 | 예/아니오의 오즈 | $e^{b}$ (OR) | Wald $z$, 우도비 $\chi^2$ | OR, 유사 $R^2$ | 11장 |

## R 코드 모음

코드는 이 책의 자료(`survey.csv`)에 그대로 돌아가도록 적었습니다. 변수명만 바꿔 쓰십시오.

### 자료 준비

<!-- norun -->
```r 분석을 시작할 때
d <- read.csv("data/survey.csv")
str(d)                                         # 변수 형태 확인
colSums(is.na(d))                              # 변수별 결측 수

d$position <- factor(d$position,               # 범주형은 factor로, 기준 집단을 첫 번째로
                     levels = c("사원", "대리", "과장이상"))
d$female <- ifelse(d$gender == "여", 1, 0)     # 이분 변수는 0/1로

vars <- c("burnout", "stress", "support", "efficacy", "female", "age", "tenure")
d_c <- na.omit(d[, c(vars, "turnover", "position")])   # 모든 모형을 같은 사례로
```

### 상관

<!-- norun -->
```r 상관행렬과 산점도
library(psych)
v <- d[, c("stress", "support", "efficacy", "burnout", "turnover")]
pairs(v)                                       # 모든 쌍의 산점도
ct <- corr.test(v, adjust = "none")
round(ct$r, 2); round(ct$p, 3)
cor.test(d$stress, d$burnout)                  # 한 쌍의 검정과 신뢰구간
cor.test(d$stress, d$burnout, method = "spearman", exact = FALSE)
```

### 회귀분석과 해석

<!-- norun -->
```r 단순·다중회귀
fit <- lm(burnout ~ stress + support + efficacy, data = d)
summary(fit)                                   # 계수, R², F
confint(fit)                                   # 계수의 신뢰구간
library(effectsize)
standardize_parameters(fit)                    # 표준화 계수 β

predict(fit, newdata = data.frame(stress = 4, support = 3.5, efficacy = 3.6),
        interval = "confidence")               # 평균의 신뢰구간 ("prediction"은 개인)
```

### 진단

<!-- norun -->
```r 가정과 영향점
library(car); library(lmtest); library(sandwich)
par(mfrow = c(2, 2)); plot(fit)                # 기본 진단 그림 네 장
residualPlots(fit)                             # 곡선 검정
shapiro.test(resid(fit))                       # 잔차의 정규성
bptest(fit)                                    # 등분산성
coeftest(fit, vcov = vcovHC(fit, type = "HC3"))  # 이분산이면 강건한 표준오차
max(cooks.distance(fit))                       # 영향점
vif(fit)                                       # 다중공선성
```

### 더미변수와 위계적 회귀

<!-- norun -->
```r 범주형 독립변수, 단계별 투입
m_pos <- lm(satisfaction ~ position + burnout, data = d)
anova(lm(satisfaction ~ burnout, data = d), m_pos)    # 범주 전체의 효과
library(emmeans)
emmeans(m_pos, pairwise ~ position)                   # 모든 쌍 비교 (Tukey)

m1 <- lm(burnout ~ female + age + tenure, data = d_c)
m2 <- update(m1, . ~ . + stress + support + efficacy)
anova(m1, m2)                                         # ΔR²의 F검정
summary(m2)$r.squared - summary(m1)$r.squared         # ΔR²
```

### 조절효과

<!-- norun -->
```r 중심화, 곱하기 항, 단순기울기
d$stress_c  <- d$stress  - mean(d$stress)
d$support_c <- d$support - mean(d$support)
m_main <- lm(burnout ~ efficacy + stress_c + support_c, data = d)
m_int  <- lm(burnout ~ efficacy + stress_c * support_c, data = d)
anova(m_main, m_int)                                  # 곱하기 항의 ΔR²

s <- sd(d$support)
emtrends(m_int, ~ support_c, var = "stress_c",
         at = list(support_c = c(-s, 0, s)))          # 단순기울기
```

### 매개효과와 조절된 매개

<!-- norun -->
```r lavaan으로 부트스트랩
library(lavaan)
med <- '
  burnout  ~ a * stress
  turnover ~ b * burnout + cp * stress
  indirect := a * b
  total    := cp + a * b
'
set.seed(2026)
fit_med <- sem(med, data = d, se = "bootstrap", bootstrap = 5000)
parameterEstimates(fit_med, boot.ci.type = "perc")
standardizedSolution(fit_med)

# 조절된 매개 (첫 단계 조절, PROCESS Model 7)
d$sxw <- d$stress_c * d$support_c
modmed <- sprintf('
  burnout  ~ a1 * stress_c + a2 * support_c + a3 * sxw
  turnover ~ b * burnout + cp * stress_c
  ind_low  := (a1 - %.4f * a3) * b
  ind_high := (a1 + %.4f * a3) * b
  index    := a3 * b
', s, s)
fit_mm <- sem(modmed, data = d, se = "bootstrap", bootstrap = 5000)
parameterEstimates(fit_mm, boot.ci.type = "perc")
```

:::paper 상관분석

:::

:::paper 다중회귀분석
> ○○, □□, △△가 ◇◇에 미치는 영향을 검증하기 위해 다중회귀분석을 실시하였다. 모든 독립변수의 VIF는 \_\_ 이하로 다중공선성의 문제는 없었다. 회귀모형은 통계적으로 유의하였으며(*F*(\_\_, \_\_) = \_\_, *p* < .001), 독립변수들은 ◇◇ 변동의 \_\_%를 설명하였다(*R*² = .\_\_, 수정 *R*² = .\_\_).
>
> ○○은 ◇◇에 정적으로 유의한 영향을 미쳤고(*B* = \_\_, β = .\_\_, *p* < .001), □□은 부적으로 유의한 영향을 미쳤다(*B* = −\_\_, β = −.\_\_, *p* = .\_\_\_). △△의 영향은 유의하지 않았다(*B* = \_\_, β = .\_\_, *p* = .\_\_\_).

## 자주 마주치는 오류 메시지

| 메시지 | 원인 | 해결 |
| --- | --- | --- |
| `models were not all fitted to the same size of dataset` | 단계마다 결측이 달라 사례 수가 다름 | `na.omit()`으로 분석 자료를 먼저 확정 (7장) |
| 계수가 `NA`로 나옴 | 완전한 공선성. 더미를 범주 수만큼 만들었거나 같은 변수가 두 번 들어감 | 더미는 $k-1$개, 변수 목록 확인 |
| `there are aliased coefficients in the model` | 위와 같음 (`vif()`에서) | 위와 같음 |
| `contrasts can be applied only to factors with 2 or more levels` | 부분 자료에서 범주가 하나만 남음 | `table()`로 범주별 사례 수 확인 |
| `glm.fit: fitted probabilities numerically 0 or 1 occurred` | 설명변수가 결과를 거의 완벽하게 가름 (완전분리) | 해당 변수의 분포 확인, 범주 합치기 |
| `glm.fit: algorithm did not converge` | 완전분리 또는 척도 문제 | 위와 같음, 변수 척도 확인 |
| `some observed variances are (at least) a factor 1000 times larger than others` | `lavaan`에서 변수 단위 차이가 큼 (예: 소득 원 단위) | 큰 변수를 1,000 등으로 나눠 단위 조정 |
| 더미의 기준 집단이 의도와 다름 | 문자 변수는 가나다순으로 수준이 정해짐 | `factor(levels = ...)` 또는 `relevel()` (6장) |
{.apa}

:::warn 오류가 나지 않는데 결과가 이상한 경우
회귀분석에서 가장 흔한 셋은 다음과 같습니다.

**① 범주형을 숫자로 넣음** — 직급을 1, 2, 3 그대로 넣으면 오류 없이 계수 하나가 나옵니다. `str(d)`로 확인합니다(6장).

**② 원점수로 곱하기 항을 만듦** — 주효과 계수가 엉뚱한 부호로 나옵니다. 중심화했는지 확인합니다(8장).

**③ 종속변수가 0/1인데 `lm()`을 씀** — 오류 없이 계수가 나오지만 확률이 음수가 됩니다(11장).
:::

## 분석 점검표

:::check 분석 전
- 변수의 척도를 확인했고, 범주형은 factor로 바꿔 기준 집단을 정했다
- 상관표로 변수 간 관계를 훑었고, 독립변수끼리 .80 이상인 쌍이 있는지 봤다
- 산점도로 곡선이나 이상치를 확인했다
- 분석에 쓸 사례를 확정했다(결측 처리)
- 독립변수 수에 비해 사례 수가 충분한지 확인했다
:::

:::check 분석 중
- 투입할 변수와 순서를 이론에 따라 미리 정했다
- 곱하기 항을 만들기 전에 중심화했다
- 잔차 진단과 VIF를 확인했다
- 부트스트랩에 `set.seed()`를 썼다
:::

:::check 보고
- *B*와 β, *R*²(위계적이면 Δ*R*²)를 함께 보고했다
- 범주형 변수의 기준 집단과 이분 변수의 코딩을 밝혔다
- 조절효과는 표, 단순기울기, 그림을 함께 제시했다
- 매개효과는 간접효과의 신뢰구간으로 판단했다
- 로지스틱 회귀는 오즈비를 확률의 배수로 쓰지 않았다
- 횡단 자료라면 인과 해석의 한계를 밝혔다
:::

## 다음 권 안내

2권에서는 **변수 사이의 관계**를 다뤘습니다. 얼마나 관련되는지, 다른 변수를 통제해도 그런지, 언제 더 강한지, 어떤 경로로 이어지는지.

그런데 2권 내내 한 가지를 당연하게 여겼습니다. **직무스트레스, 소진, 사회적지지 같은 점수가 그 개념을 제대로 재고 있다**는 것입니다. 0장에서 문항을 평균 내어 척도 점수를 만들었고, 5장에서 두 척도를 합쳐 합성 변수를 만들었습니다. 그렇게 해도 되는지는 묻지 않았습니다.

| 권 | 다루는 내용 | 2권과의 연결 |
| --- | --- | --- |
| **3권 요인분석** | 탐색적·확인적 요인분석, 신뢰도와 타당도 | 문항을 평균 내도 되는 근거, 5장의 합성 변수 |
| **4권 구조방정식** | 측정모형, 구조모형, 적합도 지수 | 9~10장의 `lavaan` 경로모형에 측정오차를 반영 |
{.apa}

:::key 3권과 4권에서 이어지는 지점
**0장의 척도 점수** — 여러 문항을 평균 내 변수 하나를 만들려면 문항들이 같은 것을 재고 있어야 합니다. 그 확인이 3권의 요인분석과 신뢰도 분석입니다.

**5장의 다중공선성** — 스트레스와 업무과부하가 .89로 상관된 것은 두 척도가 사실상 같은 개념을 재고 있다는 신호일 수 있습니다. 판별타당도라는 이름으로 3권에서 다시 다룹니다.

**9~10장의 `lavaan`** — 이번에는 관측된 점수 사이의 경로만 추정했습니다. 4권에서는 같은 문법으로 **잠재변수**를 정의해 측정오차를 걷어 낸 경로를 추정합니다. 회귀분석이 측정오차 때문에 관계를 과소추정하는 문제가 거기서 해결됩니다.
:::

## 마치며

1권이 "왜 이 분석을 쓰는가"였다면, 2권은 **"이 숫자가 정확히 무엇을 말하는가"**였습니다. 회귀계수 하나도 단순회귀에서와 다중회귀에서, 곱하기 항이 있을 때와 없을 때 뜻이 다릅니다. 같은 0.5라도 무엇을 통제했는지, 원점이 어디인지에 따라 다른 문장이 됩니다.

학위논문의 회귀분석 표에서 가장 자주 보는 실수는 계산이 아니라 해석입니다. 다중회귀 계수를 단순상관처럼 읽고, 원점수 곱하기 항의 주효과를 그대로 해석하고, 오즈비를 확률의 배수로 씁니다. 이 책이 계산보다 **읽는 법**에 지면을 많이 쓴 이유입니다.

책에 실린 R 출력은 모두 실제로 실행한 결과입니다. 같은 코드를 같은 자료에 돌리면 같은 값이 나옵니다.

:::key 후기를 남겨 주시면
읽고 나서 도움이 되었다면 **후기를 남겨 주십시오.** 어느 장이 특히 유용했는지, 어디가 더 설명이 필요했는지 알려주시면 다음 권에 반영합니다.

자신의 연구에서 막혔던 분석이 있다면 그것도 알려주십시오. 3권과 4권의 예제와 순서를 정하는 데 그대로 쓰겠습니다.
:::
