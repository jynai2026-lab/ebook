## 1권에서 2권으로

1권의 분석은 모두 **집단을 나누고 평균을 비교**하는 것이었습니다. 남녀의 자아존중감, 세 교수법의 성취도, 처치 전후의 점수가 그랬습니다. 독립변수가 집단이었습니다.

그런데 연구에서 던지는 질문은 대부분 이런 모양입니다.

- 직무스트레스가 **높을수록** 소진도 높아지는가
- 스트레스가 1점 오르면 소진은 **얼마나** 오르는가
- 사회적지지와 자기효능감을 **함께 고려해도** 스트레스의 영향이 남는가
- 스트레스는 **소진을 거쳐서** 이직의도에 영향을 주는가
- 사회적지지가 높은 사람에게는 스트레스의 영향이 **약해지는가**

독립변수가 집단이 아니라 **연속된 점수**입니다. 그리고 "다른가"가 아니라 **"얼마나"와 "어떤 경로로"**를 묻습니다. 이 질문에 답하는 도구가 회귀분석입니다.

:::key 새로 배우는 것보다 이어지는 것이 많습니다
2권의 개념 대부분은 1권에서 이미 본 것의 다른 이름입니다.

| 1권에서 본 것 | 2권에서 다시 만나는 이름 |
| --- | --- |
| 제곱합의 분할 $SS_T = SS_B + SS_W$ (9장) | 회귀의 제곱합 분할 $SS_T = SS_R + SS_E$ (2장) |
| 효과크기 $\eta^2$ (9장) | 결정계수 $R^2$ (2장) |
| 독립표본 $t$-검정 (7장) | 더미변수 하나짜리 회귀 (6장) |
| 일원분산분석 (9장) | 더미변수 여러 개짜리 회귀 (6장) |
| 이원분산분석의 상호작용 (11장) | 조절효과 (8장) |
| 신뢰구간 (6장) | 회귀계수의 신뢰구간, 부트스트랩 구간 (2장, 9장) |
{.apa}

특히 **분산분석과 회귀분석은 같은 모형**입니다. 6장에서 1권의 교수법 자료를 회귀분석으로 다시 돌려 $F$ = 18.12가 그대로 나오는 것을 확인합니다.
:::

## 예제 자료 — 직장인 300명 설문

이 책은 처음부터 끝까지 **자료 하나**를 씁니다. 장마다 자료가 바뀌면 분석 방법보다 자료를 이해하는 데 힘이 더 듭니다. 같은 자료를 두고 질문만 바꿔 가면 각 분석이 무엇을 더 알려주는지가 분명해집니다.

자료는 직장인 300명을 대상으로 한 설문을 가정해 만든 것입니다(가상 자료). 척도 점수는 모두 문항 평균이며 1~5점입니다.

| `position` | 직급 | 사원 104, 대리 104, 과장이상 92 | | |
| `stress` | 직무스트레스 | 1~5점 | 3.08 | 0.62 |

:::paper 자료는 이렇게 생겨야 합니다
**한 사람이 한 행**, **한 변수가 한 열**입니다. 1권에서와 같습니다.

척도 점수는 문항을 평균 내서 열 하나로 만들어 둡니다. 예를 들어 직무스트레스 6문항이 `st1`~`st6`에 있다면 다음 한 줄입니다.

`d$stress <- rowMeans(d[, c("st1", "st2", "st3", "st4", "st5", "st6")])`

역문항은 평균 내기 전에 뒤집어야 합니다(5점 척도라면 `6 - 점수`). 척도를 문항 평균으로 만들어도 되는지, 즉 문항들이 한 개념을 재고 있는지 확인하는 절차가 3권의 요인분석과 신뢰도 분석입니다.
:::

## 준비

1권에서 설치한 패키지에 두 개를 더합니다.

```r 최초 1회만 실행합니다
install.packages(c("psych", "car", "effectsize", "lmtest", "lavaan"))
```

| 패키지 | 쓰는 곳 |
| --- | --- |
| `psych` | 기술통계, 상관행렬 (1장) |
| `car` | 분산팽창지수, 잔차 진단 (4장, 5장) |
| `effectsize` | 표준화 회귀계수 (3장) |
| `lmtest` | 등분산 검정, 강건한 표준오차 (4장) |
| `lavaan` | 매개효과·조절된 매개의 부트스트랩 (9장, 10장). 4권 구조방정식에서도 그대로 씁니다 |

회귀분석 자체는 R에 기본으로 들어 있는 `lm()` 함수 하나로 합니다. 이 책의 회귀분석 코드는 대부분 이 모양입니다.

```r 이 책에서 가장 많이 보게 될 한 줄
fit <- lm(burnout ~ stress, data = d)
```

물결표(`~`) 왼쪽이 종속변수, 오른쪽이 독립변수입니다. 1권에서 `t.test(selfesteem ~ gender)`, `aov(score ~ method)`로 쓰던 것과 같은 문법입니다. **분석은 바뀌어도 모형을 적는 방식은 하나**입니다.

## "영향을 미친다"는 표현에 대해

학위논문에서는 회귀분석 결과를 "X가 Y에 유의한 영향을 미쳤다"고 쓰는 것이 관행입니다. 이 책의 서술 예시도 그 관행을 따릅니다.

다만 이 표현이 무엇을 말하고 무엇을 말하지 않는지는 알고 써야 합니다.

:::warn 회귀분석이 인과를 증명하지는 않습니다
회귀분석이 보여주는 것은 **"X가 높은 사람이 Y도 높은 경향이 있고, 그 경향의 크기가 이만큼이다"**입니다. X가 Y의 원인인지는 회귀분석이 아니라 **연구 설계**가 답합니다.

이 책의 자료처럼 한 시점에 모든 변수를 설문으로 잰 경우, 스트레스가 소진을 높였는지, 소진된 사람이 같은 상황을 더 스트레스로 느끼는지 자료만으로는 가릴 수 없습니다.

그래서 "영향을 미쳤다"는 **이론이 정한 방향을 따라 관계의 크기를 기술한 것**으로 읽어야 합니다. 논의 부분에서 이 한계를 적어 두는 것이 정직한 보고입니다. 9장의 매개효과에서 이 문제를 다시 다룹니다.
:::

**요약** — 2권은 연속된 독립변수가 종속변수와 **얼마나**, **어떤 경로로** 이어져 있는지를 다룹니다. 직장인 300명 자료 하나로 상관에서 시작해 매개·조절, 로지스틱 회귀까지 질문을 넓혀 갑니다. 새로운 개념처럼 보이는 것 대부분은 1권의 제곱합, 효과크기, 상호작용이 이름을 바꿔 다시 나오는 것입니다.
:::
