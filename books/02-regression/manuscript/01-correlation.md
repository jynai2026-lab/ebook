## 숫자보다 그림이 먼저입니다

직무스트레스가 높은 사람은 소진도 높을까요. 계산을 시작하기 전에 **산점도**부터 그립니다. 한 사람이 점 하나이고, 가로축이 스트레스, 세로축이 소진입니다.

```r 산점도 한 줄
d <- read.csv("data/survey.csv")
plot(d$stress, d$burnout, xlab = "직무스트레스", ylab = "소진")
```

!fig[**그림 1-1** 직장인 300명의 직무스트레스와 소진. 점구름이 오른쪽 위로 기울어 있다. 스트레스가 높은 사람일수록 소진도 높은 경향이 보인다.](ch01-scatter.svg)

점들이 오른쪽 위로 기울어진 띠 모양으로 모여 있습니다. 스트레스가 높은 사람이 대체로 소진도 높습니다. 그러나 완벽하지는 않습니다. 같은 스트레스 점수에서도 소진은 사람마다 꽤 다릅니다.

이 장에서 할 일은 **"얼마나 기울어진 띠인가, 얼마나 촘촘한 띠인가"를 숫자 하나로 요약하는 것**입니다. 그 숫자가 상관계수입니다.

## 함께 움직인다는 것을 숫자로 — 공분산

1권 2장에서 분산을 구할 때 **편차**에서 출발했습니다. 평균에서 얼마나 떨어져 있는가였습니다. 두 변수가 함께 움직이는지도 편차로 봅니다.

산점도에 두 평균을 기준선으로 그으면 평면이 네 칸으로 나뉩니다.

!fig[**그림 1-2** 두 평균선으로 나눈 네 칸. 오른쪽 위와 왼쪽 아래의 점은 두 편차의 부호가 같아 곱이 양수, 나머지 두 칸의 점은 곱이 음수다.](ch01-quadrant.svg)

| 칸 | 스트레스 편차 | 소진 편차 | 편차의 곱 |
| --- | --- | --- | --- |
| 오른쪽 위 | + | + | **+** |
| 왼쪽 아래 | − | − | **+** |
| 왼쪽 위 | − | + | − |
| 오른쪽 아래 | + | − | − |
{.apa}

두 변수가 같은 방향으로 움직이면 점이 오른쪽 위와 왼쪽 아래에 몰리고, **편차의 곱이 대부분 양수**가 됩니다. 반대 방향이면 음수가 대부분입니다. 아무 관계가 없으면 네 칸에 고르게 흩어져 양수와 음수가 상쇄됩니다.

그래서 편차의 곱을 모두 더해 평균 낸 값을 **공분산(covariance)**이라 합니다.

$$
\text{cov}(X, Y) = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{n - 1}
$$ (편차의 곱의 평균. $n-1$로 나누는 이유는 1권 2장과 같습니다)

```r 공분산
cov(d$stress, d$burnout)
```

```out
[1] 0.2297809
```

양수입니다. 300명 가운데 214명이 곱이 양수인 두 칸에 있었습니다.

:::key 분산은 자기 자신과의 공분산입니다
공분산 식에서 $Y$ 자리에 $X$를 넣으면 $\sum (X_i - \bar{X})^2 / (n-1)$, 곧 분산이 됩니다.

분산이 "한 변수가 평균 주위로 얼마나 흩어지는가"라면, 공분산은 "두 변수가 평균 주위에서 **얼마나 같은 방향으로** 흩어지는가"입니다.
:::

### 공분산만으로는 크기를 말할 수 없습니다

0.23이 큰 값일까요. 알 수 없습니다. **공분산은 단위를 따라가기 때문**입니다.

소진을 5점 척도가 아니라 100점 만점으로 바꿔 쟀다면 소진의 편차가 모두 25배가 되고, 공분산도 25배인 5.74가 됩니다. 관계는 그대로인데 숫자만 달라집니다. 키와 몸무게의 공분산은 센티미터로 재느냐 미터로 재느냐에 따라 100배가 차이 납니다.

## 단위를 없앤다 — 상관계수

해결책은 1권 2장의 $z$점수와 같습니다. **각 변수의 표준편차로 나눠 단위를 없앱니다.**

$$
r = \frac{\text{cov}(X, Y)}{s_X \, s_Y}
$$ (공분산을 두 표준편차의 곱으로 나눈 값)

```r 정의대로 계산한 값과 cor()의 값
cov(d$stress, d$burnout) / (sd(d$stress) * sd(d$burnout))
cor(d$stress, d$burnout)
```

```out
[1] 0.5505026
[1] 0.5505026
```

**$r$ = .55**입니다. 같은 계산을 다르게 볼 수도 있습니다. 두 변수를 먼저 $z$점수로 바꾸면 표준편차가 모두 1이 되므로, 상관계수는 **$z$점수끼리 곱한 값의 평균**이 됩니다.

```r z점수의 곱으로 계산해도 같습니다
zx <- scale(d$stress)
zy <- scale(d$burnout)
sum(zx * zy) / (nrow(d) - 1)
```

```out
[1] 0.5505026
```

이렇게 보면 상관계수가 왜 −1에서 +1 사이에 있는지도 이해됩니다. 모든 사람의 $z_X$와 $z_Y$가 똑같으면(점이 오른쪽 위로 향한 직선 위에 모두 놓이면) 곱의 평균이 분산과 같아져 1이 됩니다. 그보다 더 커질 수는 없습니다.

!fig[**그림 1-3** 상관계수의 크기에 따른 점구름의 모양. 부호는 기울어진 방향을, 크기는 점들이 직선 주위에 얼마나 촘촘히 모였는지를 나타낸다. 각 패널은 100명.](ch01-r-gallery.svg)

:::key 상관계수는 기울기가 아니라 촘촘함입니다
그림 1-3에서 $r$ = .8과 $r$ = .4의 점구름은 기울기가 비슷해 보여도 **흩어진 정도**가 다릅니다. 상관계수가 재는 것은 "점들이 직선 주위에 얼마나 모여 있는가"입니다.

"$X$가 1 오를 때 $Y$가 얼마나 오르는가"는 상관계수가 답하지 않습니다. 그것이 2장의 회귀계수입니다.
:::

| $\lvert r \rvert$ | 해석 (Cohen, 1988) |
| --- | --- |
| .10 | 작은 관계 |
| .30 | 중간 관계 |
| .50 이상 | 큰 관계 |
{.apa}

스트레스와 소진의 $r$ = .55는 큰 관계에 해당합니다. 다만 이 기준은 분야를 가리지 않은 대략의 출발점입니다. 같은 개념을 다른 척도로 잰 두 점수라면 .50은 오히려 낮은 값입니다.

### $r^2$ — 함께 나눠 가진 변동

상관계수를 제곱하면 해석이 하나 더 생깁니다.

$$
r^2 = .55^2 = .303
$$ (소진 변동 가운데 스트레스와 겹치는 비율)

**소진 점수가 사람마다 다른 정도(변동) 가운데 30%가 스트레스의 차이와 겹친다**는 뜻입니다. 나머지 70%는 스트레스로는 설명되지 않는 몫입니다.

!fig[**그림 1-4** 두 변수의 변동을 원으로 그리면 겹치는 부분이 $r^2$이다. 스트레스와 소진은 변동의 30%를 함께 나눠 갖는다. (개념도)](ch01-shared-variance.svg)

이 30%라는 숫자를 기억해 두십시오. 2장에서 스트레스로 소진을 예측하는 회귀분석을 하면 결정계수 $R^2$이 정확히 .303으로 나옵니다. 그리고 그 $R^2$은 1권 9장의 $\eta^2$과 같은 개념입니다.

## 상관이 0이 아닌가 — 유의성 검정

표본에서 구한 $r$ = .55가 모집단에서도 0이 아니라고 말할 수 있을까요. 1권에서 늘 하던 질문입니다. 영가설은 모집단 상관계수 $\rho$(로)가 0이라는 것입니다.

$$
H_0 : \rho = 0
$$

검정통계량은 $t$입니다.

$$
t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}} = \frac{.5505 \times \sqrt{298}}{\sqrt{1 - .303}} = 11.38
$$ (자유도는 $n - 2$ = 298)

```r 상관계수의 유의성 검정
cor.test(d$stress, d$burnout)
```

```out
	Pearson's product-moment correlation

data:  d$stress and d$burnout
t = 11.383, df = 298, p-value < 2.2e-16
alternative hypothesis: true correlation is not equal to 0
95 percent confidence interval:
 0.4663326 0.6247942
sample estimates:
      cor 
0.5505026
```

| 출력의 이 자리 | 값 | 의미 |
| --- | --- | --- |
| `t`, `df` | 11.383, 298 | 위에서 손으로 구한 값 |
| `p-value` | < 2.2e-16 | $p$ < .001 |
| `95 percent confidence interval` | .466 ~ .625 | 모집단 상관계수의 95% 신뢰구간 |
| `cor` | .5505 | 표본 상관계수 |

**$r$(298) = .55, $p$ < .001**입니다. 신뢰구간이 .47~.62로 0을 멀리 벗어나 있습니다.

:::warn 표본이 크면 작은 상관도 유의합니다
$n$ = 300이면 $\lvert r \rvert$이 .113만 넘어도 $p$ < .05가 됩니다. $r$ = .12는 $r^2$ = .014, 변동의 1.4%를 공유한다는 뜻입니다. 유의하다고 해서 의미 있는 관계라고 할 수는 없습니다.

1권 5장에서 본 것과 같습니다. **유의확률은 "0이 아닌가"에만 답하고, 크기는 $r$ 자체가 말합니다.** 논문에서는 둘을 함께 보고합니다.
:::

## 여러 변수를 한 번에 — 상관행렬

실제 논문에서는 주요 변수 사이의 상관을 표 하나로 보여줍니다. `psych` 패키지의 `corr.test()`가 상관계수와 유의확률을 함께 계산합니다.

```r 다섯 변수의 상관행렬
library(psych)
vars <- d[, c("stress", "support", "efficacy", "burnout", "turnover")]
ct <- corr.test(vars, adjust = "none")
round(ct$r, 2)
round(ct$p, 3)
```

```out
         stress support efficacy burnout turnover
stress     1.00   -0.22    -0.14    0.55     0.44
support   -0.22    1.00     0.31   -0.36    -0.22
efficacy  -0.14    0.31     1.00   -0.32    -0.11
burnout    0.55   -0.36    -0.32    1.00     0.56
turnover   0.44   -0.22    -0.11    0.56     1.00
         stress support efficacy burnout turnover
stress    0.000       0    0.015       0    0.000
support   0.000       0    0.000       0    0.000
efficacy  0.015       0    0.000       0    0.051
burnout   0.000       0    0.000       0    0.000
turnover  0.000       0    0.051       0    0.000
```

첫 번째 표가 상관계수, 두 번째 표가 유의확률입니다. 대각선을 기준으로 위아래가 같습니다.

소진은 나머지 네 변수와 모두 관련이 있습니다. 스트레스(.55), 이직의도(.56)와는 양의 관계, 사회적지지(−.36), 자기효능감(−.32)과는 음의 관계입니다. 유일하게 유의하지 않은 것은 자기효능감과 이직의도(−.11, $p$ = .051)입니다.

:::paper adjust 인자에 대해
`corr.test()`는 기본값으로 유의확률을 다중비교 보정(Holm)합니다. 상관을 10쌍 보면 1권 10장에서 본 것처럼 제1종 오류가 누적되기 때문입니다.

그러나 학위논문의 상관표는 관례적으로 **보정하지 않은 유의확률**을 표시합니다. 상관표의 목적이 가설검정보다 변수 간 관계를 개관하는 데 있기 때문입니다. 여기서도 `adjust = "none"`으로 보정 없는 값을 썼습니다. 상관 자체가 연구 가설이라면 보정을 고려합니다.
:::

## 상관계수가 속이는 네 가지 경우

상관계수는 편리하지만 **산점도를 숫자 하나로 줄인 것**입니다. 줄이는 과정에서 정보가 사라집니다. 다음 네 경우는 숫자만 보면 놓칩니다.

### 1. 직선이 아닌 관계

통계학자 Anscombe(1973)가 만든 자료 네 쌍입니다. R에 `anscombe`라는 이름으로 들어 있습니다.

```r 네 자료의 상관계수
sapply(1:4, function(i) cor(anscombe[[i]], anscombe[[i + 4]]))
```

```out
[1] 0.8164205 0.8162365 0.8162867 0.8165214
```

네 쌍 모두 $r$ = .816입니다. 평균과 표준편차도 거의 같습니다. 그런데 산점도는 전혀 다릅니다.

!fig[**그림 1-5** Anscombe의 네 자료. 상관계수는 모두 .816이지만 ① 직선 관계, ② 곡선 관계, ③ 이상치 하나가 기울기를 바꾼 경우, ④ 이상치 하나가 관계를 만들어 낸 경우로 모두 다르다.](ch01-anscombe.svg)

② 곡선 관계는 **상관계수가 직선 관계만 잰다**는 것을 보여줍니다. 뒤집힌 U자 관계라면 관계가 아주 강해도 $r$은 0 근처가 될 수 있습니다. 각성 수준과 수행처럼 "적당할 때 가장 좋은" 관계가 그렇습니다.

### 2. 이상치 하나

③과 ④는 **점 하나**가 상관계수를 좌우합니다. ④는 점 하나를 빼면 관계 자체가 없습니다. 사례 수가 적을수록 이상치의 힘이 커집니다. 4장에서 이런 점을 찾는 방법을 다룹니다.

:::ok 해결책은 하나입니다
**상관계수를 보기 전에 산점도를 그립니다.** 그림 1-5의 네 경우는 모두 산점도에서 한눈에 보입니다. `plot()` 한 줄이면 됩니다. 변수가 많다면 `pairs(vars)`가 모든 쌍의 산점도를 한 번에 그립니다.
:::

### 3. 범위 제한

스트레스가 높은 사람(3.5점 이상)만 따로 모아 상관을 구해 봅니다. 예를 들어 고위험군만 모집한 연구가 이런 상황입니다.

```r 스트레스 3.5점 이상인 사람만
high <- d[d$stress >= 3.5, ]
nrow(high)
cor(high$stress, high$burnout)
```

```out
[1] 91
[1] 0.3421627
```

전체에서 .55였던 상관이 **.34로 떨어졌습니다.** 관계가 약해진 것이 아닙니다. 스트레스의 범위가 좁아져서 스트레스의 차이로 소진의 차이를 보여줄 여지가 줄었을 뿐입니다.

!fig[**그림 1-6** 범위 제한. 스트레스 3.5점 이상(진한 점)만 보면 점구름이 둥글어져 상관이 .34로 낮아진다. 관계는 같은데 보이는 범위가 좁아졌을 뿐이다.](ch01-range.svg)

입사 시험 점수와 입사 후 업무 성과의 상관이 낮게 나오는 이유도 이것입니다. 시험 점수가 높은 사람만 입사했기 때문에 범위가 잘려 있습니다.

### 4. 제3변수

이 자료에서 근속연수와 직무만족의 상관을 구하면 이렇습니다.

```r 근속연수와 직무만족
cor(d$tenure, d$satisfaction)
```

```out
[1] 0.2572506
```

$r$ = .26, 유의한 양의 상관입니다. 오래 다닐수록 만족도가 높아진다고 해석하고 싶어집니다.

그런데 직급별로 나눠서 다시 구해 보면 이야기가 달라집니다.

```r 직급 안에서 다시 구한 상관
d$position <- factor(d$position, levels = c("사원", "대리", "과장이상"))
sapply(split(d, d$position), function(g) cor(g$tenure, g$satisfaction))
```

```out
        사원         대리     과장이상 
-0.052638493  0.008453253  0.001553163
```

같은 직급 안에서는 **상관이 사실상 0**입니다. 전체에서 보인 .26은 근속연수가 만족을 높여서가 아니라, 근속연수가 길수록 직급이 높고 직급이 높을수록 만족이 높았기 때문에 생긴 것입니다. 직급이라는 **제3변수**가 두 변수를 함께 움직였습니다.

!fig[**그림 1-7** 제3변수. 전체로 보면 근속연수와 직무만족이 함께 오르지만(회색 선), 직급 안에서는 관계가 없다(색깔별 선). 직급이 두 변수를 함께 끌어올린 것이다.](ch01-third.svg)

:::warn 상관은 인과가 아닙니다
상관이 보여주는 것은 함께 움직인다는 사실뿐입니다. 이유는 셋 중 하나입니다. $X$가 $Y$를 움직였거나, $Y$가 $X$를 움직였거나, 제3의 변수가 둘을 함께 움직였습니다. 상관계수는 이 셋을 구분하지 못합니다.

다른 변수를 **고정한 채로** 관계를 보는 방법이 3장의 다중회귀입니다. 위에서 직급별로 나눠 본 것이 그 발상의 가장 단순한 형태입니다.
:::

## 서열척도라면 — 스피어만 상관

피어슨 상관계수는 두 변수가 **등간척도 이상**이라는 전제에서 계산합니다. 1권 1장에서 다룬 척도 구분이 여기서 다시 쓰입니다.

한쪽이라도 서열척도(학년, 순위, 단일 리커트 문항)이거나, 이상치가 걱정되거나, 관계가 직선은 아니어도 한 방향으로 꾸준히 오르는 경우에는 **스피어만 순위상관($\rho$)**을 씁니다. 원점수 대신 순위를 매긴 뒤 상관을 구하는 방법입니다.

```r 순위상관
cor.test(d$stress, d$burnout, method = "spearman", exact = FALSE)
```

```out
	Spearman's rank correlation rho

data:  d$stress and d$burnout
S = 1953513, p-value < 2.2e-16
alternative hypothesis: true rho is not equal to 0
sample estimates:
      rho 
0.5658811
```

$\rho$ = .57로 피어슨 $r$ = .55와 비슷합니다. 이 자료는 이상치가 없고 관계가 직선에 가까워 두 방법의 결과가 거의 같습니다. **두 값이 크게 다르다면 산점도를 다시 볼 신호입니다.**

## 논문 결과표

상관표는 대각선 아래 삼각형만 채우고, 왼쪽에 평균과 표준편차를 함께 둡니다.

**표 1. 주요 변수의 기술통계와 상관**

| 변수 | *M* | *SD* | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1. 직무스트레스 | 3.08 | 0.62 | — | | | | |
| 2. 사회적지지 | 3.52 | 0.60 | −.22\*\*\* | — | | | |
| 3. 자기효능감 | 3.61 | 0.56 | −.14\* | .31\*\*\* | — | | |
| 4. 소진 | 2.86 | 0.68 | .55\*\*\* | −.36\*\*\* | −.32\*\*\* | — | |
| 5. 이직의도 | 2.72 | 0.82 | .44\*\*\* | −.22\*\*\* | −.11 | .56\*\*\* | — |
{.apa}

*주.* *N* = 300. \**p* < .05, \*\**p* < .01, \*\*\**p* < .001.

:::paper 결과 서술 예시
> 주요 변수 간의 관계를 확인하기 위해 피어슨 상관분석을 실시하였다(표 1). 직무스트레스는 소진(*r* = .55, *p* < .001) 및 이직의도(*r* = .44, *p* < .001)와 정적 상관을 보였고, 사회적지지(*r* = −.22, *p* < .001) 및 자기효능감(*r* = −.14, *p* = .015)과는 부적 상관을 보였다. 소진은 이직의도와 높은 정적 상관을 보였다(*r* = .56, *p* < .001). 자기효능감과 이직의도의 상관은 유의하지 않았다(*r* = −.11, *p* = .051).

상관표는 회귀분석에 앞서 **변수 사이의 관계를 미리 보여주는 자리**입니다. 독립변수끼리 상관이 지나치게 높으면(대략 .80 이상) 5장의 다중공선성을 의심할 근거가 되므로, 이 표를 먼저 살펴봅니다.
:::

:::check 점검 항목
- 상관계수를 보기 전에 산점도를 그렸다
- 공분산은 단위에 따라 바뀌고, 상관계수는 단위가 없다는 것을 안다
- 상관계수는 기울기가 아니라 직선 주위의 촘촘함이라는 것을 안다
- $r^2$이 공유하는 변동의 비율이라는 것을 안다
- 곡선 관계, 이상치, 범위 제한, 제3변수를 확인했다
- 서열척도라면 스피어만 상관을 썼다
- 상관표에 *M*, *SD*와 유의 표시를 함께 넣었다
:::

:::recap
**요약** — 상관계수는 공분산을 두 표준편차로 나눠 단위를 없앤 값이며, **$z$점수끼리 곱한 값의 평균**입니다. 점들이 직선 주위에 얼마나 촘촘한지를 −1에서 +1로 나타내고, 제곱한 $r^2$은 두 변수가 공유하는 변동의 비율입니다. 숫자 하나로 줄이는 과정에서 곡선, 이상치, 범위 제한, 제3변수가 가려지므로 **산점도를 먼저 그립니다.**
:::
